# Revision 1 실행 후 화면 유지 설계

## 목표

`1. Revision 1 생성` 실행이 끝나도 사용자를 `실험 결과` 화면으로 강제 이동하지 않는다.

## 동작

- 실행 중에는 기존 버튼 진행 상태를 유지한다.
- 성공하면 현재 `자동화 실행` 화면의 결과와 Manifest Revision 1을 갱신한다.
- 버튼 영역에 `Revision 1 생성 완료 · <Flow ID>`를 표시한다.
- 동일한 내용을 성공 알림으로도 표시한다.
- `실험 결과` 화면은 사용자가 사이드 메뉴를 직접 선택할 때만 연다.
- 실패 시에는 완료 표시를 숨기고 기존 오류 알림을 사용한다.

## 검증

- 성공 후 활성 화면이 `agent-control`인지 확인한다.
- 완료 상태에 생성된 Flow ID가 표시되는지 확인한다.
- 실험 결과 데이터는 저장되지만 자동으로 화면 전환되지 않는지 확인한다.
