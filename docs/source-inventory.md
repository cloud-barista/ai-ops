# 공개 산출물 범위

## 포함한 파일

- `llmop`: Go 요구사항 분석 API, LLM 후보 설정, 테스트와 설계·제출 문서
- `resource_ops`: Go 자원 정규화·추천 API, 스키마와 테스트
- `deployment_agent`: Go 배포·운영 판단 API와 Guard, 테스트, 설계/API/시험 문서
- `platform`: 통합 웹/API, 실행 어댑터, CPU/GPU 실행기, 관측과 플랫폼 시험
- `poc/research_policy`: 보상 학습, 추론 서비스, 실측 수집, 데이터 변환, CLI와 수집 도구
- `poc/optimization_research`: 연구 스크립트 327개, 연구 시험 파일 211개, 정책 계산 모듈, 계약·예시, 연구 보고서와 공개 가능한 결과 요약·그림

각 디렉터리의 역할은 [산출물 안내](deliverables.md)에 정리했습니다. 연구 자료는 실험 단계와 채택 여부를 포함하며, 모두 통합 플랫폼의 기본 동작으로 적용됐다는 의미는 아닙니다.

## 별도로 준비하는 파일

원본 실행 DB, 대용량 외부 데이터, 학습 모델과 모델 가중치는 배포하지 않습니다. 연구의 출처 문서, 준비 방법, 해시와 재현 스크립트는 포함합니다. 보고서의 생성 결과 중 배포하지 않는 파일은 링크 대신 경로로 표시했습니다.

개인 연락처, 개인 홈 경로, 실제 계정·서버 연결 정보, 비밀키와 토큰은 제외하거나 예시 값으로 바꿨습니다. 가상환경, 다운로드 캐시, 실행 로그, 임시 백업과 에이전트 작업 메모는 산출물에 포함하지 않습니다.

## 시험 구분

Go 모듈과 통합 플랫폼의 단위 검사, Linux 학습 정책·수집기 검사와 원자료 없이 실행하는 연구 계약 검사를 GitHub CI에서 실행합니다. 원본 데이터 또는 고정 모델이 필요한 연구 재현 시험은 해당 입력을 준비한 환경에서 실행합니다.
