# HAS-GPU request CSV source

Source: Jianfeng Gu, Puxuan Wang, Isaac David Núñez Araya, Kai Huang, and Michael Gerndt, *HAS-GPU: Efficient Hybrid Auto-scaling with Fine-grained GPU Allocation for SLO-aware Serverless Inferences*, [Zenodo record 15596511](https://zenodo.org/records/15596511), DOI 10.5281/zenodo.15596511.

License: [CC BY 4.0, as recorded by the Zenodo API](https://zenodo.org/api/records/15596511). Credit the authors and indicate changes when reusing the data.

The 18 CSVs in this directory are copied unchanged from the [official repository at commit `31f8ea29ca184193dbc7523736d77c817ddce980`](https://github.com/KontonGu/HAS-GPU/tree/31f8ea29ca184193dbc7523736d77c817ddce980). Their SHA-256 values are listed in the adjacent `../frozen_manifest.json`, based on the matching members of the Zenodo ZIP. This directory contains only request CSVs; no GPU observation files are copied. The evaluation uses only the request CSV fields described in the protocol.
