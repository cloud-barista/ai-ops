# 지원 범위별 자원 반응과 처리량 prior 선택: 부정적 실험

## 질문과 결과

기존 8개 앵커·교차 모델 공분산 방법은 같은 입력 조건의 encoder 모델에서 성능 예측이 좋았지만, **새 입력 조건의 요청/초 예측은 커널과 Ridge보다 나빴다**. 기존의 [지원 범위별 지연 보정](physical_response_transfer_findings.md)에 처리량 prior 선택을 붙이면 이 문제를 줄일 수 있는지 확인했다.

**줄이지 못했다.** 바깥 9개 모델 분할마다 다른 encoder 모델만 이용한 중첩 검증에서 공분산이 9번 모두 선택됐다. 따라서 결합 예측은 기존의 지연 보정과 모든 5,096개 자원 후보에서 정확히 같았다. 새 조건의 지연 오차는 기존 보정 수준으로 낮아졌지만, 처리량 오차와 생성 SLO 추천 성공은 개선되지 않았다. 이 방법을 새 고유 알고리즘이나 일반화 성과로 주장하지 않는다.

## 누수 없이 무엇을 선택했는가

바깥 분할에서 대상 모델 전체를 제외하고, 다른 encoder 모델 7개 또는 8개로 내부 검증했다. 내부에서는 모델 하나를 다시 제외하고 공통 입력 조건 64개를 네 부분으로 나눴다. 각 부분을 평가할 때는 숨긴 **16개 입력 조건을 모든 학습 모델에서 제외**하고 절대 성능 예측기와 donor의 모델 제외 잔차 prior를 재학습했다. 내부 대상 모델의 남은 조건에서 GPU 1개·CPU 2코어 앵커 8개를 정적으로 골라 측정한 것으로 가정했다. 그 앵커만 조건화에 사용한 뒤 숨긴 16개 조건의 앵커 처리량 절대 로그오차(MALE)를 비교했다.

후보는 이전과 같은 공분산 보정, 매끄러운 커널 보정, Ridge 보정이며, 모두 8개 프로브를 공유한다. 실제 바깥 모델에서는 기존 주 캠페인 K8 프로브와 고정 지연 보정 예측 (`../artifacts/physical_response_transfer_v1/predictions.parquet`)을 그대로 썼다. 같은 작업의 donor가 정확한 조건을 가진 주 캠페인에서는 원래 공분산 지연·처리량을 유지했다. 새 입력 조건인 novel-matrix와 space-filling의 encoder 작업에서는 donor 조건 CV로 고른 처리량 prior와 기존의 donor-CV 지연 보정을 결합했다. 같은 작업 donor가 없는 Qwen 작업은 원래 공분산의 커널 fallback으로 남겼다. 새 조건에 대한 추가 프로브는 0개다.

내부 검증은 각 바깥 분할에서 숨긴 조건 64개 × 내부 대상 모델 7–8개의 앵커 오차를 사용했다. 선택 점수의 바깥 분할 평균은 다음과 같다. 이들은 **훈련 donor 내부 점수**이며 독립 외부 성능 추정치가 아니다.

| 처리량 prior | donor 내부 앵커 RPS MALE ↓ | 선택된 바깥 분할 |
| --- | ---: | ---: |
| 공분산 | **0.2032** | **9/9** |
| 커널 | 0.2119 | 0/9 |
| Ridge | 0.2288 | 0/9 |

## 해석과 범위

이 내부 조건 CV는 **기존 64개 입력 격자에서 16개를 숨긴 보간 문제**를 만든다. 실제 novel-matrix·space-filling 조건은 원래 격자 밖에 따로 설계됐다. 또한 선택 손실은 GPU 1개·CPU 2코어의 앵커 처리량 오차인데, 최종 결정은 8개 자원 후보의 처리량·지연과 생성 SLO에 달려 있다. 내부에서 가장 작은 앵커 오차가 새 조건의 최종 처리량 오차를 최소화한다고 가정할 근거가 없음을 이번 결과가 보여준다. 단, 어느 차이가 입력 분포 변화 때문인지, 앵커 손실과 자원 반응 손실의 차이 때문인지는 이 실험만으로 분리할 수 없다.

방법 가족은 이미 새 조건에서 공분산 처리량이 악화된 것을 관찰한 뒤 구성했다. 이 평가 역시 **사후 탐색**이며, 새 모델·호스트·실제 사용자 SLO가 없는 한 독립 검증이나 학술적 노벨티 입증이 아니다. 현재 자료로는 이 처리량 prior 선택기를 채택할 근거가 없고, 같은 K8 예산에서는 기존 공분산을 유지하는 편이 정직하다.
