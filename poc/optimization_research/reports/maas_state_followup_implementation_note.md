# MaaS 상태별·결측 인식 GPU 위험 후속 실험: 점수 전 구현 선택

고정 시각: **2026-09-28 11:52 UTC**. 이 문서는 [기존 음성 결과](maas_instance_risk_findings.md)를 본 뒤 적은 [후속 가설](maas_risk_prior_art_and_next_hypothesis.md)의 구현상 빈칸을 채운다. **후속 모델 점수 계산 전**에 기록했다. 동일한 한 주의 학습·검증·시험을 다시 쓰는 탐색이며 독립 검증이 아니다. 원래 [MaaS 규약](maas_instance_risk_protocol.md)과 결과 파일은 변경하지 않는다.

## 행·시각·계측

- 기존 감사된 1% ID 표본, 같은 `instance_hash`와 정확한 5분 `time_s` 결합을 사용한다. 판단 `d=t+600초`; 입력은 `t-600,t-300,t`의 창 중 `d`까지 완료·전달된 값만이다. 정답은 `t+600,...,t+2100`의 여섯 창에서 SM ≥80% 또는 메모리 ≥90% 중 하나라도 발생한 여부다. 마지막 창 전달 가용시각 `d+2100`까지 각 분할 안에 있어야 한다. 미래 창의 결측은 음성이 아니라 정답 미관측이다.
- 완전 창 집단은 과거 세 창과 미래 여섯 창이 전부 고유·유효한 **원래 평가와 동일한 행**이다. 새 생성 결과의 분할·정답 건수를 원래 감사와 비교하고, 시험의 `(instance_hash,decision_s,y)`를 원래 `test_predictions.parquet`와 일대일로 대조한다. 기존 검증 선택 기준선과 단일 로지스틱의 **저장된 예측**은 이 같은 시험 행에만 연결한다.
- 과거 부분결측 집단은 현재 창이 고유·유효하고 미래 여섯 창도 고유·유효하지만 오래된 두 창 중 하나 이상이 없거나 중복·무효인 행이다. 현재 창이 존재하지만 무효·중복이면 `INSUFFICIENT_EVIDENCE`로 감사하고 예측하지 않는다. 원자료에 현재 행 자체가 없는 시각은 판단 후보를 만들 수 없으므로 해당 전체 달력시간 수는 알 수 없다고 표시한다.
- 완전·부분결측 **후보**는 미래 여섯 창을 보기 전에 현재·과거 관측 상태로 먼저 분류한다. 미래 여섯 창이 모두 고유·유효한 비율을 정답 관측률로 따로 기록한다. 미래 결측을 입력 특징이나 음성 정답으로 쓰지 않는다. 현재 중복 행의 `INSUFFICIENT_EVIDENCE`는 원시 행 수가 아니라 `(instance_hash,time_s)`별 한 판단으로 센다.
- 원래 기준과 같이 `samples>0`, `gpu_count>0`, SM·GPU 메모리 사용률 `[0,100]`, 시각·키 고유성을 유효 조건으로 둔다. `gpu_mem_util>100`의 공개 의미를 모른 채 제외했던 기존 실험의 해석 문제를 **탐색 한계**로 보존한다. 미래 클러스터·GPU 수 변경은 진단만 하고 특징에 넣지 않는다.

## 새 모델의 입력·적합

- 새 상태별 두 로지스틱, 새 단일 로지스틱과 상태별 **마스크 제거** 절제 모델은 모두 `완전 창 ∪ 과거 부분결측`의 **동일한 학습 행**을 사용한다. 두 창의 SM·GPU 메모리·`samples`가 무효이면 해당 열의 **학습 집합 내 유효 관측 중앙값**으로 채운다. 현재 창은 채우지 않는다. 채운 세 창으로 원래 16개 숫자 특징(세 창의 SM·메모리·samples, 현재 GPU 수, 평균·최댓값·현재−최초 변화량)을 다시 계산한다.
- 모든 새 로지스틱의 공통 특징에 `current_high`와 `any_recent_high`를 추가한다. `any_recent_high`는 **유효한** 과거 창 중 임계값을 넘은 것이 있는지다. 무효 창의 임계값 플래그는 0이며 그 창의 유효성은 별도 마스크로 알린다. 상태별·단일 주 모델에는 오래된 두 창의 유효 마스크와 `past_age_s`도 추가한다. `past_age_s`는 중간 창이 유효하면 **300**, 중간은 무효이고 최초 창만 유효하면 **600**, 둘 다 무효이면 **900초**다. 현재 창은 늘 유효하므로 나이를 0으로 만들지 않는다. 마스크 제거 절제는 두 유효 마스크와 `past_age_s`를 **함께 제거**하고 그 밖의 입력·행을 유지한다.
- 마스크 입력은 오래된 각 창의 **유효/무효 이진값 하나씩**이다. 없음·중복·범위 밖의 이유는 모델 입력으로 세분하지 않고 감사표에 따로 센다. `past_age_s`는 위 두 오래된 창만 보며 `t-900` 등 더 먼 계측을 검색하지 않는다.
- 결측 대체 중앙값과 `StandardScaler`는 학습 행에서만 적합한다. L2 `LogisticRegression(solver='lbfgs',max_iter=1000,random_state=42)`의 `C∈{0.1,1,10}` 중 검증 Brier가 낮은 값을 고른다(동률은 작은 C). 상태별 두 모델과 상태별 마스크 제거 모델은 **각 상태의 검증 행에서 별도로** C를 고르고, 단일 모델은 전체 검증 행에서 고른다. 현재 정상은 `sm_current<80`와 `mem_current<90`이 모두 참인 상태다. 모델 식별자·미래 자원·미래 정답은 특징이 아니다.
- 완전 창에는 원래 저장된 기준선 세 가지·원래 단일 로지스틱도 같은 시험 행에 보여 준다. 부분결측의 단순 기준선은 **부분결측 학습 행만** 사용해 현재 정상/초과별 양성률을 Beta(1,1) 평활한 값이다. 이 기준선의 학습률과 새 모델은 시험 정답으로 맞추지 않는다. 원래 단일 로지스틱은 부분결측 값에 적용하지 않는다.

## 점수 전 게이트와 판정

각 집단(완전, 부분결측)의 전체와 **현재 정상층**을 분리해 학습·검증·시험 각각에서 적격 판단 ≥2,000, 양성·음성 각 ≥100, 양성 인스턴스 ≥30을 확인한다. 어느 집단·층이 실패하면 그 집단·층의 점수는 계산하지 않고 수와 사유만 보고한다. 상태별 로지스틱 적합을 위해 현재 초과층의 학습 정답에도 두 클래스가 있어야 하며, 충족하지 않으면 해당 집단의 상태별 평가를 보류한다. 두 시험일 중 어느 날이든 양성 <100이면 **일자별 우세를 선언하지 않는다**. 모든 게이트를 점수 계산 전에 저장하고 해시로 고정한다.

주 지표는 같은 행의 Brier다. 보조 지표는 AP와 **해당 집단·시험일마다** 확률 상위 `ceil(5%×n)` 경보의 precision·recall이며 동률은 원래 `alarm_tie_hash` 오름차순으로 정한다. 완전 창의 현재 정상층에서 새 상태별 모델은 기존 저장 단일 로지스틱 및 검증 선택 기준선 **각각**보다 전체 Brier가 상대 ≥5% 낮고, 두 시험일 각각 낮으며, 전체 AP와 두 시험일 상위 5% recall이 각각 낮지 않은지를 확인한다. 부분결측은 같은 행의 새 단일 모델·상태별 평활률과 짝지어 보고하되, 가설 메모에 별도 수치 성공 문턱이 없으므로 사후에 만들지 않는다. 인스턴스별 표본 수·오류도 함께 보고한다. 이 평가는 실제 `SCALE_OUT/IN` 행동 효과를 측정하지 않는다.
