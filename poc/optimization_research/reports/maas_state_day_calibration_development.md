# MaaS 상태별 전날 확률 보정: 공개된 두 ID 집합의 개발 결과

2026-09-29. **상태: 후향 탐색, 독립 성공 판정 아님.** [저장 단일 모델의 새 ID 시험](maas_existing_model_new_id_findings.md)이 Brier 5% 채택 기준에 못 미친 뒤, 이미 점수를 본 bucket 0·1의 오차를 살펴 새 보정 가설을 만들었다. 두 집합 모두 방법 설계에 사용됐다. 다음 새 ID 집합을 열기 전 [평가 규약](maas_state_day_calibration_new_id_protocol.md)을 별도로 고정해야 한다.

현재 정상·과거와 미래가 완전 관측된 판단만 대상으로 한다. 고정 모델 `p_m`에, 판단일 전날 **그날 00:00 전에 정답이 완료된 행만** 써서 `any_recent_high=0/1` 상태별 발생률을 Beta(1,1)로 구했다. 훈련 기간의 상태별 발생률 `p_train,h`에 대한 로그오즈 차를 `logit(p_m)+logit(p_previous_day,h)−logit(p_train,h)`로 적용한다. 이전 날짜의 늦은 판단에서 아직 완성되지 않은 미래 정답은 제외했다. 사용자 SLO나 실제 VM 조치가 아닌 30분 내 SM≥80% 또는 GPU 메모리≥90% **관측 사건**의 확률이다.

| 공개된 ID 집합 | 판단·신규 초과 | 저장 모델 Brier | 전역 정확한 절편 | 전날 상태별 Beta 단독 | 상태별 정확한 절편 | 제안 로그오즈 차 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| bucket 0 | 53,513·1,899 | 0.019285 | 0.019256 | 0.019991 | 0.018883 | **0.018870** |
| bucket 1 | 55,436·2,287 | 0.022807 | 0.022837 | 0.023146 | 0.022334 | **0.022292** |

제안법의 저장 모델 대비 Brier 감소는 bucket 0 **2.15%**, bucket 1 **2.26%**였다. 전역 절편 대비 **2.01%·2.39%** 낮았고, ID 단위로 짝지어 2,000회 재표집한 `제안−저장 모델` 차의 95% 구간은 bucket 0 **[−0.0007696,−0.0000927]**, bucket 1 **[−0.0008532,−0.0002113]**이었다. 두 날짜 모두 저장 모델보다 낮았다. AP는 bucket 0 `0.551782→0.553610`으로 높고 bucket 1 `0.545267→0.541630`으로 조금 낮았다. [전체 집계·만기 정답 수](../artifacts/maas_state_day_calibration_dev_v1/results.json), [재현 코드](../scripts/explore_maas_state_day_calibration.py).

상태별 **정확한 절편**도 거의 같은 Brier를 냈다. 따라서 이번 숫자로 제안 로그오즈 차 수식의 고유 우위나 학술적 최초성을 주장하지 않는다. 두 집합 모두 이전 연구로 정답이 노출됐고 같은 MaaS 주간에 속한다. 전날 정답 전달 시각도 실제 기록이 아니라 창 완료+5분 가정이다. 새 ID 시험에서 보정 수식·비교기·게이트를 고정해 확인하기 전에는 위험 입력으로 채택하지 않는다.
