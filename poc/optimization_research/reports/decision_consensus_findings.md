# 같은 8회 측정에서 예측기 일치로 배포 승인을 보수화한 평가

## 평가 설계

[기존 SLO 대체 평가](counterfactual_slo_findings.md)의 고정된 모델당 8개 기준 측정 예측을 사용했다. 공분산 전이, 부드러운 커널 전이, Ridge 보정은 **같은 대상 모델의 같은 8개 공간 선택 측정**을 사용한다. 둘 또는 셋의 예측기가 모두 지연 p95와 요청/초 목표를 만족한다고 할 때만 형상을 승인하고, 승인 가능한 형상 중 GPU 수와 CPU 코어 수가 가장 작은 것을 택했다. 각 예측기 하나에 로그 여유 폭 `m ∈ {0, 0.05, 0.10, 0.20, 0.30}`을 넣는 정책도 같은 방식으로 평가했다. `m`은 예상 지연에 `exp(m)`을 곱하고 예상 요청/초를 `exp(m)`으로 나눈다.

9개 모델을 하나씩 제외하는 각 분할에서 지연·처리량 목표 25쌍은 **나머지 8개 모델의 측정 분위수만**으로 정했다. 대상 모델의 성능 실측은 선택 후 성공·잘못 승인 판단에만 썼다. 따라서 아래 결과는 실제 사용자 SLO의 검증이 아니라, 기존 SQLite 안에서 수행한 **탐색적 합성 목표 평가**다. 한 workload를 25회 반복 평가한 질의끼리는 독립적이지 않다.

## 결과

실측상 가능한 workload·목표 질의는 6,746개다. 표의 모든 정책은 대상 모델의 기준 측정 8회만 사용하며, GPU 측정 비용을 추가하지 않는다. 전체 `14,375`개 workload·목표 질의 중 승인된 수와 그 승인의 실측 결과는 다음과 같다.

| 정책 | 로그 여유 폭 | 승인 | 성공 | 잘못 승인 | 승인 중 잘못 승인율 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 공분산 단독 | 0 | 6,717 | 6,143 | 574 | 8.55% |
| 공분산 단독 | 0.05 | 6,523 | 6,056 | 467 | 7.16% |
| 공분산 + 커널 동의 | 0 | 6,635 | 6,099 | 536 | 8.08% |
| 공분산 + Ridge 동의 | 0 | 6,555 | 6,090 | 465 | 7.09% |
| 세 방법 모두 동의 | 0 | 6,523 | 6,073 | 450 | 6.90% |

세 방법 모두 동의하는 정책은 공분산 단독의 여유 폭 0.05와 **전체 승인 수가 정확히 6,523으로 같다**. 같은 총 승인 수에서 성공은 17건 많고 잘못 승인은 17건 적었다. 다만 이는 결과를 본 뒤 고른 비교다. 모델을 재표본화한 기술적 95% 구간은 모델당 성공 차이 **[-8.11, 8.22]**, 잘못 승인 차이 **[-9.11, 4.44]**로 모두 0을 포함한다. 9개 모델 중 5개에서는 세 방법 동의 정책의 잘못 승인 건수가 공분산 여유 폭 0.05보다 오히려 많았다. 두 정책의 대상 모델별 승인 수 또한 같지 않다.

여유 폭 없이 비교하면 세 방법 동의는 공분산 단독보다 잘못 승인이 **124건 적지만**, 성공도 **70건 적다**. 잘못 승인 건수는 9개 모델 모두에서 줄었다. 여유 폭을 더 넓히는 경우에는 동의 정책이 더 낫다고 할 수 없다. 예를 들어 세 방법 동의 + 여유 폭 0.10은 성공 5,869건·잘못 승인 250건인 반면 공분산 단독 + 여유 폭 0.20은 성공 **5,885건**·잘못 승인 **215건**이다. 전체 20개 동의 정책·여유 폭 조합 중 5개는 시험한 단일 예측기·고정 여유 폭 조합에 성공과 잘못 승인 양쪽에서 뒤진다. 이 비교는 **사후 설명용**이다. 대상 실측을 보고 특정 여유 폭을 선택하면 배포 정책 학습에 데이터가 누출된다.

저장된 다른 모델의 외부 분할 예측을 그대로 가져와 대상 모델용 여유 폭을 학습하는 것도 안전하지 않다. 다른 모델을 제외해 만들었던 예측기에는 지금의 대상 모델 측정값이 학습 자료로 들어갔기 때문이다. 엄밀한 여유 폭 학습에는 각 대상 모델을 뺀 상태에서 훈련 모델끼리 다시 교차 검증한 예측이 필요하다. 이번 평가는 여유 폭을 학습하지 않았다.

## 판단

예측기 일치는 추가 측정 없이 승인을 보수화한다. 하지만 공분산 단독에 여유 폭을 두는 간단한 방법과 비교한 이득은 모델별로 불안정하고, 실제 사용자 SLO가 없다. 따라서 기존 자료만으로는 이를 새로운 추론 최적화 알고리즘의 효과로 주장하기 어렵다. 세 예측기를 모두 계산하는 운영·계산 비용도 이번 GPU 측정 비용 비교에는 넣지 않았다.
