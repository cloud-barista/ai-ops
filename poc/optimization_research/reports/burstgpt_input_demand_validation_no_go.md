# BurstGPT 대화 로그의 1시간 입력 토큰 수요: 검증 단계 미채택

2026-09-28. 경희대의 응용 요구사항 분석에 쓸 **기록된 요청의 미래 입력 토큰량**을 예측했다. [점수 전 규약](burstgpt_input_demand_protocol.md), [평가 코드](../scripts/evaluate_burstgpt_input_demand.py), [합성 테스트](../tests/test_burstgpt_input_demand.py)를 먼저 동결하고 학습·검증 단계만 한 번 실행했다. **학습기는 검증 pinball 손실을 줄였지만 두 집단 모두 사전 피복률 85% 기준을 통과하지 못해 미채택**이다. 상대일 285–334의 시간별 시험 정답·예측·손실은 계산하지 않았다.

## 자료·시점·지원량

저자 공개 `BurstGPT_3.csv` (`../data/external/burstgpt_v2/BurstGPT_3.csv`)의 SHA256은 `2299986a07388aa303ec2c41d1131e756db650a39ed6ef9dfe7cc3d7f9a43b8f`이다. 시간은 **추적 상대 초**이며 실제 UTC 날짜나 요일이 아니다. 두 `Conversation log` 집단(`ChatGPT`, `GPT-4`)에서 매시 시작 시점에 해당 시간의 기록된 `Request tokens` 합계를 예측했다. 데이터에 실제 집계 게시 시각이 없어 추가 1시간 지연을 가정했고, 특징은 가장 최근에도 `h−2` 시간칸까지만 썼다. 피드백 가용 조건 `h+2≤검증 시작`을 적용한 학습 표본은 집단당 **934시간**, 검증은 집단당 **480시간**이다.

동결 manifest SHA256은 `0f4c6ba50ecf1de7b3117330bc6da57b90c8c203ec2f17021ad967a4c9e6ce38`이다. [점수 전 지원량 JSON](../artifacts/burstgpt_input_demand_v1/preperiod_support.json)의 SHA256은 `39df68c44b50eb5090679fee192622a48d9736797315f4366a700b01c12e7af5`다. 원본은 상대일 285의 첫 행에서 해석을 중단했고, 그 전 **3,452,522행**만 파싱했다. 지원량 게이트는 모두 통과했다.

| 집단 | 학습 40일 요청 / 기록 있는 시간 | 검증 20일 요청 / 기록 있는 시간 | 기록된 0토큰 요청, 학습 / 검증 |
| --- | ---: | ---: | ---: |
| ChatGPT 대화 | 35,700 / 836·960 (87.1%) | 22,508 / 439·480 (91.5%) | 472 / 85 |
| GPT-4 대화 | 17,726 / 848·960 (88.3%) | 11,725 / 435·480 (90.6%) | 329 / 140 |

위에서 요청이 없는 시간의 합계 0은 **로그에 기록된 요청 0건**이다. 원본에는 수집기 heartbeat가 없어 실제 무부하와 기록 공백을 구분할 수 없다. 0토큰 요청은 요청 수 1건·토큰 합계 0으로 보존했다.

## 검증 결과와 사전 게이트

집단별 고정 90백분위, 마지막 가용 시간과 전날 같은 시간에 학습 잔차 90백분위를 더한 기준선, 직전 24시간 경험적 90백분위를 비교했다. 검증 20일의 두 집단 동일 가중 pinball 손실이 가장 낮은 기준선은 **전날 같은 시간+학습 잔차**였다. 단위는 **기록된 입력 토큰**이며 낮을수록 좋다.

| 방법 | 두 집단 동일 가중 pinball | ChatGPT pinball / 피복률 | GPT-4 pinball / 피복률 |
| --- | ---: | ---: | ---: |
| 학습 고정 p90 | 8,649.378 | 8,831.226 / 84.58% | 8,467.530 / 81.88% |
| 마지막 가용 시간+잔차 p90 | 8,085.479 | 8,647.296 / 86.46% | 7,523.662 / 86.88% |
| **검증 선택: 전날 같은 시간+잔차 p90** | **6,901.853** | 6,558.179 / 88.96% | 7,245.526 / 83.54% |
| 최근 24시간 p90 | 8,258.882 | 8,517.715 / 88.96% | 8,000.049 / 87.08% |
| **집단별 학습 분위수 HGB** | **6,180.628** | **5,757.765 / 84.17%** | **6,603.491 / 81.46%** |

학습기의 동일 가중 손실은 선택 기준선보다 **10.45% 낮고**, ChatGPT/GPT-4 각각 **12.20%/8.86% 낮았다**. 동일 가중 일자별 손실도 **17/20일**에 더 낮았다. 따라서 사전 손실·집단별 우세·일자 우세 조건은 충족했다. 그러나 상한의 실제 피복률은 ChatGPT **404/480=84.17%**, GPT-4 **391/480=81.46%**로 **각 집단 85% 이상** 조건에 모두 미달했다. 네 사전 채택 조건 중 하나가 실패해 **전체 판정은 NO-GO**다. 선택 기준선도 GPT-4에서 83.54%에 그쳐 운영용 p90 상한이라고 볼 수 없다. 검증을 보고 여유값을 추가하거나 모델을 재적합하지 않았다.

## 재현성과 적용 범위

[검증 지표](../artifacts/burstgpt_input_demand_v1/validation_metrics.json) SHA256 `74ab536413e920df44d27d3d67f2d2b2f6e732fd647a8e64aa83fd9e60d42931`, 검증 960행의 예측 (`../artifacts/burstgpt_input_demand_v1/validation_predictions.csv`) SHA256 `b856d3dcc5e6a407a92caf054e282fba5d6b7416fb3b4609e427b2440f02a8b2`, 학습 전용 모델 (`../artifacts/burstgpt_input_demand_v1/train_models.joblib`) SHA256 `4716e0c7acef3302a9259a7236dd5a64f94864fa95e67195a80e915b35a08093`이다. 저장된 960행을 별도로 읽어 다섯 방법의 집단별 pinball·피복률이 보고 JSON과 일치함을 확인했다. 합성 테스트 **9개**와 독립 정적 코드 검토가 점수 전 통과했다. 재현 명령은 아래와 같으나, 기존 산출물 덮어쓰기 방지 때문에 새 실행은 별도 작업 폴더가 필요하다.

```bash
python3 scripts/evaluate_burstgpt_input_demand.py freeze
python3 scripts/evaluate_burstgpt_input_demand.py select
python3 -m pytest -q tests/test_burstgpt_input_demand.py
```

기존 자료 감사가 시험일별 요청 수를 이미 공개했고, 규약 초안 뒤 출처 점검에서 상대일 334의 원시 두 행이 우연히 노출됐다(ChatGPT 대화 700 입력 토큰, GPT-4 API 1,386 입력 토큰). 방법 선택에는 쓰지 않았지만 **완전 미개봉 시험**이라고 부르지 않는다. 이번에는 시간별 시험 정답을 구성하지 않았고, 규약의 검증 실패 조건에 따라 별도 시험 채점기를 만들지 않는다.

이 결과는 같은 공개 로그의 **기록된 입력 토큰량**에 한정된다. 요청 완료 토큰, 실제 GPU 처리량·자원 배정, 사용자 지연 SLO, VM 생성·삭제와 후속 결과가 없으므로 필요한 GPU 수·VM 형상이나 `SCALE_OUT/IN` 효과로 변환하지 않는다. 피복률을 개선하는 새 규칙은 이번 검증 결과를 본 뒤의 후속 탐색으로 취급하고, 별도 평가 자료 없이 운영 판단에 채택하지 않는다.
