# Argonne vLLM 형상별 지연 전이: 점수 전 규약

2026-09-29. 이 규약은 `poc/optimization_research/artifacts/argonne_vllm_audit_v1/audit.json`의 집계·원본 구조만 확인한 뒤, 새 전이 모델의 점수를 열기 전에 고정한다. KHU SQLite 또는 다른 공개 출처의 행을 결합하지 않는다.

## 질문과 분석 집단

Argonne의 vLLM 벤치마크에서 **한 새 모델의 같은 길이·배치 작업을 한 가속기 형상으로 측정**했다면, 이미 카탈로그에 존재하고 같은 작업에서 관측된 다른 가속기/개수의 지연을 예측할 수 있는가? 이는 형상별 벤치마크 지연 예측이다. VM 적합성, 실패/OOM, 가격, 사용자 SLO, 스케일 조치 결과는 정답이 아니다.

고정 CSV SHA-256은 `631a12e08c786ce2d4bdfdc0f67b93234360682cb4b36c93806270ddcfd58412`이다. 공식 논문의 배치 격자 `{1,16,32,64}`의 vLLM만 쓰고 `(모델, 길이, 배치, 하드웨어 이름, 하드웨어 수)` 중복 키의 **모든 행**을 제외한다. 서로 다른 하드웨어 이름이 2개 이상인 `(모델, 길이, 배치)`만 남기고, 이런 작업이 9개 이상인 모델 9개를 주 집단으로 고정한다. 감사 결과 169작업·1,567행이다. `Throughput`은 vLLM에서 `배치 × (입력+출력 토큰 수)/Latency`의 계산값이므로 독립 학습 정답으로 쓰지 않는다. 지연의 단위는 원본 값 그대로 두고 로그오차를 평가한다.

각 작업의 앵커는 **하드웨어 수 오름차순, 하드웨어 이름 사전순** 첫 관측 형상이다. 나머지 행이 예측 대상이다. 앵커 선정에 지연값을 쓰지 않는다. 사용 가능한 형상 목록 자체는 원본의 관측 성공 형상만 포함하므로, 예측은 미관측 형상이나 실패 형상을 다루지 않는다. 앵커 지연은 테스트 시 측정 1회 비용으로 제공한다.

## 분할·특징·방법

9회 모델 전체 제외 평가를 한다. 각 회의 학습은 나머지 8개 모델의 작업만 사용하며, 각 모델의 모든 길이·배치·하드웨어 결과는 시험 폴드 밖으로 뺀다. 원본 `Model` 문자열을 학습 특징에 넣지 않는다. 단, 이름에 명시된 명목 크기(B)를 사전에 고정해 쓴다: DeciLM-7B=7, Qwen2-7B=7, Qwen2-72B=72, Llama-2-7b=7, Llama-2-70b=70, Meta-Llama-3-8B=8, Meta-Llama-3-70B=70, Mistral-7B=7, Mixtral-8x7B=47. Mixtral의 47B는 이름의 곱셈값이 아니라 대략적인 총 파라미터 규모를 표현하기 위한 고정 근사치이며 실제 로드 메모리나 정확 파라미터 정답으로 쓰지 않는다. 숫자 특징은 `log2(크기)`, `log2(입출력 길이)`, `log2(배치)`, `log2(하드웨어 수)`이고, 하드웨어 이름은 원본 7종을 정렬한 고정 one-hot으로 표현한다. 전처리의 범주는 형상 목록만 참조하고 목표 지연은 참조하지 않는다.

같은 ExtraTreesRegressor(`n_estimators=160`, `min_samples_leaf=2`, `random_state=42`, `n_jobs=1`)를 다음 두 가지로 학습하며 정답은 `log(Latency)`이다.

1. **직접 회귀:** 대상 형상, 모델 크기, 길이, 배치만 사용한다. 앵커도 이 모델로 예측한다.
2. **앵커 조건 회귀:** 같은 특징에 앵커 형상 one-hot·개수와 `log(앵커 관측 지연)`을 더해 학습한다. 학습 폴드에서도 작업별 동일한 결정적 앵커를 제공한다. 따라서 앵커 비용은 비교 대상과 같다.

연구 후보 **앵커 잔차 보정**은 직접 회귀의 대상 로그 예측에 `log(앵커 관측 지연) - 직접 회귀의 앵커 로그 예측`을 더한다. 단순 비교기는 모든 대상에 앵커 관측 지연을 복사한다. 모든 방법의 대상 행과 앵커 선정은 동일하며, 직접 회귀가 쓰지 않는 앵커를 숨겨 유리하게 취급하지 않는다.

## 지표·성공 조건

주 지표는 각 대상의 `abs(log(예측 지연)-log(관측 지연))` 평균(MALE)을 모델별로 낸 뒤 **9개 모델 동일 가중 평균**한 값이다. 보조 지표는 전체 대상 행의 MALE와 앵커 대비 빠름/느림 방향 정확도다. 동률은 방향 오답으로 센다. 모델별 대상 수와 손실을 모두 저장한다.

앵커 잔차 보정을 **연구 후보 GO**로 기록할 필요조건은 다음을 모두 만족하는 것이다: (a) 모델 동일가중 MALE이 세 비교기 각각보다 최소 5% 낮음, (b) 앵커 조건 회귀보다 낮은 모델이 최소 6/9개, (c) 앵커 조건 회귀보다 전체 방향 정확도가 낮지 않음. 하나라도 실패하면 **미채택**한다. 단순 기준선·앵커 조건 회귀의 점수 자체가 좋더라도 이를 실제 배포 추천으로 승격하지 않는다. 같은 원본 안의 모델 분할이며 다른 연구에서 이미 Argonne 데이터를 설계에 참고했으므로 학술적 독립 검증이나 새로운 기법의 우월성으로 주장하지 않는다.

구현은 원본·적격 CSV 해시와 9개 모델·169작업·1,567행 구조를 재검사하고, 폴드별 행 예측과 집계 JSON을 남긴다. 평가 전에 코드 계약 테스트로 중복 제거, 앵커 선정과 대상 지연 누출 방지를 확인한다. 모델 적합 후에는 위 규약과 다른 기준을 채택 판단에 적용하지 않는다.
