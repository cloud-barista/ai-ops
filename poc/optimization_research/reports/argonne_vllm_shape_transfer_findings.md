# Argonne vLLM의 새 모델 가속기 형상 지연 전이

2026-09-29. [점수 전 규약](argonne_vllm_shape_transfer_protocol.md)대로 고정 원본을 감사하고 모델 전체 제외 학습을 실행했다. **결론: 앵커 잔차 보정은 미채택(`DO_NOT_ADOPT`).** 모델 동일가중 오차에서는 앵커 조건 회귀보다 낮지만, 9개 모델 중 3개에서만 이기고 형상 간 빠름/느림 판별도 낮아 사전 성공 조건을 충족하지 못했다. 이 데이터로 실제 최소 GPU/VM 형상, 실패/OOM, 사용자 SLO 또는 `SCALE_OUT/IN` 효과를 학습할 수는 없다.

## 원본과 학습 가능한 정답

[Argonne 공식 CSV](https://github.com/argonne-lcf/LLM-Inference-Bench/blob/4211f5d4e9bc0145ed541b6d372d5d8223b44235/Plots/All_results.csv)와 [논문](https://arxiv.org/html/2411.00136v1)을 고정했다. [출처·라이선스·해시](../data/external/argonne_llm_inference_bench/SOURCE.md)와 [자동 감사](../artifacts/argonne_vllm_audit_v1/audit.json)에 원본 4,772행, 15모델, 6프레임워크, 23개 하드웨어 이름×개수 형상을 기록했다. 이 실험에서는 vLLM과 논문의 배치 격자만 사용했다. 작업·형상이 같은데 실행 ID 없이 두 번 나타난 57키/114행을 **모두 제외**하고, 하드웨어 이름 2종 이상이 관측된 작업을 골랐다. 최종 주 집단은 **9모델, 169개 `(모델, 길이, 배치)` 작업, 1,567행**이다. 각 작업에 하나의 결정적 앵커를 선택하여 나머지 **1,398행**의 지연을 예측했다.

vLLM의 `Throughput` 2,067행은 모두 논문식 `배치 × (입력+출력 토큰) / Latency`와 일치했다. 따라서 처리량을 독립적인 두 번째 정답으로 학습하지 않았다. `llama.cpp`의 1,161/1,570행은 이 식과 다르므로 프레임워크 사이의 처리량을 같은 정의로 합치지 않았다. 원본에는 구성별 실패/OOM, VM 요금·생성/Ready, 사용자 요청별 지연이나 실제 조치 사건이 없다. 기록되지 않은 형상을 실패로 표시하지 않았다.

## 모델 전체 제외 결과

원본 모델 이름에서 읽은 명목 크기, 입출력 길이·배치, 가속기 이름·개수로 직접 ExtraTrees를 학습했다. 같은 작업에서 형상 수가 가장 작고 이름이 사전순인 형상을 앵커로 골랐다. 연구 후보는 직접 모델의 앵커 예측 오차를 대상 형상 예측에 더하는 **앵커 잔차 보정**이다. 강한 비교기는 동일한 앵커 실측 지연과 앵커 형상을 특징으로 직접 학습하는 ExtraTrees다. 모두 모델 9개를 하나씩 완전히 뺀 학습·평가이며, 평가 대상의 관측 지연은 특징에 들어가지 않는다.

| 방법 | 모델 동일가중 MALE ↓ | 1,398행 MALE ↓ | 앵커 대비 빠름/느림 정확도 ↑ |
| --- | ---: | ---: | ---: |
| 앵커 값 복사 | 0.7565 | 0.7466 | 0.0% |
| 직접 ExtraTrees | 0.1783 | 0.1788 | 93.78% |
| 앵커 조건 ExtraTrees | 0.1998 | **0.1517** | **95.92%** |
| 앵커 잔차 보정 | **0.1777** | 0.1957 | 95.14% |

MALE은 `|log(예측 지연)-log(관측 지연)|`의 평균이다. 모델 동일가중에서는 잔차 보정이 직접 회귀보다 **0.30%** 낮을 뿐, 사전 5% 조건에 못 미친다. 앵커 조건 회귀보다 모델 동일가중은 11.1% 낮지만, **모델별 승리 3/9**로 필요 6/9에 미달하며 방향 정확도도 0.79%p 낮다. 앵커 조건 회귀가 행 가중 오차에서 앞서지만 모든 모델에 안정적인 것은 아니다. 특히 Qwen2-72B에는 대상 행이 **9개뿐**이고, 앵커 조건 회귀 MALE은 `0.597`, 잔차 보정은 `0.020`이다. 소수 모델의 이득이 동일가중 평균을 끌어올린 면을 숨기지 않는다.

| 제외 모델 | 대상 행 | 직접 | 앵커 조건 | 잔차 보정 |
| --- | ---: | ---: | ---: | ---: |
| DeciLM-7B | 63 | 0.119 | 0.111 | **0.090** |
| Qwen2-72B | 9 | 0.042 | 0.597 | **0.020** |
| Qwen2-7B | 187 | **0.092** | 0.115 | 0.108 |
| Llama-2-70B | 124 | 0.142 | **0.130** | 0.253 |
| Llama-2-7B | 320 | 0.189 | **0.185** | 0.250 |
| Llama-3-70B | 119 | 0.143 | **0.130** | 0.274 |
| Llama-3-8B | 260 | **0.074** | 0.092 | 0.126 |
| Mistral-7B | 184 | **0.084** | 0.107 | 0.146 |
| Mixtral-8x7B | 132 | 0.719 | **0.331** | 0.334 |

형상 간 방향 정확도가 높아도 비용·메모리·실패 위험을 반영한 최적 형상을 골랐다는 뜻은 아니다. 원본은 이미 측정된 성공 형상만 평가해 선택 편향이 있다. 특히 Mixtral의 직접 회귀 오차가 큰 점과 모델별 잔차 보정의 반대 방향 결과 때문에, 다른 모델·장비의 안전성을 일반화하지 않는다.

## 재현

`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 /usr/bin/python poc/optimization_research/scripts/evaluate_argonne_vllm_transfer.py`로 [폴드·모델별 점수](../artifacts/argonne_vllm_transfer_v1/results.json)와 1,398행 예측 (`../artifacts/argonne_vllm_transfer_v1/held_model_predictions.csv`)을 만든다. 원본·적격 행·규약·코드의 SHA-256을 결과에 기록한다. `python -m unittest discover -s poc/optimization_research/tests -p 'test_evaluate_argonne_vllm_transfer.py' -v`의 **3개 계약 테스트**가 통과했다. 테스트는 지연값과 무관한 앵커 선택, 대상 지연이 특징에 들어가지 않음, 중복 형상 거절을 확인한다.

이 음성 결과 이후 같은 평가 행으로 방법이나 채택 문턱을 바꾸면 독립 확인이 아니다. 직접 회귀는 **이 공개 벤치마크 안의 관측 형상**에 관한 후속 비교 기준선으로만 남긴다. 새 앱의 배포 형상을 실제로 승인하려면 모델·가속기별 실행 성공/OOM, 메모리 제한, 요청 지연, 실제 사용자 SLO, 가격 및 대체 형상 관측이 필요하다.
