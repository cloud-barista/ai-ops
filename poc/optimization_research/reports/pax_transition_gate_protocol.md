# PAX 온라인 노드 전환의 전후 관측 적격성 게이트: 사전 규칙

고정일: 2026-09-28. 이 문서는 전환·창·클라이언트 안정성 건수를 계산하기 **전**에 작성한다. [공식 PAX 데이터](https://zenodo.org/records/1136276)의 README와 세 CSV의 경로·헤더·시각 형식만 확인했다. `results.csv`의 처리량·응답시간 값은 계산·비교하지 않는다. 이후 규칙 변경은 새로운 탐색 실험으로 표시한다.

## 관측 단위와 입력

- 원본은 `poc/optimization_research/data/external/pax_autoscale_feasibility/PAX.zip`이며 ZIP SHA-256은 `db15cfa75f05d44020a3f5c4f6f4930cbb1c2518dd3884391917615cea52a23a`이다. 공식 Zenodo 메타데이터의 크기는 1,307,826 B, MD5는 `56cf6c11f79e0cffadeb2414784a789b`이다. 구현에서 공식 MD5와 ZIP 무결성을 재검산한다.
- 같은 디렉터리에 `runningVMs.csv`, `results.csv`, `clients.csv` 세 파일이 있는 폴더만 한 실험으로 본다. `Add single node`에는 전환·클라이언트 CSV가 없으므로 제외한다. `Tracing impact`는 세 파일이 없어 제외한다. 폴더 간 데이터는 결합하지 않는다.
- README에서 `runningVMs.csv`는 온라인 Cassandra 노드 수, `results.csv`는 YCSB 측정, `clients.csv`는 YCSB 클라이언트 수다. `runningVMs.csv`는 헤더 없는 `날짜,시간,노드 수`; 나머지는 헤더가 있다. 코드가 `results.csv`에서 읽고 저장하는 필드는 **`datetime`뿐**이다. 시각대 정보가 없어 각 폴더 안에서만 단순 시각으로 비교한다.

## 전환·창 규칙

1. 각 실험의 온라인 노드 표본을 시각순으로 정렬한다. 동일 시각·동일 값의 중복만 하나로 줄이고, 같은 시각에 서로 다른 노드 수가 있거나 음수·비정수 값이 있으면 해당 실험을 제외한다. 인접 표본의 노드 수가 달라진 경우를 전환 후보로 센다. `t`는 **새 노드 수가 처음 관측된 시각**이며 조치 명령 시각이 아니다. 직전 표본과의 간격이 120초를 넘으면 전환 시각 불확실성으로 후보를 제외한다.
2. 전환마다 결과 시각의 전창 `[t-180초, t)`와 후창 `(t, t+180초]`를 사용한다. 정확히 `t`의 YCSB 표본은 구간 귀속이 불확실해 제외한다. 양쪽 창에 각각 서로 다른 결과 시각 **12개 이상**을 요구한다. 전창의 첫/끝 결과는 각각 `t-150초` 이전과 `t-30초` 이후, 후창의 첫/끝 결과는 각각 `t+30초` 이전과 `t+150초` 이후여야 한다. 한쪽 결과 시각 중복 또는 인접 간격 30초 초과는 그 창을 불완전으로 본다.
3. `[t-180초, t+180초]` 안에 다른 온라인 노드 전환이 있으면 해당 후보를 제외한다. 따라서 채택된 전후 창과 다른 전환이 겹치지 않는다. 단, 폴더 내 다른 채택 창끼리의 경계가 닿거나 겹치면 두 후보 모두 제외한다.
4. 클라이언트 CSV도 전후 창에 각각 시각이 다른 표본 **12개 이상** 있어야 한다. 전창 클라이언트 수의 중앙값 `m`이 1 이상이어야 한다. 전후 창 전체 클라이언트 수 각각이 `m`에서 **10% 이내** (`|c-m| <= 0.1*m`)이고, 후창 중앙값도 같은 범위 안이어야 한다. 동일 시각 충돌·음수·비정수 클라이언트 수는 해당 실험을 제외한다. 이 조건은 같은 수요 수준의 전후 관측을 걸러내는 적격성 조건이며, 숨은 수요 변화가 없었다는 증명은 아니다.

## 집계와 판정

- 전체 완전 실험 폴더 수, 시간 범위가 겹치는 폴더 쌍, 원시 전환 수와 방향, 직전 표본 간격 분포, 전환 간격의 최소·중앙값, 각 단계의 탈락 수, 최종 전환의 폴더별·방향별 수를 낸다. 같은 날짜라도 반복 실험인지 알 수 없으므로 **폴더는 기록 단위이지 독립 시행의 증거가 아니다**. 날짜/시간 범위 중첩 쌍을 별도 경고한다.
- **제한적 전후 관측 비교 GO**는 최종 적격 전환이 10개 이상, 3개 이상의 실험 폴더에 분포하고, 증가·감소 방향 각각 3개 이상이며, 시간 범위가 겹치는 두 폴더의 사례를 독립 표본으로 합산하지 않고도 이 조건이 성립할 때만 부여한다. 그렇지 않으면 NO-GO로 둔다. GO여도 조치 명령 시각, 미실행 대안, 사용자 SLO의 인과 효과나 AI-App GPU VM 확장을 검증한 것은 아니다.
- 본 게이트는 **자료 적격성**만 판단한다. 처리량·응답시간 전후 차이, 통계적 유의성, ML 성능, 정책 효과를 계산하지 않는다.
