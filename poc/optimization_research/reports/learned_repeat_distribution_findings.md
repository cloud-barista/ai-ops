# Donor 모델만으로 반복 측정 예측폭을 학습한 실험

## 결론

경희대의 **배포·제어 판단용 추론 신뢰도** 연구로, 같은 AI 응용·GPU 형상을 몇 차례 측정한 뒤 다음 배치 벤치마크 한 번의 p95 지연과 요청/초 분포를 예측하는 모델을 학습했다. 대상 모델을 완전히 제외한 다른 7모델에서 분산 결합 강도와 예측폭을 골랐다. 내부 CRPS 최적화는 외부 평가에서 지나치게 좁은 예측구간을 자주 만들었다. 별도의 내부 NLL 최적화는 극단적인 밀도 실패를 줄였지만, 고정 5 pseudo-count 수축 및 대상 셀 Student-t를 **일관되게 이기지 못했다.** 이 학습법을 실제 배포 판단에 채택할 근거는 없다.

학습 코드와 16개의 전체 이력 모델은 [코드](../scripts/learned_repeat_distribution.py)와 [학습 파라미터](../artifacts/learned_repeat_v1/trained_models.json)에 있다. 저장 모델은 수집기 버전·GPU 수·지표·초기 반복 횟수별 donor 로그분산, 선택된 pseudo-count, 폭 배수와 입력·출력 스키마를 포함한다. 이 모델은 같은 호스트와 고정 자원 셀의 **후속 배치 측정 분포**만 출력한다. 실제 사용자 지연 SLO, 배포 또는 Scale-out/in 결정을 출력하지 않는다.

## 학습과 검증

기존 SQLite 측정 스냅샷 (`../data/audit_v1/measurements.parquet`)의 `khu-hf-live` GPU 반복만 사용했다. 수집기 `v1`과 `v2`를 분리하고, 실행 시작 시각으로 회차를 정렬했다. `v1`의 `round-100`은 시간상 첫 회차이므로 run ID 숫자로 정렬하면 누출이 생긴다. 두 버전은 각 8모델·16자원 셀이며 외부 평가 전 43/27회, 외부 평가 20회다.

평가는 **`cutoff_last_k`만** 대상으로 했다. 대상 모델 1종의 43/27회 prefix 중 마지막 `k=2,5`회만 probe로 사용하고 마지막 20회를 미래 결과로 가렸다. 다른 7모델은 동일 prefix 전체를 학습 기록으로 사용한다. `immediate_first_k`에 이 방법을 적용하면 donor 내부 검증이 처음 k회 이후 자료를 읽게 되므로 그 시나리오에는 적용하지 않았다.

하이퍼파라미터 선택에도 대상 모델을 쓰지 않았다. 각 외부 분할의 7 donor를 하나씩 내부 검증 대상으로 삼았다. `v1` 내부 시점은 23회 뒤, `v2`는 7회 뒤다. 내부 대상의 시점 직전 k회로 평균·표본분산을 구하고, 나머지 6 donor의 내부 시점 **이전** 회차에서 GPU 수별 잔차분산을 구했다. 내부 시점 이후 20회로 CRPS 또는 NLL을 점수화했다. 선택된 설정은 외부 대상의 마지막 k회와 7 donor의 전체 prefix에 적용했다. 어느 단계에서도 외부 대상 모델의 다른 셀이나 미래 결과를 donor에 넣지 않았다. 내·외부 학습 실행 종료가 평가 시작보다 이른지도 검사한다. [누출·시간 검증 테스트](../tests/test_learned_repeat_distribution.py)

예측분포는 로그 성능의 정규분포다. 대상 셀의 k회 평균을 위치로 고정하고, `v=(λ×v_donor_GPU+(k−1)×v_local)/(λ+k−1)`의 분산을 사용한다. 예측 표준편차는 `sqrt(v×(1+1/k))×c`다. 내부 donor에서 `λ∈{0,1,2,5,10,20,50}`와 `c∈{0.75,1,1.25,1.5}`를 선택했다. **CRPS 최소화와 NLL 최소화를 별도 학습 방법**으로 평가했다. 전자는 최초 실험의 1차 방법이다. 후자는 전자의 외부 NLL 폭증을 본 뒤 추가했으므로, 두 방법 모두 탐색적 결과이고 후자는 사전 지정된 독립 검증이 아니다. 고정 5 수축, donor 분산 단독, 대상 표본분산 정규분포, 대상 Student-t를 **같은 외부 donor 이력·대상 k회 probe 비용**으로 비교했다. 평균은 셀의 미래 20회 → 모델 내부 셀 → 8모델 순서로 계산했다.

## 외부 결과

아래 CRPS는 로그 결과의 점수이며 작을수록 좋다. 요청/초는 벤치마크의 `examples_per_second / batch_size`다. 표의 지표가 서로 단위가 달라 지연과 요청/초의 점수를 직접 비교하지 않는다. 원자료는 전체 요약 (`../artifacts/learned_repeat_v1/summary.csv`), 모델별 점수 (`../artifacts/learned_repeat_v1/per_model.csv`), 모델 짝 비교 (`../artifacts/learned_repeat_v1/paired_comparisons.csv`)에 있다.

CRPS 하나만 낮춰 학습하면 donor 분산을 섞지 않는 `λ=0`, 폭 `c=0.75`가 자주 선택됐다. 수치 계산에는 로그 표준편차 `0.001`의 최소값이 적용된다. `v1·요청/초, k=2`에서 외부 평균 NLL은 고정 5의 `−0.798`에 비해 CRPS 학습법이 **`106.461`**로 크게 악화됐고, 90% 포함률은 `0.843→0.666`으로 하락했다. `v2·요청/초, k=2`도 NLL `−1.599→10.284`, 포함률 `0.911→0.700`이었다. NLL 학습법은 이 실패를 완화했으나, `v1·요청/초, k=2`에서는 CRPS `0.0504`로 좋아져도 NLL `−0.209`로 고정 5보다 나빴다. `v2·요청/초, k=5`에서는 NLL 학습법이 고정 5보다 CRPS `0.0255→0.0250`, NLL `−1.779→−1.870`으로 좋았지만 대상 Student-t의 NLL `−2.266`에는 못 미쳤다. NLL은 연속밀도의 단위 의존 점수라 음수도 정상이다.

같은 donor prefix를 기준으로 대상 모델당 평균 GPU-wall 비용은 v1 `k=2/5`에서 `8.61/21.59초`, v2에서 `9.47/23.49초`다. 모델 제외 donor 이력은 v1 평균 `1290.27초`, v2 `898.90초`/분할이다. GPU-wall은 실행시간에 GPU 복제 수를 곱해 합산했다. 고정 5와 학습법 모두 해당 donor 이력을 사용하며, 추가로 donor 측정을 수행한 실험은 아니다. 이 값은 이미 수집된 SQLite 자료의 재사용 비용을 반사실적으로 계산한 것이다. 측정 비용 표 (`../artifacts/learned_repeat_v1/cost_summary.csv`)

## 판정과 제한

이 실험에서 **학습 자체는 완료**됐고, 외부 모델 제외·시간 분할로 효과를 측정했다. 후속 실험의 기본 비교 대상으로는 고정 5 수축과 대상 Student-t를 유지한다. 새로운 donor 학습법은 계산량과 설정 복잡도를 늘렸으나 일관된 점수 이득이 없고 일부 밀도 점수가 극단적으로 나쁘므로 연구 후보로만 남긴다. 특히 CRPS만 최적화한 설정은 90% 예측구간을 요구하는 판단 인터페이스에 그대로 쓰면 안 된다.

자료는 한 호스트, 수집기 2개, 모델 8개, 고정 GPU 셀 16개다. 두 수집기는 독립된 새 호스트가 아니다. 같은 SQLite를 여러 차례 탐색했으므로 위 표는 별도 독립 검증이 아니다. 미래 20회는 상관된 반복이고 새 응용 등록, 새로운 인프라 형상, 실제 SLO, Scale-out/in 성공을 검증하지 않는다. 저장된 전체 이력 모델도 외부 fold 모델의 비교 점수를 그대로 갖는다고 주장하지 않는다. 경험적 분산 수축과 proper score의 원리는 기존 연구([Smyth 2004](https://www.math.tau.ac.il/~yekutiel/eBayes/smyth_2004.pdf), [Gneiting·Raftery 2007](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf))에 있으므로 이 식 자체의 학술적 최초성을 주장하지 않는다.
