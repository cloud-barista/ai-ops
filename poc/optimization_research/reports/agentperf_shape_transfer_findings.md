# AgentPerfBench 새 AI 모델 GPU 형상 성능 전이: 고정 규약 평가 결과

작성일: 2026-09-29. [점수 확인 전에 고정한 규약](agentperfbench_shape_transfer_protocol.md)을 그대로 구현했다. [공식 AgentPerfBench 데이터](https://huggingface.co/datasets/agent-perf-bench/AgentPerfBench/tree/722f2b9d8a6acd222811f4e210a96865f774f6ee)를 KHU SQLite와 합치지 않은 **별도 LLM 서빙 도메인** 실험이다. 데이터 고정 revision `722f2b9d8a6acd222811f4e210a96865f774f6ee`, `trace_replay/summary.parquet` SHA-256 `568efbdae473a830ba792317fb09cfba0ea4f667db67b93d28e72637a5c71d1e`. 실행 코드는 [`scripts/evaluate_agentperf_shape_transfer.py`](../scripts/evaluate_agentperf_shape_transfer.py), 전 결과와 후보행 예측은 [`artifacts/agentperf_shape_transfer_v1/`](../artifacts/agentperf_shape_transfer_v1/)에 있다.

## 결론

**형상비 ExtraTrees 전이는 채택하지 않는다 (`do_not_adopt`).** 모델 9개를 하나씩 통째로 제외했을 때, 가장 강한 기준선인 직접 ExtraTrees의 모델 균등 MALE은 p90 end-to-end 지연 `0.4523`, 요청/s `0.3653`이다. 형상비 ExtraTrees는 각각 `0.6604`, `0.5406`으로 두 지표 모두 나빴다. 사전 고정한 채택 항목 17개 중 5개만 통과했다. 직접 회귀는 이 **관측된 형상과 공개 벤치마크 조건에서** 후속 연구 기준선으로 남길 만하지만, 사용자 SLO 승인·미관측 형상 추천·VM 배포/스케일 판단의 검증 결과는 아니다.

## 데이터와 평가 설계

원본 2,932행에서 지표가 0이거나 비유한 36행, 일부 요청 실패가 역산된 724행을 제외해 2,172행이 남았다. 같은 `(model, engine, profile, concurrency, num_requests)`에 두 형상 이상 있는 묶음은 551개/1,734행이다. 동일 실행 입력 토큰 총량 최대/최소 `≤1.00001`, 출력 토큰 총량 `≤1.05`를 적용한 **주 분석**은 485묶음/1,526행이다. 각 묶음의 GPU 개수가 최소이고 기종 순서가 `2080Ti→3090→A100-40GB→H100`으로 가장 앞선 관측 형상을 앵커로 고정해, 나머지 1,041 후보행을 예측했다. 모든 방법에 앵커 1회 실측값을 동일하게 제공했다. 후보의 결과는 집단 선별과 정답·후향적 제약에만 썼고 예측 특징에는 넣지 않았다.

모델 ID는 분할 키로만 사용했다. 입력 특징은 공개 모델명에서 읽은 명목 크기, 모델 계열, 엔진, 프로필, 동시성, 요청 수, 앵커/목표 GPU 기종·수, 앵커 지연·요청/s다. 각 학습 fold에서만 결측 보정과 범주 인코딩을 적합했다. 9개 모델 제외 fold 외에 4개 계열 제외 fold를 별도 평가했다. `gpt-oss-120b`의 주 평가 후보는 **6행뿐**이므로 그 fold의 불확실성이 크다. 원자료의 미측정·실패 형상을 성공/실패 정답으로 만들지 않았다.

## 모델별 완전 제외 결과

MALE은 예측 로그 성능과 관측 로그 성능의 절대 차이 평균이며 **낮을수록 좋다**. 우선 표는 9개 모델의 MALE을 같은 가중치로 평균한다.

| 방법 | p90 지연 MALE | 요청/s MALE | p90 방향 적중률 | 요청/s 방향 적중률 |
|---|---:|---:|---:|---:|
| 앵커 복사 | 0.7798 | 0.7055 | 0.000 | 0.000 |
| donor 형상비 중앙값 | 0.6918 | 0.6347 | 0.698 | 0.704 |
| **직접 ExtraTrees** | **0.4523** | **0.3653** | **0.817** | **0.828** |
| 형상비 ExtraTrees | 0.6604 | 0.5406 | 0.687 | 0.734 |

앵커 복사는 변화 방향을 항상 `0`으로 예측하므로 방향 적중률이 0이다. 후보행 가중 MALE도 직접 회귀 `0.5001`/`0.4184`가 형상비 전이 `0.7738`/`0.6353`보다 낮다. 모델별 세부 값과 분할별 학습/평가 모델 명단은 [`summary.json`](../artifacts/agentperf_shape_transfer_v1/summary.json)에 있다.

| 제외 모델 | 후보행 | 직접 p90 | 형상비 p90 | 직접 요청/s | 형상비 요청/s |
|---|---:|---:|---:|---:|---:|
| Llama-3.1-70B | 97 | 0.378 | 0.453 | 0.369 | 0.405 |
| Llama-3.1-8B | 362 | 0.721 | 1.311 | 0.582 | 1.200 |
| Llama-3.3-70B | 45 | 0.076 | 0.070 | 0.139 | 0.080 |
| Mixtral-8x7B | 50 | 0.515 | 0.923 | 0.328 | 0.980 |
| Qwen2.5-72B | 45 | 0.164 | 0.409 | 0.156 | 0.260 |
| Qwen3.5-27B | 24 | 0.512 | 0.359 | 0.242 | 0.343 |
| Qwen3.5-9B | 310 | 0.370 | 0.541 | 0.340 | 0.247 |
| gpt-oss-120b | 6 | 0.800 | 1.548 | 0.700 | 1.034 |
| gpt-oss-20b | 102 | 0.535 | 0.330 | 0.431 | 0.317 |

형상비 전이는 donor 중앙값을 p90에서 5/9모델, 요청/s에서 6/9모델 이겼다. 직접 ExtraTrees를 이긴 모델은 두 지표 각각 **3/9**뿐이다. 모델 균등 MALE에서 직접 회귀보다 개선되어야 하는 5% 기준도 양쪽 모두 통과하지 못했다.

## 계열 제외·합성 후보 선택

| 제외 계열 | 직접 p90 | 형상비 p90 | 직접 요청/s | 형상비 요청/s |
|---|---:|---:|---:|---:|
| gpt-oss | 0.606 | 0.441 | 0.471 | 0.466 |
| llama | 0.547 | 0.632 | 0.492 | 0.575 |
| mixtral | 0.515 | 0.923 | 0.328 | 0.980 |
| qwen | 0.381 | 0.478 | 0.316 | 0.249 |

형상비 전이는 llama·mixtral 계열의 두 지표와 qwen의 p90 지연에서 직접 회귀보다 10%를 넘게 악화했다. `mixtral`은 원본에서 단일 모델 계열이므로 계열 제외와 해당 모델 제외가 같다.

같은 GPU 기종 안에 GPU 개수 후보가 2개 이상 있는 부분그룹은 510개/후보 형상 1,204행이며 **7개 모델만** 지원한다. `Qwen3.5-27B`와 `gpt-oss-120b`에는 이 보조 검사의 조건부 후보군이 없다. 각 부분그룹의 **관측 후보 로그 지연·로그 요청/s 중앙값**으로 후향적 합성 제약을 만든 뒤, 예측상 두 제약을 만족하는 최소 GPU 개수를 고른 결과다. 로그 중앙값은 후보 수가 짝수일 때 원값의 기하 중앙에 해당한다. 이 제약은 테스트 결과에서 만들었으므로 실제 사용자 SLO·운영 승인 성능으로 해석할 수 없다.

이 합성 제약을 실제로 충족하는 관측 후보가 있는 부분그룹은 **506/510개**이고, 4개는 어느 후보도 두 조건을 동시에 만족하지 않는다.

| 방법 | 510건 중 선택 | 실제 두 제약 모두 충족 | 거짓 승인 | 선택 없음 |
|---|---:|---:|---:|---:|
| 앵커 복사 | 113 | 75 | 38 | 397 |
| donor 중앙값 | 378 | 311 | 67 | 132 |
| 직접 ExtraTrees | 269 | 236 | **33** | 241 |
| 형상비 ExtraTrees | 347 | 297 | **50** | 163 |

형상비 전이의 거짓 승인은 직접 회귀보다 17건 많아 채택 기준을 통과하지 못했다. 방법별 선택 빈도가 다르므로 이 표만으로 어느 방법의 운영상 위험이 낮다고 비교할 수 없다.

점수 전 규약의 `실제 후보의 중앙값`은 로그 공간/원 단위 중 어느 척도인지 모호하다. 위의 로그 중앙값을 주 정의로 두고, **원 단위 관측값의 중앙값**을 문턱으로 쓰는 사후 해석 민감도를 별도로 계산했다. 직접 회귀는 267건 선택·33건 거짓 승인, 형상비 전이는 344건 선택·51건 거짓 승인으로 채택 결론이 같다. 원 단위에서는 원본 관측값으로 중앙값과 실제 충족 여부를 비교하며, `primary_synthetic_raw_median_sensitivity.csv` (`../artifacts/agentperf_shape_transfer_v1/primary_synthetic_raw_median_sensitivity.csv`)에 사례별 결과를 남겼다.

## 고정 민감도 평가

주 분석 외에 원래 정한 두 집단만 확인했다. 두 평가도 동일한 9개 모델 제외 분할·방법·하이퍼파라미터를 유지했다. 출력 토큰 총량 1%에서는 입력 기준 `1.00001`을 유지하고 출력 기준만 `1.01`로 좁혔다.

| 집단 | 묶음/행/후보행 | 직접 p90 | 형상비 p90 | 직접 요청/s | 형상비 요청/s |
|---|---:|---:|---:|---:|---:|
| 주 분석: 입력 `1.00001`, 출력 `1.05` | 485 / 1,526 / 1,041 | **0.452** | 0.660 | **0.365** | 0.541 |
| 출력 토큰 1% | 295 / 869 / 574 | **0.415** | 0.604 | **0.384** | 0.623 |
| 토큰 총량 제한 없음 | 551 / 1,734 / 1,183 | **0.404** | 0.574 | **0.368** | 0.422 |

모든 집단에서 직접 ExtraTrees가 형상비 ExtraTrees보다 두 지표의 모델 균등 오류가 낮다. 토큰 총량 제한을 없애면 다른 수의 출력 토큰을 생성한 실행도 같은 조건으로 비교하게 되어 해당 점수의 해석이 더 약해진다.

## 검증과 적용 한계

재현 명령: `python scripts/evaluate_agentperf_shape_transfer.py`; 계약 검증: `python -m unittest discover -s tests -p 'test_evaluate_agentperf_shape_transfer.py' -v` (**7개 통과**). 스크립트는 원본 SHA와 주 집단 485묶음/1,526행을 확인하고, 각 집단의 모델 제외 후보행 예측 CSV, 주 집단의 계열 제외 예측 및 합성 선택 CSV, 분할 명단과 점수를 `summary.json`에 저장한다. 테스트는 원본 변조 차단, 정해진 표본, 목표 결과의 특징 누출 방지, 모델/계열 분할, 앵커 선택, 후향적 선택 계산을 점검한다.

이 데이터는 성공률 75% 미만 실행이 공개 전에 제거됐고, 여기서는 성공률 100% 실행만 평가했다. 동일 조건·형상 반복 측정이 없고, 가격·CPU/RAM·실제 사용자 SLO·VM 생성/Ready·배포/스케일 조치 결과가 없다. 따라서 성공 표본으로 제한된 **관측 형상 사이의 벤치마크 성능 예측** 결과다. 직접 ExtraTrees도 이 범위를 넘어 자동 승인 또는 스케일 정책으로 연결하려면 별도 자료와 검증이 필요하다.
