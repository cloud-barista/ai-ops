# 공개 조치→Ready→사용자 결과 자료 추가 점검

2026-09-29. [기존 공개 자료 감사](public_scale_action_dataset_audit.md)와 [사건 데이터 계약](scale_effect_data_contract_v1.md)에 없는 원본 두 개를 확인했다. 적격 기준은 **같은 실행·응용에서 실제 조치 발행 시각, 적용/Ready 시각, 조치 전후의 요청별 성공·지연 또는 사용자 SLO 결과를 연결할 수 있는가**이다. 정책이 계산한 희망 replica, 관측 replica 수, 초 단위 집계 P95를 각각 명령·Ready·개별 요청의 대체값으로 사용하지 않는다. 이번 점검은 웹 공개 원본과 저장소 설명을 읽었으며, 데이터 다운로드와 새 모델 학습은 하지 않았다.

| 후보와 공개 원본 | 확인한 스키마·파일·접근성 | 엄격한 접합 판정 |
| --- | --- | --- |
| [InferScale 공식 저장소](https://github.com/wenhug/inferscale), [실제 `loadgen.log` 예](https://github.com/wenhug/inferscale/blob/main/experiments/data/ramp/inferscale-1/loadgen.log) | AI 추론 AKS 실험의 공개 텍스트 로그 한 건은 **363행·15.3 KB**이고 `[0s] qps= 2 ok=2/2 P50=641ms P95=641ms` 같은 초 단위 부하·성공 수·지연 분위수 행을 포함한다. [재현 코드](https://github.com/wenhug/inferscale/blob/main/experiments/reproduce.py)는 `experiments/data/ramp/{정책}-{반복}/loadgen.log`와 `multitenant/.../loadgen.log`를 읽어 SLO 충족률을 계산한다. [실험 설명](https://github.com/wenhug/inferscale/blob/main/experiments/README.md)과 [출처 설명](https://github.com/wenhug/inferscale/blob/main/docs/provenance.md)은 공개물이 역사적 로그의 작은 부분집합이며 대형 controller 로그·cluster dump는 제외한다고 명시한다. | **NO-GO.** 부하 생성기의 **초 단위 SLO 집계**는 공개됐지만 조치 발행/ID, Pod Ready 원본, 요청별 결과가 이 묶음에 없다. 다른 반복·정책 로그의 P95 차이를 개별 조치 효과로 학습할 수 없다. 초 단위 SLO 산술 검증에는 사용 가능하다. |
| [Sinan-GCP 저자 저장소](https://github.com/zyqCSL/sinan-gcp), [실험 주 프로그램](https://github.com/zyqCSL/sinan-gcp/blob/master/master_deploy_social.py) | [README](https://github.com/zyqCSL/sinan-gcp#usage)는 GCE에서 SocialNetwork 실험을 실행한 뒤 master node의 `logs/deploy_data`에 실행 로그를 생성·수집한다고 설명한다. 프로그램에는 `ScaleDecLog`, `ActionLog`, `Feature.time`, 관측/예정 replica, CPU limit, end-to-end latency, RPS, 실패 수가 있고, [분석 코드](https://github.com/zyqCSL/sinan-gcp/blob/master/data_proc/plot.py)는 `rps.txt`, `e2e_lat_99.0.txt`, 서비스별 `cpu_limit_*.txt`를 읽는다. 따라서 **코드와 생성 형식은 공개 접근 가능**하다. 웹에서 같은 실행의 실제 원시 조치·Ready·요청 결과 파일 묶음은 확인하지 못했다. | **NO-GO (현재 공개 확인 범위).** 리소스 조정과 SLO 연구의 재현 절차이지, 계약을 충족한다고 확인된 원본 데이터셋이 아니다. CPU limit/replica 계측에는 발행 조치 ID·성공/실패·Ready 시각이 필요하고, p99 시계열은 요청별 완료 로그가 아니다. 공개 원시 실행 로그의 경로·파일 목록과 접합률을 확인하기 전에는 학습 정답으로 쓰지 않는다. |

**결론:** 새로 확인한 두 후보 모두 현재 공개 아티팩트만으로 `action issued → applied/Ready → 전후 요청별 사용자 결과`를 연결하지 못한다. InferScale은 공개된 실제 AI 추론 SLO 집계의 작은 검산 자료이고, Sinan은 자원 조정 실험을 재현하는 코드·로그 형식 참고 자료다. 경희대 `DEPLOY/UPDATE/SCALE_OUT/SCALE_IN` 지도학습 및 정책 효과 검증은 [사건 데이터 계약](scale_effect_data_contract_v1.md)의 동일 `app_id`/`deployment_id`/`decision_id`/`action_id`와 원본 시각이 수집된 후에 시작해야 한다. 이 판정은 위 원본의 공개 확인 범위에 한하며 다른 공개 자료의 부재를 증명하지 않는다.
