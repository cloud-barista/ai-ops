# Chutes 다음 5분 요청량 p90: 모델별 승리 게이트 실패

2026-09-29. **상대 수요 학습기는 검증에서 미채택했다.** 35개 모델을 같은 비중으로 평가한 q0.9 pinball 손실은 가장 강한 기준선보다 **5.34% 낮았지만**, 기준선보다 나은 모델이 **16/35개(45.7%)**로 사전 문턱 60%에 못 미쳤다. 이는 요청량 예측 신호의 제한된 탐색 결과이며 실제 `SCALE_OUT/IN` 효과가 아니다. [점수 전 규약](chutes_demand_p90_v1_protocol.md)에 따라 row group **74–76은 받거나 열지 않았다**.

## 자료·결정 시점

[공식 Harvard MadSys Chutes 데이터 카드](https://huggingface.co/datasets/harvardMadsys/chutes_metadata)의 고정 revision `85722e694bf7bb8a5a5ccdf70424fa5998372467`에서 이전 TTFT 연구가 추출해 해시를 기록한 row group 65–73을 재사용했다. [동결 manifest](../artifacts/chutes_demand_p90_v1/frozen_manifest.json)는 코드, 규약, 7개 합성 테스트, 이전 추출물, 이전 학습 전용 35개 모델 목록을 **새 요청량 예측 점수 전에** 고정한다. 소스 9,013,248행의 ID 중복 및 시작시각 순서와 각 분할의 완전한 입력·정답 창을 검사했다. 스트리밍 시작의 모델 ID 결측은 0건이었다. 실제 날짜가 아닌 정규화 시각을 달력 특징으로 쓰지 않았다.

목표는 `t` 이후 5분에 **기록된** `chat_stream`/`completion_stream` 시작 건수이며, 0건도 포함했다. `t`의 활성 판단은 해당 모델의 과거 30분 시작 요청 ≥30건일 때만 한다. 학습기 입력은 해당 모델과 전체 서비스에서 이미 시작된 요청의 과거 5·10·30·60분 건수뿐이다. TTFT·인스턴스·캐시·완료 결과를 사용하지 않아 TTFT 유효 기록이 검증 요청의 60.6%뿐이었던 문제의 영향을 받지 않는다. 단, 원본에 수집기 생존·전달 지연이 없어 **관측된 요청량의 오프라인 예측**이다. 이전 TTFT 목표로 학습 구간에서 등록한 35개 모델은 요청량과 TTFT 기록이 많은 모델 쪽으로 편향될 수 있다.

| 지원량 | 학습 | 검증 |
| --- | ---: | ---: |
| 35개 모델 × 5분 격자 | 4,620 | 1,925 |
| 과거 정보로 적격인 판단 | 4,004 (86.7%) | 1,514 (78.6%) |
| 적격 중 미래 요청 양수/0 | 3,471 / 533 | 1,298 / 216 |
| 등록 모델별 적격 최소·최대 | 72–132 | 15–55 |
| 전체 서비스 시작이 0인 5분 칸 | 0/132 | 0/55 |
| 등록 모델의 기록된 스트리밍 시작 | 2,623,340 | 1,164,833 |

지원량은 사전 기준을 모두 통과했다. 학습 `[1970-12-27 23:15, 1970-12-28 10:15)`, 검증 `[11:25, 16:00)`이다. 봉인 시험 `[17:05, 23:30)`은 검증 게이트 실패로 사용하지 않았다. 새 후보는 [SwissAI 상대 수요 가설](swissai_scale_adaptive_protocol.md)을 5분 목표와 다른 AI 서빙 서비스에 적용한 재검증이다. 새 알고리즘의 최초성을 주장하지 않는다.

## 같은 판단 행의 검증 점수

주 지표는 요청/5분 단위의 모델별 q0.9 pinball 손실을 계산한 뒤 모델을 균등 평균한 값이다. 각 모델의 학습 총 가중치도 같게 했다. 피복률은 `실제 요청 수 ≤ 예측 p90`인 판단 비율이다. 과소예측량은 모델별 `max(실제−예측,0)` 평균을 다시 모델 균등 평균한 값이다. [전체 검증 지표](../artifacts/chutes_demand_p90_v1/validation.json)와 동일 판단 행의 예측 (`../artifacts/chutes_demand_p90_v1/validation_predictions.parquet`)을 보관했다.

| 방법 | 모델 균등 pinball ↓ | 전체 행 pinball ↓ | 모델 균등 피복률 ↑ | 모델 균등 과소예측량 ↓ |
| --- | ---: | ---: | ---: | ---: |
| 직전 5분 건수 지속 | 78.396 | 96.382 | 61.36% | 77.897 |
| 과거 30분의 5분 건수 경험적 p90 | 49.598 | 59.519 | 83.46% | 23.460 |
| 절대 수요 q0.9 학습기 | 48.316 | 59.164 | 86.70% | 31.391 |
| **상대 수요 q0.9 후보** | **45.735** | **55.704** | **88.66%** | **20.215** |

후보는 세 기준선 중 가장 좋은 절대 수요 학습기보다 손실 **5.34% 감소**, 피복률 **1.95%p 증가**, 모델 균등 과소예측량 **35.6% 감소**로 세 문턱을 만족했다. 하지만 절대 수요 학습기보다 손실이 낮은 모델은 **16/35개**, 사전 60% 기준에 해당하는 최소 21개보다 5개 적다. 모델 균등 손실 차이의 가장 큰 양수 기여 모델은 한 모델에서만 78.14 요청/5분이었고, 다른 19개 모델에서는 후보가 악화됐다. 개선이 충분히 넓게 나타났다는 근거가 없어 **종합 검증 판정은 실패**다. 이 결과를 보고 모델이나 문턱을 수정하지 않았다.

## 재현과 제한

검증 예측 Parquet **1,514행·35개 모델**을 평가 코드와 별도 계산으로 다시 읽어 네 방법의 모델 균등 손실·피복률·과소예측량이 `validation.json`과 일치함을 확인했다. `(모델,t)` 중복은 0건이다. `fetch-test` 명령은 검증 실패를 읽고 **네트워크 접근 전에 오류로 중단**했고, 새 시험 추출 디렉터리·기존 시험 추출 파일·`test.json`은 모두 없다. 학습기에 쓴 환경은 Python 3.9.25, pandas 2.3.0, scikit-learn 1.6.1, pyarrow 21.0.0이다. 버전은 manifest에 기록하지만 평가 코드가 실행 시 동일 버전을 강제하지는 않으므로, 다른 버전의 완전한 수치 재현은 보장하지 않는다.

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python -m unittest discover -s tests -p 'test_evaluate_chutes_demand_p90_v1.py' -v
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python scripts/evaluate_chutes_demand_p90_v1.py validate
```

검증의 7개 합성 테스트가 통과했다. 동결 규약·구현·테스트 SHA-256은 각각 `1ba9d9fc526d4b4cc4bc8359451ee09d027d8482977ece83dd793082a1eb0376`, `bf13469a8d359214480bdbeea8b721437fdfa64108ad5df60bdd4397d826526f`, `2a3d7ef2aadfb193af9ce40e3feba2b0f5c34559b019194416443c02df546e7c`이다. 동결 manifest SHA-256은 `581c398c41697e13bcde6531b9a24cd41cc6fd9b35d1ccbaae01e6c595e33881`, 검증 지표는 `d21717aad022b6db7a24c2666b8705b2f1bde6617529223021721a1dd77b0684`, 예측 파일은 `e2ed80dab28a3ceb80403780838da49a3683ba4c1b5423f5b4cc2cfa96cdcdb6`이다. 다음 방법을 검토한다면 이 검증 결과는 개발 자료로 취급하고 별도 규약과 보류 기간을 정해야 한다.
