# BurstGPT 요청 시점 출력 토큰 p90 평가

2026-09-28. [사전 규약](burstgpt_output_tokens_protocol.md)에 따라
[BurstGPT v2.0 원본](../data/external/burstgpt_v2/SOURCE.md)의 출력 토큰 수를
예측했다. 구현은 [`evaluate_burstgpt_output_tokens.py`](../scripts/evaluate_burstgpt_output_tokens.py),
선택 고정 및 정확한 점수·예측은 [`artifacts/burstgpt_output_tokens_v1`](../artifacts/burstgpt_output_tokens_v1)에 있다.

## 결론

검증 구간에서 가장 낮은 일별 동일 가중 p90 pinball 손실을 낸 고정 HGB
모델을 시험 전에 선택했다. 그러나 **시험 836,144건에서 포괄률은
69.61%**로 명목 p90의 90%에 크게 못 미쳤다. 같은 요청에서 입력 토큰
구간별 최근 7일 p90 기준선은 사후 비교상 손실이 더 낮았지만,
포괄률이 86.08%라 안전한 용량 상한으로 채택할 수 없다. 이 결과는
출력 길이 요구사항의 변화 탐지를 위한 연구 근거이며, 실제 GPU·VM
수 또는 `SCALE_OUT/IN` 판단의 정답이 아니다.

## 자료·재현 경계

원본 5,344,021행 중 요청 시점에 알 수 있다고 가정한
`Request tokens > 0` 규칙으로 4,956,059행을 선정했다. 이 중 출력 0은
단 1행이다. `Response tokens > 0`이라는 사후 결과 필터는 사용하지
않았다. 상태 열이 없으므로 이 대상을 검증된 성공 응답 전체로 해석하지
않는다. `Model`, `Log Type`, `log1p(Request tokens)`만 모델 입력으로
사용했고, 출력·총 토큰, 경과시간, 세션 ID는 제외했다.

| 구간(상대일) | 역할 | 입력 토큰 양수 요청 |
| --- | --- | ---: |
| 225–294 | 명목 학습 | 3,319,751 |
| 225–293 | 실제 고정 모델 학습·정적 기준선 | 3,315,205 |
| 295–314 | 검증 전체 | 800,164 |
| 303–314 | 방법 선택 평가 | 603,725 |
| 315–334 | 잠긴 시험 | 836,144 |

예측일 `d`에는 **요청일 `d-8`..`d-2`의 출력 로그가 일괄 전달됐다는
가정**으로 최근 기준선과 잔차를 계산했다. 공개 자료에서 실제 완료일과
로그 전달 지연을 검증할 수 없으므로 운영 환경의 가용시각 보장은 아니다.
HGB는 day 225–293에서만 학습했고 다시 맞추지 않았다. 적응 잔차는
모델 학습 밖인 day 295 이후의 이전 요청일에서만 계산했다.

## 시험 전 선택

검증 day 303–314의 하루별 p90 pinball 손실을 같은 비중으로 평균해
여섯 후보 중 최소값인 `hgb_base`를 선택했다. 선택은
[`selection_manifest.json`](../artifacts/burstgpt_output_tokens_v1/selection_manifest.json)에
원본·규약·코드·모델·검증 예측/점수의 SHA256과 함께 시험 점수 계산 전에
고정했다. manifest SHA256은
`e613ce78feec71931fadbf36a2c2b399cc1d4fcbf5af931d67c4f21a42a1f35d`다.
시험 출력은 이 해시들을 다시 검사한 뒤 생성됐다. 시험 목표값의
분포는 품질 감사 단계에서 이미 확인했으므로, 아래 평가를 완전한
블라인드 외부 검증이라고 부르지 않는다. 다만 시험 방법 선택에는 시험
예측 손실을 사용하지 않았다.

| 방법 | 검증 동일 일 가중 손실 ↓ | 검증 요청 가중 손실 ↓ | 검증 포괄률 |
| --- | ---: | ---: | ---: |
| 정적 전체 p90 | 63.590 | 24.133 | 92.80% |
| 정적 코호트 p90 | 30.944 | 16.615 | 96.92% |
| 최근 7일 코호트 p90 | 32.890 | 16.961 | 87.55% |
| 최근 7일 코호트×입력 구간 p90 | 33.253 | 16.677 | 81.32% |
| **고정 HGB p90 — 사전 선택** | **28.135** | **13.667** | **86.01%** |
| HGB + 학습 외 잔차 p90 | 32.851 | 16.635 | 81.43% |

손실 단위는 토큰이다. 선택된 모델은 검증에서도 명목 90% 포괄률에
못 미쳤다. 최저 손실 선정 규칙은 안전한 용량 상한 채택 규칙이 아니다.

## 잠긴 시험 결과

| 방법 | 시험 동일 일 가중 손실 ↓ | 시험 요청 가중 손실 ↓ | 시험 포괄률 | 평균 예측 토큰 |
| --- | ---: | ---: | ---: | ---: |
| 정적 전체 p90 | 248.091 | 114.229 | 68.42% | 110.0 |
| 정적 코호트 p90 | 188.060 | 89.914 | 72.93% | 166.7 |
| 최근 7일 코호트 p90 | 118.940 | 62.326 | 80.85% | 283.0 |
| 최근 7일 코호트×입력 구간 p90 | **89.541** | **42.046** | 86.08% | 295.6 |
| **고정 HGB p90 — 사전 선택** | 194.203 | 93.173 | **69.61%** | 138.0 |
| HGB + 학습 외 잔차 p90 | 117.512 | 59.768 | 81.41% | 291.6 |

검증에서 선택된 고정 HGB는 시험에서 정적 코호트 기준선보다도
일별 동일 가중 손실이 높았다(194.203 대 188.060). 최근 입력 구간
기준선의 시험 손실이 낮다는 사실은 **시험을 본 뒤 알게 된 결과**이므로
이 시험에서 해당 방법을 사후 선택해 채택 성능으로 보고하지 않는다.
또한 어떤 후보도 전체 90% 포괄률을 달성하지 못했다.
일별 손실과 포괄률 변화는 [그림](../artifacts/burstgpt_output_tokens_v1/daily_drift.png)에 표시했다.

분포 이동이 크다. 입력 토큰 양수 요청의 출력 p90은 학습 기간 111개,
검증 기간 93개, 시험 기간 529개였다. `GPT-4 | API log`의 출력 p90은
각 기간 269·112·1,703개였다. 시험에서 사전 선택 HGB의 이 코호트
포괄률은 35.8%였고, 마지막 두 5일 블록의 전체 포괄률은 각각
30.4%, 36.3%였다. 최근 입력 구간 기준선도 마지막 두 블록에서
77.9%, 73.0%에 그쳤다. 따라서 평균 손실 개선만으로 p90 예측의
신뢰도를 주장할 수 없다.

## 검산과 해석 한계

시험 예측 836,144행의 `row_id`는 모두 고유하고, 원본 CSV와 시각·모델·
로그 유형·입력 및 출력 토큰이 전부 일치했다. 저장된 예측에서 여섯 방법의
요청·일별 손실 및 포괄률을 별도로 재계산해 점수 JSON과 차이 0을
확인했다. day 315·325·330에서 각 코호트의 첫 다섯 요청, 총 60건의
최근 입력 구간 p90을 원본의 `d-8`..`d-2` 요청만으로 다시 계산해
불일치 0건이었다. [단위 테스트](../tests/test_burstgpt_output_tokens.py)는
사전 선정, 하루 배치 경계, 미래 라벨 불변성, 손실·선택 기준을 확인한다.

이 자료에는 요청별 `max_tokens` 설정, 사용자 작업 종류, 정확한 모델
버전과 프롬프트 의미, GPU/VM 사양, 모델별 KV 캐시 계수, 사용자 지연
SLO, 배포·스케일 행동과 이후 성능이 없다. 출력 토큰 수를 실제 KV 캐시·
VRAM 요구량으로 바꾸려면 별도 모델·GPU 계측이 필요하다. 따라서 추정한
출력 토큰 p90을 메모리나 노드 수로 직접 변환할 수 없으며, 실제 응용의
`DEPLOY/UPDATE/SCALE_OUT/SCALE_IN` 판단을 검증하지 않는다. 출력 길이
추정과 최근 분포 적응에는 기존 연구가 있으므로, 이 평가를 새로운 학습
알고리즘의 학술적 독창성으로 주장하지 않는다.

재현:

```bash
python -m unittest discover -s tests -p test_burstgpt_output_tokens.py
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 MKL_NUM_THREADS=2 python scripts/evaluate_burstgpt_output_tokens.py validate --output artifacts/burstgpt_output_tokens_repro
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 MKL_NUM_THREADS=2 python scripts/evaluate_burstgpt_output_tokens.py test --output artifacts/burstgpt_output_tokens_repro
python scripts/plot_burstgpt_output_drift.py
```

이미 선택 manifest가 있으면 `validate`는 덮어쓰기를 거부한다. 새
방법·조건을 시험하려면 다른 버전의 규약과 시험 구간이 필요하다.
