# Chutes 요청량 p90 v2: 최근 오차 적응의 내부 검증 미채택

2026-09-29. **최근 예측 오차에 따라 세 전문가의 가중치를 갱신하는 후보는 학습 구간 내부 검증에서 미채택했다.** 모델 균등 q0.9 pinball 손실은 가장 강한 기존 단일 기준선보다 6.10% 낮았으나, 같은 학습 자료로 정한 **고정 혼합**보다 개선이 0.37%에 그쳤다. 사전 문턱 2%에 못 미쳤고, 지원량이 충분한 1시간 블록도 4개 중 2개만 고정 혼합보다 좋았다. 따라서 별도 시험 row group 77–79는 요청 값으로 추출·열람하지 않았다. 기존 연구에서 봉인한 74–76도 그대로 유지했다.

## 독립 시험을 남겨둔 설계

[공식 Harvard MadSys Chutes 자료](https://huggingface.co/datasets/harvardMadsys/chutes_metadata)의 고정 revision `85722e694bf7bb8a5a5ccdf70424fa5998372467`과 기존 추출 row group 65–73을 사용했다. v1의 **이미 노출된** 검증 결과는 방법의 동기일 뿐, v2의 예측·가중치 보정·게이트 점수에 쓰지 않았다. v1에서는 상대 수요 모델의 전체 개선 중 86.5%가 한 모델에서 나왔고, 충분한 자료가 있는 31개 모델 중 26개에서 시간대에 따라 절대·상대 모델의 승자가 바뀌었다. 이에 따라 [점수 전 규약](chutes_demand_p90_v2_protocol.md)은 절대 q0.9, 상대 q0.9, 과거 30분 경험적 p90을 **모델별 최근 손실**로 섞는 단 한 가지 후보를 고정했다.

학습 구간은 시간 순서로 F0 5시간(기본 모델 적합), C 3시간(모델별 전문가 손실을 전체 평균 쪽으로 수축하여 고정 사전 가중치 보정), G 3시간(최근 손실 순차 갱신과 검증)으로 나눴다. G의 각 예측에는 그보다 먼저 끝난 최근 60분의 정답만 반영했다. 비교용 고정 혼합은 C에서 정한 가중치를 G 내내 유지한다. 35개 등록 모델과 `과거 30분 ≥30건` 적격 규칙은 이전 실험에서 고정돼 있었다. 정답은 다음 5분의 **기록된 스트리밍 시작 요청 수**다.

Parquet footer의 **메타데이터만** 확인해 별도 시험 원본 row group 77–79의 시작시각 범위를 확인했다. 정규화 시각 `1970-12-29 00:40≤t<06:20`을 시험 격자로 고정했다. 첫 판단의 60분 이력과 마지막 정답 5분이 전부 이 세 그룹에 속한다. 시험 모델 집합의 ≥12 적격 판단 규칙은 전체 시험 구간을 본 뒤 적용하는 **사전 정의된 사후 지원량 필터**이며, 시점별 온라인 모델 선택을 뜻하지 않는다. 시험 요청 값을 보기 전 [동결 manifest](../artifacts/chutes_demand_p90_v2/frozen_manifest.json)에 규약·코드·합성 테스트·기존 추출 해시를 기록했다.

## 학습 구간 내부 G 결과

F0/C/G 적격 판단은 각각 **1,821/1,089/1,094행**, 세 구간 모두 35개 모델이다. 모델별 최소 판단 수는 16/12/17행이고, 전체 서비스의 스트리밍 시작이 0인 5분 격자는 세 구간 모두 0개다. 고정 지원량 조건을 통과했다. 모델 균등 지표는 모델별 평균을 먼저 구하고 다시 35개 모델을 동일 비중으로 평균한다.

| 방법 | 모델 균등 pinball ↓ | 모델 균등 피복률 ↑ | 모델 균등 과소예측량 ↓ |
| --- | ---: | ---: | ---: |
| 직전 5분 건수 | 68.924 | 59.94% | 69.397 |
| 과거 30분 경험적 p90 | 49.946 | 83.23% | 28.413 |
| 절대 수요 q0.9 | 60.114 | 86.54% | 44.775 |
| 상대 수요 q0.9 | 43.665 | 88.34% | 21.334 |
| C에서 정한 고정 혼합 | 41.154 | 89.20% | 21.869 |
| **최근 오차 적응 후보** | **41.000** | **88.75%** | **21.411** |

후보는 기존 단일 기준선 중 최선인 상대 수요 q0.9보다 6.10% 낮은 손실, 35개 중 22개 모델의 개선, 88.75% 피복률, 한 모델을 빼도 최선의 기존 단일 기준선 대비 최소 4.66% 개선을 보였다. 그러나 고정 혼합 대비 손실 감소는 **0.37%**이고, 1시간 블록 승리는 **2/4**다. [전체 점수](../artifacts/chutes_demand_p90_v2/gate.json)의 사전 게이트는 고정 혼합 대비 ≥2%, 지원 블록 ≥2/3 승리를 요구하므로 결과는 **실패**다. 고정 혼합의 41.154 역시 이 G 점수를 본 결과이므로 이를 새 후보로 사후 교체해 시험으로 보내지 않았다.
