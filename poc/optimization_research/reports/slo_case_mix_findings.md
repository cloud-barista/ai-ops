# 합성 SLO 판단의 난도와 오류 구성 감사

## 무엇을 다시 계산했나

[기존 합성 SLO 평가](counterfactual_slo_findings.md)의 고정된 K=8 예측과 SQLite 측정 스냅샷을 그대로 사용했다. 새 모델 하나를 제외한 나머지 모델의 측정치에서 지연·요청/초 목표를 정하고, 제외한 모델의 8개 자원 형상을 평가했다. 목표당 실측상 가능한 형상이 **0개**, **1~7개**, **8개**인 경우를 분리했다. 각 방법은 예측상 가능한 형상 중 GPU 복제 수, CPU 코어 수 순으로 가장 작은 것을 고른다. 기준 측정에 이미 포함된 GPU 1개·2코어 형상을 고른 경우도 따로 세었다.

## 전역 훈련 분위수 목표

| 실측 가능 형상 수 | 질의 수 | 비율 | 두 제약의 단독 실패형이 모두 존재 |
| --- | ---: | ---: | ---: |
| 0개 | 7,629 | 53.1% |  |
| 1~7개 | 3,794 | 26.4% |  |
| 8개 | 2,952 | 20.5% |  |
| 전체 | 14,375 | 100% | 264 (1.84%) |

가능 형상이 없거나 모두 가능한 질의가 **73.6%**다. 따라서 전체 성공 횟수는 선택이 어려운 질의의 성능을 과대평가할 수 있다.

| 방법 | 0개: 잘못 승인 | 1~7개: 선택 / 성공 / 잘못 승인 | 8개: 성공 | 전체 성공 / 잘못 승인 |
| --- | ---: | ---: | ---: | ---: |
| 공분산 전이 | 288 | 3,477 / **3,191** / 286 | 2,952 | **6,143 / 574** |
| 부드러운 커널 전이 | 327 | 3,443 / 3,135 / 308 | 2,939 | 6,074 / 635 |
| 직접 Ridge | 339 | 3,378 / 3,127 / **251** | 2,942 | 6,069 / 590 |
| 전역 평균 | 356 | 3,313 / 2,961 / 352 | 2,936 | 5,897 / 708 |

부분가능 질의에서 공분산은 커널보다 성공 **56건 증가**, 잘못 승인 **22건 감소**다. Ridge보다 성공은 **64건 증가**했지만 잘못 승인도 **35건 증가**한다. 전체에서 Ridge보다 잘못 승인이 16건 적었던 이유는 불가능한 질의의 잘못 승인이 51건 적었기 때문이다. 어떤 오류를 더 중시하는지에 따라 평가가 달라진다. 세 주요 방법 모두 이미 실측한 기준 형상을 선택해 성공한 **512건**이 포함되어 있다. 이 512건은 예측 성능의 차이를 설명하지 않는다.

## 동일 입력 조건의 훈련 donor로 만든 목표

전역 목표가 다른 배치·입력 길이·동시성의 성능을 섞는 영향을 확인했다. 같은 작업, 배치, 입력 길이, 동시성, 반복 수를 가진 **훈련 donor**만으로 각 workload의 목표를 다시 정했다. 동일 조건 donor가 없는 Qwen은 제외되어 encoder 8모델의 512개 workload만 비교할 수 있다. 아래 `전역 목표, 같은 모집단`도 바로 그 512개 workload에 전역 목표를 적용한 수치다.

| 목표 설정 | 전체 질의 | 가능 0개 | 가능 1~7개 | 가능 8개 | 두 제약의 단독 실패형 동시 존재 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 전역 목표, 같은 모집단 | 12,800 | 6,374 | 3,480 | 2,946 | 228 |
| 동일 입력 조건 donor 목표 | 12,800 | 5,225 | **4,919** | 2,656 | **647** |

동일 입력 조건 목표는 부분가능 사례를 3,480건에서 4,919건으로 늘린다. 그래도 가능 형상이 0개 또는 8개인 질의가 **61.6%**이고, 실제 사용자 요구사항은 아니다.

| 동일 입력 조건 목표 | 전체 성공 / 잘못 승인 | 부분가능: 선택 / 성공 / 잘못 승인 |
| --- | ---: | ---: |
| 공분산 전이 | **6,914 / 771** | 4,626 / **4,258** / 368 |
| 부드러운 커널 전이 | 6,865 / 828 | 4,615 / 4,216 / 399 |
| 직접 Ridge | 6,876 / 774 | 4,586 / 4,224 / **362** |
| 전역 평균 | 6,548 / 1,042 | 4,432 / 3,905 / 527 |

부분가능 질의에서 공분산은 커널보다 성공 **42건 증가**, 잘못 승인 **31건 감소**다. Ridge보다 성공은 **34건 증가**하지만 잘못 승인도 **6건 증가**한다. 이 비교는 공분산 전이가 일부 훈련 기반 목표에서 판단을 개선한다는 탐색 근거다. 실제 가격·운영 SLO가 없고 새 호스트·모델 검증도 없으므로 비용 효율이나 배포 안전성을 입증하지 않는다.
