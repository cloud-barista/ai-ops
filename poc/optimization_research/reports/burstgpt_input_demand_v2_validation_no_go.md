# BurstGPT 입력 수요의 학습 블록 보정: 검증 NO-GO

2026-09-28. **v2 보정 모델은 미채택이다.** 동일 집단 가중 90백분위 pinball 손실은 사전 선택 기준선보다 10.86% 낮았지만, GPT-4의 검증 피복률이 **82.92%**로 사전 기준 85%에 못 미쳤다. 이 규약에 따라 상대일 285–334의 시간별 시험 목표는 채점하지 않는다.

## 규약과 자료 경계

[점수 전 규약](burstgpt_input_demand_v2_protocol.md)과 [활성 동결 manifest](../artifacts/burstgpt_input_demand_v2/freeze_manifest.json)는 v1 실패를 본 뒤 작성됐다. 각 집단에서 상대일 225–254의 성숙한 **694시간**으로 v1과 같은 q90 HGB를 적합하고, 255–264의 성숙한 **239시간**을 별도 보정 블록으로 사용했다. 마지막 적합 정답 `h=6118`은 보정 시작 `h=6120`에 이용 가능하며, 아직 이용 불가능한 `h=6119`는 제외했다. 보정 잔차의 216번째 오름차순 값을 0 이상으로 자른 이동량은 ChatGPT **4,471.039 입력 토큰**, GPT-4 **1,030.143 입력 토큰**이었다. 보정 블록 피복률은 두 집단 모두 **216/239=90.38%**였다. 적합·보정 블록의 기록 있는 일수·시간 비율은 두 집단 모두 사전 지원량 조건을 통과했다.

검증은 상대일 265–284의 집단별 480시간이다. 과거 입력의 최신 시점은 `h−2`이며, 목표는 `Conversation log`에 **기록된** 한 시간의 `Request tokens` 합계다. 무기록 시간칸의 0은 실제 수요 0이라는 증거가 아니다. [v1 검증](burstgpt_input_demand_validation_no_go.md)을 보고 후속 설계를 했으므로 이번 검증은 **탐색 평가**다. 과거 원본 점검에서 시험 마지막 두 행의 입력값이 우연히 노출된 사실도 이미 [규약](burstgpt_input_demand_v2_protocol.md)에 기록했다. 시험의 시간별 예측 점수는 계산하지 않았다.

## 같은 행의 검증 결과

| 방법 | 두 집단 동일 가중 pinball | ChatGPT 피복 | GPT-4 피복 |
| --- | ---: | ---: | ---: |
| 선택 기준선: 전날 같은 시간 + 학습 잔차 p90 | 6,901.853 | 88.96% | 83.54% |
| v1 HGB, 40일 적합 | 6,180.628 | 84.17% | 81.46% |
| v2 HGB, 30일 적합·비보정 | 6,268.228 | 85.42% | 82.50% |
| **v2 HGB, 30일 적합·블록 보정** | **6,152.008** | **87.08%** | **82.92%** |

v2 보정 모델은 기준선보다 **10.86%** 손실이 낮고, 두 집단 각각 기준선보다 손실이 낮았다. 집단을 동일 가중한 하루 손실도 **20일 중 17일** 앞섰다. 그러나 GPT-4 피복은 **398/480시간**으로 필요한 **408/480시간**보다 10시간 부족하다. ChatGPT 피복은 418/480시간이다. v1 HGB에 비해 ChatGPT 손실은 5,757.765→5,654.687로 낮아졌지만 GPT-4는 6,603.491→6,649.330으로 높아졌다. 보정 블록의 90.38% 피복이 뒤따른 검증 블록의 피복을 보장하지 못했다.

독립 확인으로 예측 CSV (`../artifacts/burstgpt_input_demand_v2/validation_predictions.csv`)의 960행을 표준 CSV 리더로 다시 집계했다. `mean(max(0.9×(y−p),−0.1×(y−p)))` 손실, `y≤p` 건수, 집단별 480행·일별 24행·17일 우세가 [지표 JSON](../artifacts/burstgpt_input_demand_v2/validation_metrics.json)과 모두 일치했다. 지원량·모델·예측 파일의 실제 SHA-256도 지표 JSON에 기록된 해시와 일치했다. [보정 지원량](../artifacts/burstgpt_input_demand_v2/preperiod_block_support.json)은 두 집단 모두 통과했다.

**결론:** 사전 채택 조건 네 항목 중 GPT-4 피복률 하나가 실패했다. 같은 검증을 보고 이동량이나 블록 길이를 다시 조정하지 않는다. 일방향 잔차 보정은 [기존 분위수 보정 연구](https://papers.neurips.cc/paper_files/paper/2019/hash/5103c3584b063c431bd1268e9b5e76fb-Abstract.html)와 관련된 방법이므로 알고리즘의 학술적 최초성을 주장하지 않는다. 시간 상관·분포 변화가 있는 추적에는 교환가능성 기반 피복 보장을 적용할 수 없다. 기록된 입력 토큰 수요는 GPU 수·VM 형상·실제 스케일 조치나 사용자 SLO의 정답이 아니다.
