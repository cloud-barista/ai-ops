# 비슷한 과거 모델에 가중치를 주는 잔차 공분산: 개선 근거 없음

## 질문과 평가

새 AI 모델의 GPU 1개·CPU 2코어 구성에서 8개 입력 조건을 측정했을 때, 그 잔차가 비슷한 과거 모델에 더 높은 가중치를 주면 나머지 입력 조건과 자원 형상 예측이 좋아지는가? 기존의 과거 모델 균등 공분산, 평균을 제거한 공분산, 부드러운 커널, Ridge를 **같은 8개 프로브와 같은 예측·평가 행**에서 비교했다.

주 데이터의 9개 모델을 하나씩 통째로 제외했다. 각 fold의 절대 성능 모델과 자원 형상 반응 모델은 나머지 8개 모델로만 학습했고, donor 잔차는 해당 donor 모델을 다시 뺀 내부 홀드아웃 예측에서 계산했다. encoder 8개는 같은 64개 입력 조건을 공유해 donor 잔차를 정렬할 수 있다. Qwen은 같은 작업·입력 그리드의 donor가 없어 커널로 돌아간다. 새 입력 조건 평가는 주 데이터에서 선택한 8개 앵커만 이용했으며 추가 프로브는 0개다.

가중치는 측정한 앵커에서 donor와 새 모델의 잔차 간 제곱거리를 donor 잔차 크기로 정규화하고, 고정 온도 1의 softmax를 적용했다. **이 가중치 강도는 제외 모델의 성능 결과로 조정하지 않았다.** donor별 잔차 외적의 가중 평균을 기존과 동일하게 부드러운 커널과 50:50으로 섞었다. donor 가중 평균과 중심화 공분산을 함께 쓰는 변형도 따로 비교했다. 예측 단계가 읽는 제외 모델의 성능 값은 선택된 앵커 8개뿐이다.

## 가중치 쏠림과 모델별 손실

공유 encoder fold당 donor는 7개다. 가중치의 유효 donor 수 `1/Σw²`는 **2.62~6.11개**였다. ALBERT를 제외한 fold에서 ELECTRA donor 하나가 가중치 **57.3%**를 받으며 유효 donor 수가 2.62개로 줄었다. 이 fold의 가중 2차 모멘트는 기존 균등 방법 대비 Novel matrix 지연/요청 MALE이 각각 **+0.0210/+0.0163** 악화됐다. 반면 주 데이터에서는 각각 −0.0021/−0.0045 좋아졌다. 측정 앵커에서 비슷하다는 신호가 새 입력 조건까지 이어지지 않는 구체적 사례다.

다른 주 데이터 fold에서도 ELECTRA를 제외했을 때 가중 방식의 지연/요청 MALE은 **+0.0056/+0.0041** 악화됐다. 전체 encoder 8개 중 가중 2차 모멘트의 주 데이터 지연 개선/악화는 각각 4/4개 모델이었다. 새 Space filling에서는 기존 균등 방식보다 성공 건수가 1개 줄었다. donor 몇 개의 높은 가중치가 일부 모델의 외부 입력 조건에서 오히려 불리했다.

Qwen은 정렬 가능한 donor가 없어 가중 방식과 기존 커널이 정확히 동일하다. 전체 9개 모델 합산이 가중 방식의 새로운 전이 성능을 보여준다고 해석하면 안 된다.

## 재현 및 해석 범위

- 실행: `OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python scripts/donor_similarity_transfer.py`
- 구현: `scripts/donor_similarity_transfer.py`; 누수·공분산 테스트: `tests/test_donor_similarity_transfer.py` (6개 통과).
- 원자료 해시, 가중치, 모델별 결과, 예측값: `artifacts/donor_similarity_transfer_v1/`.
- 기존 주 데이터·새 조건의 균등 공분산·커널 예측과 현재 재계산 예측은 최대 약 `3.6e-15` 차이로 일치했다. 기존 중심화 공분산 예측도 최대 약 `2.7e-15` 차이로 일치했다.
- 주 데이터는 단일 GPU 호스트이며 SLO는 수집 과정에서 생성된 값이다. 독립 모델·하드웨어·실사용 SLO에 대한 일반화 근거는 없다.

방법 자체도 학술적 신규성으로 주장하기 어렵다. 역사적 곡선에서 경험적 평균·공분산을 추정해 새 과제의 몇 개 관측에 맞추는 [Empirical Gaussian Processes](https://arxiv.org/abs/2602.12082)와, 여러 출처의 유사성을 모델링하는 [Source-Target Similarity Modelings for Multi-Source Transfer Gaussian Process Regression](https://proceedings.mlr.press/v70/wei17a.html) 등 선행 연구가 있다. 현재 결과로는 donor 유사도 가중을 핵심 신규 방법으로 채택하지 않는다.
