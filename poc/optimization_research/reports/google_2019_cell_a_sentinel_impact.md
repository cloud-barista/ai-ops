# Google 2019 cell-a 특수 시각의 기존 시험 영향

2026-09-29. 기존 [cell-a 신규 JOB 도착량 예측](google_2019_arrival_model_findings_v1.md)의 원본 추출은 `time=0`을 일반 사건 시각으로 허용했다. [Google v3 형식 문서](https://drive.google.com/file/d/10r6cnJ5cJ89fPWCgj7j4LtLBqYN9RiI9/view)는 `0`을 **추적 시작 전**, `2^63−1`을 **추적 종료 후**의 특수 시각으로 정의한다. 따라서 기존 cell-a 시계열과 이를 학습 원본으로 사용한 [cell-b 이전 시험](google_2019_cell_b_adaptive_findings_v1.md)은 **특수 시각 미제외 동결 실험**으로 읽어야 한다. cell-b 자체의 새 추출기는 두 특수 시각을 제외했다.

원본 cell-a gzip 10개 전부를 스트리밍하며 시각·JOB SUBMIT과 익명 ID의 최소 정상시각을 재점검했다. 원시 ID는 집합과 임시 DB에만 두고 보고서에는 저장하지 않는다.

재추출은 [검증·추출 스크립트](../scripts/audit_google_2019_cell_a_sentinels.py)(SHA-256 `172c03f5c9ebbc5de899e55ae82b7b01a9086be490e0c2e3e48e32a26de148db`)로 재현한다. 기존 v1 원본·동결·코드·시계열의 해시를 확인한 뒤 공식 gzip 10개를 다시 읽었다. [보정 시계열](../artifacts/google_2019_cell_a_sentinel_v2/series.json)(SHA-256 `7678e205e07891ab7698ff7315c29eda7d9eb2c99fc52e84af54d87acccb9f12`)과 [bin별 영향](../artifacts/google_2019_cell_a_sentinel_v2/impact.json)(SHA-256 `713d41d0146196acb895ad546fc2d50a59612e3e65b4dccebf1a15cc527ff90a`)을 별도 보존했다. 임시 ID DB는 삭제됐고 합성 테스트 12개가 통과했다.

| 항목 | 원본 전수 감사 |
| --- | ---: |
| 전체 collection 사건 | 20,807,441행 |
| `time=0` 추적 전 사건 | 50,005행 |
| 그중 유효 JOB SUBMIT | 14,276행·ID 14,276개 |
| `time=2^63−1` 추적 후 사건 | 0행 |
| 정상시각 사건 | 20,757,436행 |
| 정상시각 유효 JOB SUBMIT 원시 행 | 4,713,506행 |
| 정상시각 고유 최초 JOB SUBMIT | 4,713,501개 |
| 정상시각 최소 시각 | 600,037,539µs |

추적 전 JOB ID 중 **2개**는 정상시각에도 유효 SUBMIT이 있었다(정상시각 행 7개). 두 ID의 최초 정상시각은 각각 5분 bin **1227**과 **1528**이었다. 기존 원본 추출은 같은 ID의 `time=0`을 최초로 선택해 그 bin에서 두 신규 JOB을 빠뜨렸다. 기존 수 `505`·`487`은 특수 시각을 제외하면 각각 `506`·`488`이다. 두 bin 모두 기존 train 안에 있고 validation/test 목표 bin에는 직접 겹치지 않는다.

더 넓은 차이는 시계열 시작점이다. 특수 시각을 제외하면 첫 완전 bin은 기존 `1`에서 **`3`**으로 이동하고 마지막 완전 bin `8928`은 같다. 첫 288개 burn-in 뒤 60/20/20 시간분할을 같은 규칙으로 다시 계산하면 다음처럼 바뀐다.

| 구간 | 기존 동결 v1 | 특수 시각 제외 시 |
| --- | --- | --- |
| 완전 bin | 1–8928, 8,928개 | 3–8928, 8,926개 |
| train 목표 | 289–5472, 5,184개 | 291–5472, 5,182개 |
| validation 목표 | 5473–7200, 1,728개 | 5473–7199, 1,727개 |
| test 목표 | 7201–8928, 1,728개 | 7200–8928, 1,729개 |

동결된 v1의 모델 점수와 cell-b 이전 점수를 이 감사로 자동 보정하지 않는다. 두 학습 정답과 분할 경계가 바뀌므로 같은 모델을 다시 학습·평가하면 **새 실험**이다. 기존 v1 Poisson HGB의 큰 실패가 뒤집힌다고 주장할 근거도, 정확히 같은 점수가 유지된다고 주장할 근거도 여기에는 없다. cell-b 시험은 **그때 동결된 cell-a 학습기**를 처음 보는 cell-b에 적용한 결과로서 재현 가능하지만, 깨끗한 cell-a 정답으로 학습한 모델의 결과는 아니다. 새 모델 판단에는 특수 시각을 제외한 별도 시계열과 새 독립 셀이 필요하다.
