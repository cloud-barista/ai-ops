# 전체 자원 형상 잔차 공분산 전이: 기각한 탐색 가설

## 질문과 결론

새 모델에서 GPU 1개·CPU 2코어의 8개 입력 조건만 측정한다. 이전 모델에서 학습한 **입력 조건 × GPU·CPU 형상 전체의 예측 잔차 관계**로 나머지 형상의 성능을 직접 보정하면, 기존의 “앵커 잔차를 입력 조건 사이에 전이한 뒤 자원 반응 모델에 넣는 방법”보다 좋아지는가?

현재 SQLite에서는 **좋아지지 않았다.** 같은 프로브와 비용을 사용했을 때 encoder 8개 모델의 지연/요청 처리량 평균 절대 로그오차(MALE)는 새 방법 **0.269/0.165**, 기존 앵커 전이 **0.235/0.119**였다. 실제 가능한 작업의 SLO 성공도 **295/309**로 기존 **298/309**보다 적었고, 예측을 따라 선택한 형상의 위반은 **18건**으로 기존 **13건**보다 많았다. 따라서 이 구성은 후속 연구의 주 방법으로 채택하지 않는다.

## 방법과 공정한 비교

- 바깥쪽 leave-one-model-out 분할에서 새 모델 하나를 완전히 제외했다. 나머지 모델의 결과로 절대 성능 ExtraTrees와 앵커 조건부 자원 반응 ExtraTrees를 학습했다.
- 이전 모델 각각의 전체 8개 자원 형상 잔차는 그 이전 모델도 제외한 **안쪽 모델 단위 교차검증**으로 얻었다. 그 모델의 미측정 성능을 학습한 모델이 만든 잔차를 쓰지 않았다.
- 동일한 입력 조건을 공유하는 이전 encoder 모델의 잔차 표면으로 자원 형상별 잔차와 앵커 잔차의 경험적 2차 모멘트를 계산했다. 여기에 고정된 부드러운 입력·자원 커널을 50% 섞었다. 관측된 8개 앵커 잔차로 전체 표면을 조건화했다. 경험적 Gaussian process와 소수 관측 조건화 자체는 [Empirical Gaussian Processes](https://arxiv.org/html/2602.12082) 등의 선행 원리이며 이 실험의 신규성으로 주장하지 않는다.
- 비교군에는 **동일한 8개 공간 medoid 입력 조건**을 측정한 기존 앵커 공분산 전이, 앵커 커널 전이, 앵커 Ridge 전이, 절대 성능 모델에 직접 적용한 평균 잔차 보정과 Ridge 보정을 넣었다. 새로운 방법의 커널만 남긴 대조군도 추가했다.
- 모든 방법의 예측 오차는 새 모델의 **모든 입력 조건에서 앵커를 제외한 7개 자원 형상**에 대해 측정했다. SLO 선택은 동일한 8개 형상 전체와 동일한 실제 가능 작업 집단을 사용했다. 측정 비용은 `GPU 개수 × wall_seconds`로 계산했고, `wall_seconds`에 포함된 로딩 시간을 중복 가산하지 않았다.
- 등록 시 모델의 파라미터 크기를 알 수 있다고 가정했다. 새 모델의 다른 성능 값은 선택된 8개 앵커를 제외하고 예측 함수가 읽지 않는다. 테스트에서는 모든 미측정 앵커와 나머지 자원 형상의 지연·처리량을 크게 바꾸어도 예측이 동일함을 확인했다.

## 결과: 모델당 앵커 8개

오차는 모델별 MALE의 평균이다. SLO 성공의 분모는 실제로 가능한 작업 수다. 아래 각 공유 그리드 방법의 측정 비용은 모델당 **5.76 GPU-wall초**로 같다.

| 공유 그리드 encoder 8개 | 지연 MALE | 요청/초 MALE | SLO 성공 | SLO 위반 |
| --- | ---: | ---: | ---: | ---: |
| 전체 자원 잔차 경험적 공분산 | 0.269 | 0.165 | 295/309 | 18 |
| 전체 자원 잔차 부드러운 커널만 | 0.392 | 0.319 | 278/309 | 28 |
| 기존 앵커 공분산 전이 | **0.235** | **0.119** | **298/309** | **13** |
| 기존 앵커 커널 전이 | 0.247 | 0.135 | 290/309 | 17 |
| 기존 앵커 Ridge 전이 | 0.251 | 0.142 | 292/309 | 15 |
| 절대 성능 + 직접 Ridge 보정 | 0.257 | 0.136 | 288/309 | 14 |
| 절대 성능 + 전체 평균 잔차 | 0.331 | 0.261 | 282/309 | 15 |

경험적 전체 자원 공분산은 **그 구성의 커널 대조군**보다는 확실히 낫다. 다만 연구 판단에 필요한 비교는 가장 강한 기존 방법과의 차이다. 기존 앵커 공분산 전이에 비해 지연 MALE은 모델 평균 **0.0342**, 요청/초 MALE은 **0.0456** 높았다. 두 오차 모두 8개 중 6개 모델에서 더 컸다. 모델 재표본추출 20,000회의 탐색적 95% 구간은 차이(새 방법 − 기존)가 지연 **[−0.0190, 0.0870]**, 요청/초 **[0.0095, 0.0946]**였다. 같은 데이터에서 방법을 탐색한 후 계산한 구간이므로 확증적 검정이 아니다.

Qwen 1개는 encoder와 입력 조건 및 작업 종류가 달라 정렬되는 이전 모델이 없다. 이 경우 경험적 방법은 부드러운 커널로 **완전히 fallback**하므로 경험적 방법과 커널 대조군의 예측이 행마다 정확히 같다. Qwen의 지연/요청/초 MALE은 **0.400/0.356**, SLO 성공 **39/48**, 위반 **9건**이었다. 기존 앵커 전이는 **0.262/0.188**, **40/48**, **5건**이었다. 측정 비용은 두 방법 모두 **16.54 GPU-wall초**였다. Qwen에서 GPU1·CPU4의 새 방법 지연/요청 오차는 **0.276/0.223**이지만, GPU2·CPU16에서는 **0.488/0.481**로 커진다. 고정 자원 커널의 앵커 유사도도 각각 **0.899**, **0.234**다. 이는 앵커에서 먼 형상에 보정을 충분히 전파하지 못하는 설명과 일치하지만, 원인을 독립적으로 분리한 실험은 아니다.

## 해석과 중단 기준

8개 encoder가 공유하는 64개 입력 조건 안에서도 전체 자원 잔차의 경험적 관계가 커널 대조군을 개선한 사실은 확인된다. 그러나 이미 학습한 자원 반응 모델을 **추정한 앵커 값으로 다시 평가하는 기존 경로**가 더 정확하다. 전체 자원 표면을 직접 보정하는 현재 구현은 처리량 오차와 SLO 선택을 악화시켰다. Qwen은 정렬 donor가 없어서 이 방법의 교차 모델 전이 자체를 시험하지 못한다.

주 캠페인에서 강한 기존 방법보다 나쁘므로 새 입력 조건 캠페인으로 확대하지 않았다. 이것이 모든 가능한 공동 공분산 모델이 실패한다는 증거는 아니지만, 현재 방법을 새로운 핵심 알고리즘이나 노벨티 근거로 삼을 수 없다는 결론에는 충분하다. 또한 현재 SLO는 수집 과정에서 만든 값이라 실제 사용자 요구 분포의 개선을 증명하지 않는다.
