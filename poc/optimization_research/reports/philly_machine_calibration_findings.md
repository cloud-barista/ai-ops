# Philly 미사용 기계의 GPU 위험 보정 시험

## 결론

**사전 동결한 방법 개선 기준을 통과하지 못했다.** 앞선 시험에서 본 `[5,15)` 기계를 개발 자료로만 사용해 기계별 사전기간 위험 보정 규칙을 정하고, 겹치지 않는 `[15,25)` 기계의 2017년 12월 1–15일을 한 번 채점했다. 새 시험의 33개 적격 기계·599,752개 판단에서 제안법의 행 Brier는 동결 통합 로지스틱 `p₀` 대비 `0.109163` 대 `0.109416`으로 0.23% 낮았다. 요구한 상대 5%에 못 미치고, 기계 재표집 95% 구간은 0을 포함했으며 두 번째 고정 달력 반구간에서 악화했다. AP도 `0.7241` 대 `0.7487`로 낮아졌다. 기계 동일 가중 Brier `0.088816` 대 `0.090686`은 개선됐으나 이것만으로 채택 조건을 충족하지 않는다.

이 결과는 **GPU 사용률의 미래 30분 고위험 사건 확률**에 관한 것이다. 사용자 지연 SLO, 앱별 배포 적합성, VM 증설·축소 조치의 효과를 측정하지 않았다. 기계별 절편 보정 자체는 알려진 통계 방법이며 새 학술 원리로 주장하지 않는다. 이 실험의 경희대 연구 대상은 동결 위험 모델에 기계 자신의 과거 관측 결과를 안전하게 결합하기 위한 시점·지원량·보류 규칙이다.

## 설계와 데이터 경계

기존 통합 로지스틱은 Philly 원본 기계 해시 버킷 `<5`의 21기계로 이미 학습·동결됐다. 해시 버킷 `[5,15)`의 47기계와 그 12월 성능은 이전 연구에서 확인했으므로 이번 방법 선택에만 썼다. 새 버킷 `[15,25)`은 [규약](philly_machine_calibration_protocol_frozen.md)과 [개발 선택](../artifacts/philly_machine_calibration_v1/development_selection.json)을 동결한 뒤 수집했다. 원시 ID 집합의 교집합은 세 그룹 모두 0이다. 같은 2017년 Philly 클러스터·같은 기간의 **새 기계 홀드아웃**이며 새 클러스터·장비·서비스로의 일반화 시험은 아니다.

원본 압축 아카이브를 전체 스트리밍으로 확인했다: 1,055,988,361바이트, SHA256 `2037ccf63a725a02be718b0e1aeee6142c90b7f62d0d849295120e9f6ba13d2c`, GPU CSV 44,750,640행·552기계. 그중 새 해시 구간 3,512,172행·42기계만 보존했다. 정규화 과정에서 GPU 슬롯 폭 변화 1,980행을 무효로 표시했고, 폭 오류율 1%를 넘는 기계는 없었다. 원본 행 순서와 Parquet의 행 수·SHA가 감사 기록과 일치한다. [출처·전처리 기록](../data/external/msr_philly_2017_calibration_holdout/SOURCE.md)에 파일별 해시와 라이선스·인용 정보를 적었다.

주 모집단은 GPU의 현재 5분 평균이 80% 미만이고 과거 세 5분 창이 완전한 `complete/below_80` 판단이다. 미래 여섯 5분 창이 모두 관측되며 그중 하나라도 80% 이상이면 양성으로 정의했다. 원래 후보 생성기의 분할 경계를 재사용해, 각 교정 라벨의 미래 결과가 12월 시험 **이전에** 완결되도록 했다. 기계 교정에는 P1 `2017-10-04`–`11-15`, P2 `11-16`–`11-30` UTC의 같은 층에서 한 시간 간격으로 뽑은 정답만 사용했다. 12월 정답은 점수 계산에만 사용했다.

## 개발 선택

개발 기계에서 전역 절편 이동 `δ_g=+0.418424`를 P1+P2 결과로 맞췄다. 그러나 12월 개발 사건률은 15.49%였고, 원래 모델의 평균 예측은 15.93%, 전역 이동 예측은 19.32%였다. 전역 이동만 적용하면 개발 행 Brier가 `0.077783→0.081368`, 기계 동일 가중 Brier가 `0.069491→0.073328`로 악화했다. 첫 탐색의 전역 이동 기반 게이트도 기계 동일 가중 Brier `0.069804`로 원래 모델보다 나빴다. 이 [초기 개발 선택 기록](../artifacts/philly_machine_calibration_v1/development_selection_initial_global.json)을 남겼다. 이 단계에서 본 12월은 독립 검증 자료가 아니다.

이 진단을 반영해 새 표본을 열기 전에 기준 확률 `p₀`/`p_g`, 벌점 표준편차 `sigma∈{0.5,1,2}`, P1→P2 Brier 개선 게이트 `>{0,0.002}`를 개발 기계에서만 비교했다. 선택된 제안법은 원래 `p₀`를 기준으로 하고, 해당 기계 P1에서 맞춘 국소 절편이 P2의 `p₀`보다 Brier를 `0.002` 초과 개선한 경우에만 P1+P2로 절편을 다시 맞춰 12월에 적용한다. 최소 5일·시간 간격 정답 30개가 없거나 P1/P2 각각 최소 3일·15개가 없으면 보류한다. 보류하면 **원래 `p₀`로 돌아간다.** `sigma=2`가 선택됐다. 개발 12월에서 8개 기계에 적용됐으며 기계 동일 가중 Brier가 `0.069491→0.068578`로 1.31% 낮아졌다. 반대로 행 Brier는 `0.077783→0.078027`, AP는 `0.7073→0.6814`로 악화했다. 이 선택의 개발 성능을 성공 근거로 사용하지 않는다.

기준선도 독립적으로 선택했다. 원래 `p₀`, `state_recent` Beta, 전역 이동 `p_g`, 기계별 과거 사건률, 게이트 없는 기계별 절편(`p₀`/`p_g` 기준과 `sigma`를 자체 선택) 중 개발 12월의 기계 동일 가중 Brier가 가장 낮은 **원래 `p₀`**를 주 기준선으로 동결했다. 후보 12개와 실패한 전역 이동 후보의 점수는 모두 개발 선택 JSON에 남아 있다.

## 점수 전 감사

수집 전 규약·개발 선택·수집기·정규화기·후보 생성기·평가기·원래 모델 명세의 SHA가 고정값과 일치했다. [점수 전 감사](../artifacts/philly_machine_calibration_v1/test_dry_run.json)는 미래 GPU 값을 **집계 양성·음성 게이트에 내부 사용**했지만, 행별 정답과 모델 점수는 저장하거나 방법 선택에 사용하지 않았다. 42기계 중 33기계가 12월 주층 판단을 제공했다. 주층 후보와 미래 완결 판단은 각각 599,752개, 집계 양성 144,362개·음성 455,390개, 양성 UTC 날짜 15개였다. 기계별 폭 제외 0, 미래 관측률 및 입력 유효창 비율 100%, 양·음 기계 수와 두 고정 반구간 조건이 모두 충족됐다. 원본·정규화·후보 특징/관측성 fingerprint가 채점 직전 다시 일치함을 확인했다. 독립 리뷰어가 해시·행수·집계 게이트를 별도로 재계산한 뒤 동결 점수를 한 번 실행했다.

따라서 이 기계별 교정·보류 방법의 **독립 개선은 확인되지 않았다.** 새 시험을 보고 `sigma`, 게이트, 기준 확률 또는 주 기준선을 다시 고르지 않는다. 이 관측 위험 신호를 실제 배포·스케일링 판단에 사용할 때는 원래 동결 모델을 기준으로 유지하고, 기계별 확률 적응의 성능 주장은 별도 독립 클러스터나 실제 AI-App 운영·SLO 자료가 확보된 뒤 다시 시험해야 한다.
