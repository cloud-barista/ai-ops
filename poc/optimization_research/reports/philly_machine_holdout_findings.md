# Philly GPU 위험 예측: 처음 보는 기계에서의 고정 모델 평가

## 결론

기존 21개 기계만으로 학습·선택한 통합 로지스틱 모델은 **겹치지 않는 37개 기계**의 2017년 12월 주 시험층 741,597건에서, 기존 검증으로 선택한 `state_recent` Beta 확률표보다 30분 내 GPU 80% 이상 사용률 사건을 더 정확하게 예측했다. Brier는 **0.089879 → 0.077783**(상대 **13.46%** 감소)이며, [사전 고정 성공 기준](philly_machine_holdout_protocol_draft.md)을 모두 통과했다. 이는 동일 Philly 클러스터·같은 시험 기간의 다른 원시 기계 ID로 위험 확률이 전이된 결과다. 실제 VM 증설·축소의 이득이나 사용자 SLO 개선을 뜻하지 않는다.

## 자료와 동결 절차

- 출처는 Microsoft Research의 [Philly GPU 추적 자료](https://github.com/msr-fiddle/philly-traces/blob/29a1b87fa2d9ed80b83c9e3a37f3a88d382b031d/README.md)다. 원본 아카이브 SHA256 `2037ccf63a725a02be718b0e1aeee6142c90b7f62d0d849295120e9f6ba13d2c`를 전체 검사했다.
- 신규 모집단은 학습·검증·기존 시험에 쓰인 해시 버킷 `<5`와 겹치지 않는 `[5,15)`다. 47기계의 원시 4,040,392행을 감사했고 38기계가 시험 날짜에 활동했다. 폭 품질로 제외한 기계는 없었다. [점수 전 감사](philly_machine_holdout_dry_run_gate.md)의 주 시험층은 37기계·741,597건·양성 114,906건으로 모든 사전 게이트를 통과했다.
- 모델과 기준선은 새 기계 값을 열기 전에 [동결 기록](philly_machine_holdout_protocol_frozen.md) 및 [모델 명세](../artifacts/philly_machine_holdout_model_v1/model_spec.json)로 고정했다. 기존 시험 예측 217,750건을 같은 키에서 재현한 뒤 새 표본을 수집했다. 기존 시험 결과를 이미 본 뒤 통합 모델을 골랐으므로, 이번 평가는 **그 선택된 모델의 기계 간 후속 확인**이다.
- 점수 전 감사 `dry_run_audit.json` SHA256: `0f3cee25bc763453c6b654d8c18aeecd7df456f4f6677cc3fdf69f08a55f9ff9`. 최종 [지표 JSON](../artifacts/philly_machine_holdout_score_v1/metrics.json) SHA256: `0bce9c01c7b66bba1fd15d9d303f149f000068e312badc4a4373a57dfd588e70`; 행별 예측 (`../artifacts/philly_machine_holdout_score_v1/test_predictions.parquet`) SHA256: `3907dcfde07f7127157ac5c4a5705df7d1790e11a197b726aa66aed06f3aed6c`.

## 주 시험 결과: 완전 과거·현재 80% 미만

| 지표 | 통합 로지스틱 | 고정 Beta 기준선 |
| --- | ---: | ---: |
| Brier, 낮을수록 좋음 | **0.077783** | 0.089879 |
| Average precision | **0.707340** | 0.457322 |
| 각 날짜 확률 상위 5%를 합친 경보 recall | **0.296129** | 0.253886 |
| 같은 경보의 precision | **0.917516** | 0.786631 |

동일 기계를 짝지어 2,000회 재표집한 `Brier(로지스틱)−Brier(Beta)`는 **−0.012096**, 95% 백분위 구간은 **[−0.017790, −0.007629]**다. 기계별 Brier 차의 동일 기계 가중 평균도 **−0.010849**였다. 고정된 12월 1–7일 반구간은 **0.070943 대 0.083777**, 12월 8–15일은 **0.083581 대 0.095051**로 모두 개선됐다. 별도로 15개 UTC 날짜의 Brier 차도 모두 음수였다. 여기서 재표집 단위는 판단 행이나 GPU 슬롯이 아니라 **기계**다.

기계별로는 **32/37대에서 개선, 5/37대에서 악화**됐다. 가장 큰 악화 기계는 4,852건에서 Brier가 **0.159095 대 0.075438**이었다. 이 기계의 실제 양성률은 **13.56%**, 로지스틱 평균 예측은 **40.28%**였으므로 장비별 확률 오차가 남아 있다. 같은 클러스터의 여러 기계가 날짜별 부하를 공유할 수 있어 기계 단위 구간을 클러스터·연도 전이의 불확실성으로 해석하지 않는다.

별도 읽기 전용 검산에서 정규화된 4,040,392개 원시행의 순서, 5분 창과 미래 6창, 점수 전 정답 집계와 두 반구간 수를 재계산했다. 저장된 957,708건의 예측을 동결된 표준화 모수·회귀 계수·Beta 표에서 다시 만들어 최대 확률 오차가 로지스틱 `2.22e-16`, Beta `0`이었다. 주 지표와 시드 43의 2,000회 기계 재표집 구간도 재현했다. 원본 압축 아카이브는 보존하지 않았으므로 압축본 SHA·tar 무결성은 수집기의 전량 스트리밍 감사 기록에 의존한다.

## 보조층과 연구 범위

현재 이미 80% 이상인 완전 과거층 216,111건은 Brier **0.036977 대 0.040420**(상대 8.52% 감소)이었다. 이 층은 원래부터 고사용률 상태가 이어질 가능성이 높아 주 결론과 합치지 않는다. 부분결측층은 새 시험 후보가 0건이고 기존 학습·검증 게이트도 실패했으므로 모델 점수를 내지 않았다. 따라서 **관측 품질 입력의 고유 이득**은 이 실험으로 확인할 수 없다.

원본은 GPU 슬롯의 분당 `nvidia-smi` 사용률이다. 예측 정답은 30분 내 5분 평균 사용률 80% 이상이며, 실제 사용자 지연, 응용 SLO 위반, VM 용량 부족의 원인 또는 `SCALE_OUT/IN` 조치의 효과가 아니다. 경희대 판단기의 **위험 입력 신호**로는 검증됐지만 운영 조치로 연결하려면 실제 응용 요청·자원·명령·결과가 연결된 별도 자료가 필요하다. 다음 모델 변경은 이 신규 홀드아웃을 탐색 자료로 재분류하고 새로운 미사용 기계나 기간에서 다시 확인해야 한다.
