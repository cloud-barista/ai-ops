# HAS-GPU 요청별 30초 미래 지연 예측: 학습 모델 미채택

**결론:** [고정 프로토콜](has_gpu_request_p95_30s_protocol.md)의 4계열 전체 제외 평가에서 Ridge는 과거 p95 유지 기준선보다 나빴다. 동일 가중 계열 평균 MALE은 유지 기준선 **0.395**, 훈련 평균 변화율 **0.400**, Ridge **0.738**이었다. 20% 초과 과소예측률도 각각 **8.9%, 8.9%, 24.6%**였다. 따라서 이 자료에서 학습한 Ridge를 경희대 배포·스케일 판단 입력으로 채택할 근거가 없다. 이 결과를 본 뒤 특징·임계값을 바꿔 같은 창의 점수를 재사용하지 않는다.

## 원본·게이트·평가 단위

[HAS-GPU 공식 Zenodo 아티팩트](https://zenodo.org/records/15596511)와 동일한 SHA-256의 요청 CSV 18개를 [공식 GitHub 고정 커밋](https://github.com/KontonGu/HAS-GPU/tree/31f8ea29ca184193dbc7523736d77c817ddce980)에서 받았다. CC BY 4.0 출처는 [소스 기록](../artifacts/has_gpu_request_p95_30s_v1/source_csv/SOURCE.md)에 명시했다. [고정 목록](../artifacts/has_gpu_request_p95_30s_v1/frozen_manifest.json)은 요청 멤버 18개의 경로·SHA-256, 감사 JSON·프로토콜·코드·테스트의 SHA-256을 담는다. GPU 기록은 받거나 특징으로 사용하지 않았다. 원본의 모든 선택 행은 `status_code=200`, `success=True`, 해당 계열의 고정 `mode` 조건을 통과했다.

첫 완료 시각부터 30초마다 잡은 후보 중 과거 30초 **완료** 요청과 미래 30초 **시작** 요청이 각각 100건 이상이고, 미래 창 뒤에 완료 기록 30초가 더 남아 있는 창만 선택했다. [건수 전용 게이트](../artifacts/has_gpu_request_p95_30s_v1/count_gate.json)는 BERT 8실행·61창, ResNet 4·24창, ConvNeXt 3·18창, MobileNet 3·18창으로 **총 121개 비중첩 창**을 확인했다. 네 계열 모두 사전 조건인 적격 실행 3개·창 15개 이상을 충족한 뒤에만 [점수 파일](../artifacts/has_gpu_request_p95_30s_v1/scores.json)을 한 번 계산했다. 요청 `timestamp`는 완료 시각이므로 시작 시각은 `timestamp-duration`으로 근사했다.

목표는 미래에 시작한 요청의 HTTP 왕복시간 p95와 과거에 완료된 요청 p95의 로그 비율이다. MALE은 예측·관측 미래 p95 로그비의 절댓값 평균이며 낮을수록 좋다. 과소예측률은 `예측 p95 < 0.8 × 관측 p95`인 창의 비율이다. 계열 전체를 시험에서 제외하고 나머지 계열로만 훈련했다. 수치는 먼저 실행별 창 평균, 다음 계열별 실행 평균, 마지막 4개 계열의 동일 가중 평균이다.

| 제외 계열 | 실행·창 | 과거 p95 유지 MALE / 과소예측 | 훈련 평균 변화율 MALE / 과소예측 | Ridge MALE / 과소예측 |
| --- | ---: | ---: | ---: | ---: |
| BERT | 8 · 61 | 0.707 / 11.9% | 0.718 / 11.9% | 1.523 / 74.8% |
| ResNet | 4 · 24 | 0.450 / 12.5% | 0.460 / 12.5% | 0.609 / 12.5% |
| ConvNeXt | 3 · 18 | 0.363 / 11.1% | 0.363 / 11.1% | 0.483 / 11.1% |
| MobileNet | 3 · 18 | 0.059 / 0.0% | 0.059 / 0.0% | 0.339 / 0.0% |
| **계열 동일 가중 평균** | **18 · 121** | **0.395 / 8.9%** | **0.400 / 8.9%** | **0.738 / 24.6%** |

Ridge의 MALE은 네 계열 모두에서 과거 p95 유지보다 컸다. BERT 제외 fold에서 Ridge의 20% 초과 과소예측률은 74.8%였으며, 유지 기준선은 11.9%였다. 이는 모델 계열이 바뀔 때 현재 네 요청 요약 특징의 전이가 불안정하다는 **이 실험 내 관찰**이다. 원인이나 다른 장비에서의 실패율로 일반화하지 않는다.

**사후 기술 점검:** BERT 창의 과거 p95 중앙값은 1.735초로 ResNet 0.140초, ConvNeXt 0.113초, MobileNet 0.112초와 차이가 컸다. BERT 61창 중 54창은 `log(과거 p95)`가 훈련 세 계열의 관측 범위를 벗어났다. 미래/과거 p95 비율의 BERT p10~p90도 0.358~13.127로 MobileNet 0.929~1.070보다 넓었다. 이는 입력 범위 차이가 실패에 관여했을 **가능성과 일치하지만 원인을 증명하지 않는다**. 이 점검을 근거로 고정 점수의 모델·특징을 수정하지 않았다.

## 해석 범위

미래 요청 수로 적격 창을 고른 평가이므로 결과는 **나중에 확인된 활성 부하 창**에만 해당한다. 요청 기록에 없는 미완료 요청은 30초 여유 조건으로도 완전히 배제할 수 없다. 자료·목표는 앞선 구조 감사를 본 뒤 정했으며, 동일 환경의 네 계열을 제외 평가한 결과는 독립 외부 검증이 아니다.

이 자료에는 스케일 명령 발행 시각, Pod/VM Ready 시각, 대체 조치 결과가 없다. 지연 예측 실패나 성공을 `SCALE_OUT/IN`의 효과, 적절한 GPU 수, 운영 SLO 달성으로 해석할 수 없다. 실제 판단 연구를 이어가려면 [사건 데이터 계약](scale_effect_data_contract_v1.md)에 명시한 명령·준비·요청 연결 자료가 필요하다.

검증: 합성 누출·경계·검열·계열 제외 테스트 8개와 문법 검사를 통과했다. 별도 읽기 전용 계산에서 고정 Ridge의 예측값은 scikit-learn `StandardScaler` + `Ridge(alpha=10)` 결과와 모든 제외 계열에서 최대 절댓값 차이 `3.55×10⁻¹⁵` 이내로 일치했다. 고정 결과 `scores.json` SHA-256은 `877919c2363e4f718ffc4057d07fd614684acfa3ecba6fc4bae452705eec354d`다.
