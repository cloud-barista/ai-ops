# GenTD26 파이프라인 업데이트 지연 예측: 점수 전 규약

작성: 2026-09-28. 이 문서는 시험 점수를 계산하기 전에 고정한다. 이미 공개 자료의 전체 행 수, 시각·컨테이너 분포, 지연의 전체 분위수와 0값 건수는 감사했다. 따라서 이 시험은 새로운 서비스에 대한 독립 검증이 아니라 **한 공개일 내의 시간순 탐색**이다.

## 질문과 관측 정의

Alibaba GenTD26의 `pipeline_update_latency_anon.csv`가 기록한 다음 파이프라인 적재·전환 지연의 90백분위 상한을, 해당 기록 시각보다 **최소 5분 이전**에 관측된 파이프라인 이력과 컨테이너 GPU·메모리 상태로 예측한다. 기록은 36,046행, 132개 익명 컨테이너, 약 22.42시간이며 0ms가 2,622행이다. 0ms의 뜻은 공개 문서만으로 확정할 수 없으므로 모두 포함한다. 목표 단위는 원본의 밀리초다.

이 자료에는 업데이트 명령의 발행 시각·종료 시각·모델 ID·버전 ID·사용자 SLO·VM 전환 로그가 없다. 기록 시각을 정확한 개시 시각으로 해석하거나 예측값을 실제 `UPDATE` 실행시간/자동 승인으로 사용하지 않는다. 같은 `(container_ip, timestamp_anon)` 키에 있는 Base·LoRA·ControlNet 지연은 동시/사후 값일 수 있고 가산식도 일관되지 않으므로 **입력에 넣지 않는다**. 사용자 요청 CSV와 모니터링 CSV의 익명 시각축도 맞지 않으므로 연결하지 않는다.

## 고정 분할과 시점 제한

- 최초 파이프라인 시각 `t0=1662858777`초. 학습 구간 `[t0,t0+8h)`, 검증 `[t0+8h,t0+12h)`, 시험 `[t0+12h,끝]`로 나눈다. 원자료 후보는 차례로 24,767/8,355/2,924행이다. 시험 전반 `[12h,16h)`은 2,210행, 후반 `[16h,끝]`은 714행이다.
- 학습 모델에는 `t <= t0+8h−300s`의 정답만 사용한다. 검증 선택에는 `t <= t0+12h−300s` 정답만 사용한다. 같은 5분 보류 규칙은 과거 이력 특징과 온라인 기준선에도 적용한다. 기록 시각이 종료 시각이어도, 시작 시각이어도 이 여유는 원본 최대 기록 지연 약 108초보다 길다. 실제 피드백 가용 시각은 기록되어 있지 않아 이 조건은 보수적인 **가정**이다.
- GPU duty, GPU 메모리 사용량, 컨테이너 메모리 사용률은 같은 익명 컨테이너의 `t−300s` 이하 마지막 계측만 조회한다. 조회 지점보다 10분 넘게 오래된 값은 결측으로 둔다. 결측은 미래값이나 0으로 채우지 않는다. IP 자체, 현재/미래 구성요소 지연, 현재/미래 파이프라인 지연은 입력에서 제외한다.
- 파이프라인 과거 이력은 전역 최근 1·4시간의 표본 수·중앙값·p90, 같은 컨테이너 최근 4시간의 표본 수·중앙값·p90·직전 지연·마지막 관측 후 시간으로 구성한다. 각 통계는 보류 시각 전에 알려진 기록만 쓴다. 새 컨테이너의 과거는 결측으로 둔다.

## 비교와 선택

1. 단순 기준 후보: 학습 구간 고정 전역 p90, 전역 최근 1시간 p90, 전역 최근 4시간 p90, 컨테이너 최근 4시간 p90과 전역 최근 4시간 p90의 혼합(`n/(n+κ)`, `κ=20` 또는 `100`). 과거 창이 비면 학습 구간 고정 p90을 사용한다. 검증 pinball 손실 최저 후보 하나를 **시험 전** 선택한다.
2. 학습기 두 개: 같은 `HistGradientBoostingRegressor`의 90백분위 회귀. 이력 특징만 쓴 모델과 GPU/메모리 상태를 추가한 모델을 각각 고정해 비교한다. `max_iter=120`, `max_leaf_nodes=15`, `min_samples_leaf=50`, `learning_rate=.05`, `l2_regularization=10`, `random_state=42`. 두 모델 모두 첫 8시간의 가용 학습행으로만 적합한다. 검증 후 재학습·초모수 변경을 하지 않는다.
3. 주 비교는 **상태 추가 모델**과 검증 선택 단순 기준선이다. 보조 비교는 상태 추가 모델과 이력 전용 모델이다. 지표는 p90 pinball 손실, 실제값이 예측 상한 이하인 비율, 평균 예측 상한, 30분 블록별 손실 및 컨테이너별 손실이다. 30분 블록 재표집은 같은 하루 안의 상관만 반영한다.

연구용 채택 기준은 시험 전체 pinball 손실이 단순 기준보다 최소 5%, 이력 전용 학습기보다 최소 2% 낮고, 전체 포괄률 88% 이상, 고정 시험 전·후반 각각 85% 이상이며, 두 반구간 모두 단순 기준보다 pinball 손실이 낮은 것이다. 시험 행이 1,000개 미만이거나 사전 GPU·메모리 세 계측 중 어느 것의 시험 적격률이 95% 미만이면 상태 추가 효과 평가를 중단한다. 하나라도 실패하면 이 모델은 업데이트 판단기에 채택하지 않는다. 이 기준을 통과해도 실제 배포·스케일 효과는 입증되지 않는다.
