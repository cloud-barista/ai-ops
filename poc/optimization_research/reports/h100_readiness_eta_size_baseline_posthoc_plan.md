# 준비시간 상한의 모델 크기 직선 기준선: 점수 후 반증

2026-09-29. [첫 규약](h100_readiness_eta_protocol.md)과 [첫 점수](../artifacts/h100_readiness_eta_v1/metrics.json)를 이미 고정·열람한 뒤 더 강한 단순 비교가 필요함을 확인했다. 첫 점수의 `phase_p90`과 `phase_cache_p90`은 모델 크기를 무시한다. 아래 두 기준선은 **사후 추가**하며 첫 사전 채택 게이트를 소급 수정하거나 독립 검증이라 부르지 않는다. 첫 규약·스크립트·아티팩트는 덮어쓰지 않는다.

각 모델 크기 전체 제외 분할과 여섯 시작 단계는 첫 시험과 동일하다. `size-linear` 기준선은 donor의 `모델 명목 크기(B) → 해당 단계부터 /health까지 남은 초`에 절편 포함 최소제곱 직선을 적합하고, donor의 **같은 행**에서 `실측−직선 예측` 잔차의 경험적 90분위를 더한다. 결과가 음수면 0초로 자른다. `no-cache`는 단계별 150개 donor trial로 한 직선과 여유를 적합한다. `oracle-cache`는 단계×C0–C4별 30개 donor trial로 각각 적합한다. NumPy `lstsq`와 선형 보간 분위수를 쓰며 보류 모델의 라벨은 적합·여유 계산에 넣지 않는다. 이 기준선은 현재 단계까지의 경과시간도 사용하지 않으므로, 원래 QuantileRegressor의 모델 크기·단계 진행시간 특징에 대한 간단한 크기 법칙 비교다. 캐시 조건은 여전히 실제 운영에서 관측되지 않은 오라클이다.

원래 1,200개 행과 정확히 결합해 전체·보류 모델별·단계별·조건별 90분위 pinball, 피복률, 5/10초 초과 과소예측을 나란히 기록한다. 모델을 단위로 한 승패와 원래 5%·과소예측·3/4 분할 기준을 **진단값으로만** 계산한다. 네 Qwen3 크기·한 H100·한 날, 조건/실험 묶음 교란 및 단계 이벤트의 온라인 `available_at` 부재 때문에 수치가 좋아도 운영용 준비시간 상한이나 배포 명령 판단으로 승격하지 않는다.
