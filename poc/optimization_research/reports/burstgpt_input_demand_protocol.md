# BurstGPT 대화 로그의 1시간 입력 토큰 수요: 점수 전 규약 v1

**범위.** 경희대 응용 요구사항 분석 모듈에 줄 수 있는 *기록된 요청 수요*의 90백분위 신호를 평가한다. `BurstGPT_3.csv`의 `ChatGPT` 및 `GPT-4` **`Conversation log` 두 집단만** 사용한다. 판단 대상은 상대시간 시간칸 `h`에 제출된 요청의 `Request tokens` 합계 `V[h]`다. 이 값은 GPU 사용량·필요 GPU 수·VM 형상·SLO 위반·`SCALE_OUT/IN` 효과의 정답이 아니다. 원자료에는 로그 완전성을 증명할 heartbeat가 없다. 요청이 없는 시간칸의 `V=0`은 **기록된 요청 0건**을 뜻할 뿐 실제 서비스 수요 0건의 증거가 아니다. `Request tokens=0`인 기록은 요청 수에는 포함하고 토큰 합계에는 0을 더한다.

## 출처·기존 노출·잠금

- [저자 공개 BurstGPT v2.0](https://github.com/HPMLL/BurstGPT/releases/tag/v2.0)의 로컬 원본은 `BurstGPT_3.csv` (`../data/external/burstgpt_v2/BurstGPT_3.csv`)이며 크기 **231,682,327 B**, SHA256 **`2299986a07388aa303ec2c41d1131e756db650a39ed6ef9dfe7cc3d7f9a43b8f`**다. 열은 `Timestamp,Session ID,Elapsed time,Model,Request tokens,Response tokens,Total tokens,Log Type`다. 기존 전량 감사 (`../data/external/burstgpt_v2/audit.json`)는 상대일 225–334에 5,344,021개 요청, 상대일별 요청 수와 모델×호출유형 총수를 이미 공개했다. 규약 초안을 쓴 뒤 별도 원본 점검에서 시험 마지막 두 행을 `tail -2`로 우연히 봐서, day 334의 ChatGPT Conversation 입력 700토큰과 GPT-4 API 입력 1,386토큰도 노출됐다. 이 두 값은 방법 선택에 쓰지 않았다. 따라서 이번 시험을 완전한 미개봉 정답 시험이라고 부르지 않는다. **시간별 미래 입력 토큰량의 모델별 예측 점수**는 아직 계산하지 않았다.
- 시간은 원본 `Timestamp`의 **추적 상대 초**다. 절대 UTC 날짜·요일은 알려져 있지 않다. 시간칸은 `h=floor(Timestamp/3600)`, 상대일은 `floor(Timestamp/86400)`으로 정하며 시각 순서를 바꾸지 않는다. `hour%24`는 상대시각의 하루 위상일 뿐 UTC 시간이나 실제 요일이 아니다.
- 코드·합성 테스트·이 규약·출처·기존 감사 및 Python/numpy/scikit-learn 버전을 `freeze_manifest.json`의 해시로 고정한다. 동결 모드는 원본을 **해시로만** 읽으며 정답을 파싱하지 않는다. 학습·검증 모드는 manifest 무결성을 확인한 뒤 `day<285` 행까지만 해석한다. 원본이 시간순이므로 첫 `day≥285`에서 중단한다. 시험의 행별 입력 토큰량을 읽거나 집계하지 않는다. 기존 산출물은 덮어쓰지 않는다. 별도 시험 채점기·승인 규약이 동결되기 전에는 `day≥285`를 채점하지 않는다.

## 시점·정답·입력

- 학습 상대일 **225–264** (`h=5400..6359`), 검증 **265–284** (`h=6360..6839`), 시험 **285–334** (`h=6840..8039`)이다. 두 집단에서 모든 정시 시간칸을 열거한다. 기록이 없는 칸도 로그상 0으로 남기며 사후 정답 관측성에 따라 평가행을 선택하지 않는다.
- `h` 시작에서 `[h,h+1)`의 토큰 합계 `V[h]`를 예측한다. 한 시간 집계가 끝나고 **추가 한 시간 뒤 게시된다**고 보수적으로 가정한다. 따라서 `h`의 입력에 사용할 수 있는 최신 칸은 **`h−2`**다. 이 전달 지연은 추적에 실제 기록된 값이 아니며 적용 가능성의 가정이다. 학습 전 가용 정답은 `h+2≤6360`인 `h≤6358`뿐이다. 첫 학습 후보는 24시간 과거를 확보한 `h=5425`다. 따라서 집단당 학습 후보 **934시간**, 검증 **480시간**, 시험 **1,200시간**이 고정된다. 시험의 후보 수는 정답값을 보지 않고 계산할 수 있다.
- 특징에는 `h−2,h−3,h−4,h−24`의 요청 수와 입력 토큰 합계, `h−25..h−2` 24시간의 토큰 평균·90백분위·기록이 있는 시간 비율, 상대시각 하루 위상 `sin/cos`만 넣는다. 토큰 관련 수치 특징은 `log1p`로 변환한다. `h−1`, `h` 또는 그 이후의 기록·응답 토큰·완료시간·세션 ID는 특징으로 쓰지 않는다. 빈 칸은 요청 수 0·토큰 합계 0으로 표시하고, 실제 0토큰 요청과 구별하기 위해 요청 수를 별도로 유지한다. 서로 다른 집단을 합쳐 하나의 응용처럼 만들지 않는다.

## 고정 기준선·학습기·선택

모든 확률적 상한과 보정량은 각 집단의 **학습 후보 934건만** 사용한다. 경험적 분위수는 NumPy의 `quantile(q, method="higher")`로 고정한다. 각 예측은 음수면 0으로 자른다.

1. `train_fixed_p90`: 학습 `V[h]`의 고정 90백분위.
2. `last_available_residual_p90`: `V[h−2] + Q₀.₉(train V[h]−V[h−2])`.
3. `same_hour_yesterday_residual_p90`: `V[h−24] + Q₀.₉(train V[h]−V[h−24])`.
4. `trailing_24h_p90`: `V[h−25..h−2]`의 시점별 90백분위. 보정·학습은 없다.

제안 학습기는 **집단별로 따로** 맞춘 `HistGradientBoostingRegressor(loss="quantile", quantile=0.9, max_iter=80, max_leaf_nodes=7, learning_rate=0.05, min_samples_leaf=20, l2_regularization=1.0, random_state=42)`다. 전처리·모델은 학습 시간칸에만 적합하고, 검증 중 재학습하지 않는다. 다른 하이퍼파라미터나 사후 계수 탐색은 하지 않는다.

## 점수 전 지원량 게이트·검증 판단

manifest를 확인한 뒤 학습·검증의 집단별 요청 수, 0토큰 요청 수, 기록이 있는 시간칸 수와 일수만 먼저 감사한다. 각 집단의 학습은 **≥30개 상대일**, 검증은 **≥15개 상대일**에 기록이 있어야 하며, 학습의 960칸 중 **≥70%**, 검증의 480칸 중 **≥70%**가 한 건 이상 기록돼야 한다. 실패하면 모델을 맞추거나 검증 손실을 계산하지 않는다. 시간칸의 무기록이 실제 무부하인지 알 수 없다는 제한은 이 게이트를 통과해도 남는다.

통과하면 검증 20일·집단당 480개 시간칸에서 90백분위 pinball 손실과 `V≤예측` 피복률을 계산한다. 두 집단의 평균 손실을 같은 가중치로 평균한다. 기준선은 네 방법 가운데 검증 평균 손실이 가장 낮은 것을 **위 순서로 동률 처리**해 한 번 선택한다(`≤10⁻¹²` 차는 동률). 학습기 채택 조건은 선택 기준선보다 검증 평균 손실이 **상대 ≥5% 낮고**, 두 집단 각각 손실이 낮으며, 두 집단의 피복률이 각각 **≥85%**이고, 두 집단을 동일 가중한 일자별 손실에서 **20일 중 ≥12일** 이기는 것이다. 실패하면 학습기는 요구 신호에 채택하지 않고, 이 실험의 시험 채점을 중단한다. 성공해도 관측 로그의 수요 예측 후보일 뿐이다. 검증 뒤 기준·특징을 바꾸면 이후 같은 시험은 탐색 평가로 표기한다.

검증을 통과해 별도 시험 프로토콜·채점기·선택 결과와 모델 파일의 해시를 고정한 경우에만 상대일 285–334의 시간별 정답을 연다. 시험 전에 기록의 소실을 직접 식별할 방법이 없으므로 각 집단의 **기록 있는 시간 비율·일수**를 집계해 보고하며, 성능은 *기록된 토큰량*에만 제한한다. 50일을 10개의 연속 5일 블록으로 표시하고 집단별 손실·피복률·무기록 시간 비율을 함께 보고한다. 이 시험이 통과해도 실제 토큰 처리량, GPU 수량, VM 생성·삭제 효과나 서비스 SLO를 추정한 것은 아니다.
