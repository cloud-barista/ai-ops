# 조건별 비대칭 승인 여유값: 같은 승인 수에서 이득 없음

## 질문과 방법

기존 K8 공분산 예측의 지연·요청/초 오류를 단일 여유값 대신 **높은 수요 여부와 GPU replica 수별로 다르게 보정**하면, 같은 수의 배포를 승인하면서 실제 SLO 위반을 줄일 수 있는지 시험했다. [사전 규약](asymmetric_margin_preregistration.md)에 분위수 75%, 높은 수요의 기준(batch ≥12 또는 최대 길이 ≥512), 네 조건, donor 4모델 상당의 전역 수축, 공통 고정 로그 여유값 0.05, 평가 비교를 결과 실행 전에 고정했다. 지연 오차와 요청/초 오차의 여유값은 따로 학습한다. 이미 실측한 K8 앵커 후보의 기본 운영점 마진은 0이다.

9개 모델 중 대상 H를 하나씩 제외했다. H의 K8 예측은 동결 예측 (`../artifacts/cross_model_covariance_v1/predictions.parquet`)을 사용했다. 마진 보정은 나머지 8모델을 4/4 모델 단위로 교차 적합해 만들었다. pseudo-target D마다 H와 D를 모두 뺀 네 모델로 절대·자원반응 예측기와 donor OOF 공분산을 다시 학습했다. D에서는 원래와 같은 GPU1·CPU2 앵커 8개만 측정했다고 가정한다. **기존 donor의 LOOMO 예측 파일은 H를 학습에 포함하므로 보정에 쓰지 않았다.** 보정은 예측 오류 분위수만 사용하며 pseudo-target의 SLO로 방법을 고르지 않는다. 4모델 학습에서 얻은 오차가 H 예측의 8모델 학습 오차와 같다는 보장은 없는 계산량 절약 근사다.

요청/초 실측은 원본 examples/s를 batch size로 나눴다. 후보는 GPU 수, CPU 코어 수 순서로 가장 작은 예측 충족 형상을 고른다. 모든 정책은 대상 모델의 동일한 K8 측정과 동일한 예측을 사용하므로 추가 GPU 측정은 없다. 학습·추론 계산 비용은 별도로 비교하지 않았다.

## 결과

아래 *기본 운영점*은 각 방법의 고정/학습 마진을 그대로 적용한 결과다. 합성 목표 25쌍은 각 대상 H를 뺀 8모델의 실측 분위수로 정했다. 총 14,375개의 작업·목표 질의 중 실제 가능한 질의는 6,746개다. 같은 작업의 25개 질의는 서로 연관되어 있다.

| 합성 목표의 기본 운영점 | 승인 | 성공 | 잘못 승인 | 가능한 질의 누락 |
| --- | ---: | ---: | ---: | ---: |
| 조건별 비대칭 여유값 | 6,281 | 5,980 | 301 | 766 |
| 전역 비대칭 여유값 | 6,248 | 5,969 | 279 | 777 |
| 공통 고정 로그 여유값 0.05 | 6,523 | 6,059 | 464 | 687 |
| K8 0마진 | 6,717 | 6,143 | 574 | 603 |

보수적인 방법일수록 승인 수가 줄어드는 효과가 있으므로, 위 표의 잘못 승인 건수만으로 우위를 판단할 수 없다. **대상 모델마다 조건별 방법의 승인 수와 정확히 같은 수**로 다른 방법의 예측 여유도 순위를 잘라 비교하면 다음과 같다. 조건별 방법은 자기 기본 운영점의 선택을 그대로 사용한다.

| 합성 목표의 동수 승인 비교 | 승인 | 성공 | 잘못 승인 |
| --- | ---: | ---: | ---: |
| 조건별 비대칭 | 6,281 | 5,980 | 301 |
| 전역 비대칭 | 6,281 | 5,974 | 307 |
| 공통 고정 로그 여유값 0.05 | 6,281 | **5,999** | **282** |
| K8 0마진 | 6,281 | **5,999** | **282** |

조건별 방법은 전역 비대칭보다 잘못 승인 6건 적었지만, 더 단순한 고정 여유값 및 K8 순위보다 **19건 많았다**. 모델별 차이는 고정 여유값 대비 3모델 개선, 6모델 악화였다. **성공 건수의 모델당 차이(조건별 방법 − 고정 여유값)**는 평균 **−2.11건**이고, 모델 9개를 단위로 한 seed 42·10만 회 bootstrap의 기술적 95% 구간은 **[−6.67, 2.11]건**이다. 같은 SQLite에서 방법을 구성한 뒤 보는 탐색 구간이므로 확증적 신뢰구간이 아니다. 이 동수 비교에서는 실측값을 절편 선택에 쓰지 않았지만, 절편이 음수면 예측상 목표 미달 후보도 순위상 승인할 수 있다. 따라서 **배포 가능한 정책의 성능 수치가 아니라 위험 순위 진단**이다.

원본 수집기가 생성한 SLO에서도 조건별 방법의 기본 운영점은 **342승인·333성공·9잘못 승인**, K8 0마진은 **356·338·18**이었다. 같은 342승인에 맞추면 조건별 방법 9잘못 승인, 고정 여유값과 K8은 각각 **7잘못 승인**이었다. 이 원본 SLO도 독립적인 사용자 요구는 아니다.

## 판단과 재현

이 조건부 비대칭 마진은 두 위험 지표를 작업 수요와 GPU 수에 따라 학습한다는 점에서 현재 K8 추천기의 별도 결정 계층이다. 하지만 **같은 승인 수에서 단순 기준을 이기지 못했으므로 채택하지 않는다.** 4모델 교차 적합 보정의 분포 차이와 한 호스트·9모델·생성 SLO라는 범위 때문에 운영 효과 또는 일반화를 주장할 수 없다. GPU 2개는 수집기에서 두 독립 replica를 동시에 실행한 결과이며 실제 VM scale-out 전환의 관측은 아니다.

재현 자료는 [코드](../scripts/evaluate_asymmetric_margin.py), [단위 테스트](../tests/test_asymmetric_margin.py), [외부 대상 실측 변조 누출 검사](../tests/test_asymmetric_margin_leakage.py), 모델별 결과 (`../artifacts/asymmetric_margin_v1/per_model_results.csv`), [중첩 분할 기록](../artifacts/asymmetric_margin_v1/nested_split_manifest.json), [전체 지표와 SHA-256](../artifacts/asymmetric_margin_v1/metrics.json)에 있다. H의 지연을 1000배, 처리량을 1/1000, wall time을 100배로 바꾸고 중첩 보정을 재학습해도 해당 H의 donor 예측 4,088행은 기존 결과와 수치 오차 1e-12 안에서 같았다. 대상 라벨은 보정 경로에 들어가지 않았다.
