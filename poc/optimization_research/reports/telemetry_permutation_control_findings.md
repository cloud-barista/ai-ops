# GPU 1개 텔레메트리의 작업별 대응 관계: 순열 대조 실험

## 질문과 정보 경계

[이전 실험](telemetry_conditioned_scaling_findings.md)에서 GPU 1개·CPU 2코어의 모니터링 요약을 넣은 모델은 같은 호스트 GPU 2개·CPU 2코어 요청/초 예측 오차를 낮췄다. 그 개선이 **각 작업과 그 작업의 모니터링 값이 맞게 연결된 덕분인지** 검사했다. 이는 조건별 예측 정보의 대조 실험이며, 모니터링 값이 성능을 *일으킨다*는 인과 실험이 아니다.

주 캠페인 9개 모델·575작업을 대상으로 모델 ID 하나를 통째로 제외해 기존 `no_count` ExtraTrees 예측기를 매번 다시 학습했다. 학습에는 다른 모델만 들어간다. 대상 모델에서는 현재 GPU 1개 실행의 지연·요청/초와 GPU 사용률 평균·최댓값, GPU 메모리 사용 최댓값, CPU 사용률 평균을 관측하고 GPU 2개 처리량을 예측했다. 같은 4차원 텔레메트리 벡터를 대상 모델의 작업 간에 **통째로 무작위 재배치**하는 대조를 시드 32개로 반복했다. 입력 성능·작업 메타데이터·GPU 2개 평가 결과는 고정했고, 4개 텔레메트리 값의 결합 분포도 정확히 유지했다. 추가 대조에서는 배치 크기가 같은 작업 안에서만 재배치해 텔레메트리와 배치 크기의 관계를 유지했다. 대상 GPU 2개 텔레메트리와 결과는 예측기에 들어가지 않는다.

## 결과

요청/초 MALE는 각 모델의 작업 오차를 평균한 다음 9개 모델을 똑같이 가중해 평균했다. 재배치 방법의 값은 32개 시드의 평균이다.

| 입력 | 모델별 평균 요청/초 MALE ↓ | 정렬된 입력보다 오차가 컸던 시드 | 정렬이 재배치 평균보다 좋았던 모델 |
| --- | ---: | ---: | ---: |
| 기존 텔레메트리 없이 GPU 1개 성능만 사용 | 0.1120 | — | — |
| **실제 작업과 맞는 4개 텔레메트리** | **0.0961** | — | — |
| 전체 작업 간 텔레메트리 벡터 재배치 | 0.1167 | **32/32** | 7/9 |
| 같은 배치 크기 안에서 재배치 | 0.1094 | **32/32** | 7/9 |

전체 재배치의 시드별 모델 평균 오차 범위는 0.1137–0.1227, 같은 배치 크기 안의 범위는 0.1066–0.1127이었다. 정렬된 값에서 재배치 평균을 뺀 모델 평균 차이는 각각 −0.0206과 −0.0133이다. 모델 단위 재표본추출의 **기술적** 95% 구간은 각각 `[-0.0352, -0.0072]`, `[-0.0238, -0.0041]`이다. 순열 시드 32개는 독립적인 모델 32개가 아니다. 전체 결과는 모델·시드별 점수 (`../artifacts/telemetry_permutation_control_v1/per_model_metrics.csv`)에 있다.

**작업과 텔레메트리의 대응 관계에는 현재 자료의 처리량 예측에 유용한 정보가 있다.** 배치 크기만으로 설명되는 효과도 전부가 아니다. 다만 9개 모델 중 2개에서는 정렬된 입력이 재배치 평균보다 약간 나빴다. 재배치는 실제로 일어나지 않는 작업·계측 조합을 만들며, 계측값은 작업 복잡도나 실행 시간의 대리 지표일 수 있다. 따라서 이번 결과로 어느 텔레메트리 항목이 인과적으로 필요하다거나 다른 호스트·모델에서 재현된다고 말할 수 없다. 기존의 [정적 Scale-out 판단 평가](telemetry_conditioned_scaling_findings.md)에서도 처리량 오차 개선은 일관된 성공/오승인 개선으로 이어지지 않았다.

이 방법 가족과 대조 실험은 기존 결과를 확인한 뒤 설계된 **사후 탐색**이다. 순열에서 32/32 시드보다 좋았다는 순위는 조건별 예측 정보의 단서이지, 독립 검증된 학술적 독창성이나 운영 수준의 Scale-out 이득이 아니다. 데이터에는 실제 사용자 SLO, 시간 순서대로 기록된 증설 action, VM 생성·전환 비용이 없다. GPU 2개는 같은 호스트의 복제 실행이며 별도 VM 2대를 뜻하지 않는다.

재현: `OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python scripts/telemetry_permutation_control.py`.
