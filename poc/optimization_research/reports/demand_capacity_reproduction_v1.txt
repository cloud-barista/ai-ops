AI-MCMP 수요 기반 가상 용량 판단 재현

실험의 위치
- scripts/demand_capacity_policy.py: 플랫폼 중립 가상 용량 정책과 유체 대기열
- scripts/evaluate_demand_capacity_policy.py: Coding/LMM 고정 모델을 별도로 재생
- scripts/verify_demand_capacity_policy.py: 전체 행 재생, 시점 검사, 기존 예측 점수 일치
- tests/test_demand_capacity_policy.py: 준비 지연·최소/최대·축소·피드백 시점 검사
- reports/demand_capacity_protocol_v1.json: 정책·비교기·평가 가정
- artifacts/demand_capacity_v1/findings.txt: 결과와 해석
- artifacts/demand_capacity_v1/decision_replay.csv.gz: 198시나리오의 171,072개 판단
- artifacts/demand_capacity_v1/scenario_summary.csv: 시나리오 전체 요약

Python 3.9.25, scikit-learn 1.6.1, NumPy 2.0.2를 사용한다.
기존 데이터와 모델을 읽기만 하며 새 output 경로가 이미 존재하면 중단한다.

cd /home/researcher/ai-mcmp/research
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=scripts OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /usr/bin/python -m unittest discover -s tests -p test_demand_capacity_policy.py -v
PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 /usr/bin/python scripts/evaluate_demand_capacity_policy.py --research-root /home/researcher/ai-mcmp/research --output /tmp/demand_capacity_rerun
PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /usr/bin/python scripts/verify_demand_capacity_policy.py --research-root /home/researcher/ai-mcmp/research --output /tmp/demand_capacity_rerun

경희대 담당 항목과의 대응
- 배포·Scale-out/in 판단: 기존 학습 수요를 KEEP/SCALE_OUT/SCALE_IN/ABSTAIN 판단에 연결한 탐색 실험.
- 운영 피드백 추론 최적화: 완료된 이전 창의 수요 예측 잔차를 사용한 양수 q90 보정.
- 자동화 에이전트 핵심: 판단 상태·보류·최소/최대·준비 대기를 실행 기능과 분리.

이 단계는 토큰 용량 연구다. 실제 Deployment Spec, GPU/VM 개수, 사용자 지연, 실제 가격을 생성하지 않는다.
관측 시각과 수집 가능 시각은 같다고 가정한다. INNO·ETRI 원본 사건이 연결되면 별도 Adapter와 검증이 필요하다.
Philly·Alibaba 위험 신호는 Azure 요청과 같은 앱으로 결합하지 않는다.
원시 모델과 자료는 그대로 보존하고, 학습이나 최종 운영 정책 채택으로 소개하지 않는다.
