# BurstGPT 1시간 출력 토큰 수요: 검증 단계 NO-GO

2026-09-28. **학습기를 경희대 요구사항·스케일링 판단의 상한 신호로 채택하지 않는다.** 기록된 대화 요청의 다음 한 시간 출력 토큰 합계를 예측한 학습기는 단순 기준선보다 q90 pinball 손실이 낮았지만, 두 집단 모두 [검증 전 탐색 규약](burstgpt_output_demand_protocol.md)의 피복률 85% 문턱을 통과하지 못했다. 상대일 285–334의 **시간별 출력 합계 정답은 파싱하거나 점수화하지 않았다.**

## 출처·시점·지원량

[공식 BurstGPT v2.0 원본](../data/external/burstgpt_v2/SOURCE.md) `BurstGPT_3.csv`의 SHA256은 `2299986a07388aa303ec2c41d1131e756db650a39ed6ef9dfe7cc3d7f9a43b8f`다. `ChatGPT`·`GPT-4`의 `Conversation log`를 따로 집계했고, 출력 0인 요청과 무기록 시간칸도 임의로 제거하지 않았다. 훈련 day 225–264, 검증 day 265–284이며 `h` 예측에는 `h−2` 이하의 로그만 썼다. 출력 로그의 실제 전달 시각이 없으므로 두 시간 피드백 경계는 **가정**이다.

학습 전 첫 패스는 시각·모델·로그 유형으로 요청 수와 기록 시간만 집계했다. 지원량이 통과한 뒤 두 번째 패스에서 입력·출력 토큰을 파싱했다. 두 패스 모두 시험 첫 행의 시각만 파싱하고 중단했다. 학습 가능한 성숙 정답은 집단당 **934시간**, 검증은 **480시간**이다.

| 집단 | 학습 40일 요청 / 기록 시간 | 검증 20일 요청 / 기록 시간 | 출력 0 요청, 학습 / 검증 |
| --- | ---: | ---: | ---: |
| ChatGPT 대화 | 35,700 / 836·960 (87.08%) | 22,508 / 439·480 (91.46%) | 472 / 85 |
| GPT-4 대화 | 17,726 / 848·960 (88.33%) | 11,725 / 435·480 (90.63%) | 329 / 140 |

두 집단 모두 학습 40일·검증 20일에 기록이 있고 기록 시간 ≥70%로, 사전 지원량 게이트는 통과했다. `Response tokens=0`은 실제 무응답·실패 여부를 구분할 상태 열이 없으며, 빈 시간의 합계 0은 로그 공백과 실제 무부하를 구분하지 못한다.

## 고정 비교와 결과

네 기준선 중 검증의 두 집단 동일 가중 손실이 가장 낮은 것은 **전날 같은 시간 출력량 + 학습 잔차 q90**이었다. 학습기는 입력·출력·요청 수의 과거 기록을 사용한 고정 q90 HGB였다. 손실 단위는 한 시간에 기록된 출력 토큰이며 낮을수록 좋다.

| 방법 | 집단 동일 가중 q90 pinball | ChatGPT pinball / 피복률 | GPT-4 pinball / 피복률 |
| --- | ---: | ---: | ---: |
| 학습 고정 q90 | 2,063.240 | 1,936.175 / 85.21% | 2,190.305 / 84.17% |
| 마지막 가용 시간 + 학습 잔차 q90 | 1,847.500 | 1,793.219 / 86.46% | 1,901.780 / 87.71% |
| **선택 기준선: 전날 같은 시간 + 학습 잔차 q90** | **1,485.291** | **1,331.546 / 88.33%** | **1,639.035 / 86.25%** |
| 직전 24시간 경험적 q90 | 1,897.935 | 1,730.200 / 86.88% | 2,065.670 / 85.00% |
| **학습 q90 HGB** | **1,284.764** | **1,137.590 / 82.08%** | **1,431.938 / 82.50%** |

HGB의 집단 동일 가중 손실은 선택 기준선보다 **13.50% 낮았고**, 두 집단 각각에서도 낮았다. 집단을 동일 가중한 날짜별 손실은 **16/20일**에 HGB가 낮았다. 하지만 피복률은 ChatGPT **394/480=82.08%**, GPT-4 **396/480=82.50%**로, 두 집단 모두 필요한 **408/480=85%**에 못 미쳤다. 각 집단의 20일 중 HGB가 85%에 못 미친 날도 ChatGPT 12일, GPT-4 10일이다. 사전 네 채택 조건 중 **피복률 조건이 실패**했으므로 전체 판정은 NO-GO다. 선택 기준선도 90% 명목 상한을 일관되게 충족한 것은 아니다.

## 재현성·해석

점수 전 [동결 manifest](../artifacts/burstgpt_output_demand_v1/freeze_manifest.json)의 SHA256은 `619c799a2d10db31281fb71637ee0e0590de6af06b7a7139bdc08aa3bfdf654a`다. 규약 SHA256 `58ac2b0abb59c8a86fdcc5db3ff6b1ade45de5b48c3e48bbca5de5243f92c478`, [평가 코드](../scripts/evaluate_burstgpt_output_demand.py) SHA256 `e9482a33c58bb06d326244be3ae0eafad24a21e95d2a8fec3466c1512d3af5a0`, [합성 테스트](../tests/test_burstgpt_output_demand.py) SHA256 `2cb24d9f4c4c09b8435557f7319bb1fedbe264ee5d792b6b32d79e4f70fcd313`이다. 합성 테스트 **8개**가 통과했다. 검증 예측 CSV (`../artifacts/burstgpt_output_demand_v1/validation_predictions.csv`)의 **960행**은 두 집단 각각 연속한 480시간이며 키 중복이 없었다. 별도 읽기 전용 계산으로 모든 방법의 집단별 손실·피복률을 [보고 지표](../artifacts/burstgpt_output_demand_v1/validation_metrics.json)와 대조했고 불일치는 없었다. 저장된 결과물·동결 파일의 해시도 일치했다.

이 과제는 기존 [요청별 출력 토큰 연구](burstgpt_output_tokens_findings.md)와 [시간별 입력 토큰 수요 연구](burstgpt_input_demand_validation_no_go.md)의 **다른 라벨**인 시간별 출력 합계를 평가했다. 다만 같은 원본의 출력 분포와 요청별 시험 성적을 이미 열람한 뒤 설계했으므로 **후향적 탐색**이다. 출력 합계는 기록된 응답 길이의 합이며 실제 GPU 연산량·KV 메모리·GPU 수 또는 VM 조치 효용이 아니다. 이번 검증 실패 뒤 같은 검증 구간에서 여유값이나 특징을 반복 조정하지 않는다. 새로운 서비스·기간의 독립 수요 기록과 실제 인프라/조치 결과가 있어야 정책용 상한과 자원 판단을 평가할 수 있다.
