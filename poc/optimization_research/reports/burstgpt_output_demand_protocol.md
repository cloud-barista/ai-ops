# BurstGPT 대화 로그의 1시간 출력 토큰 수요: 검증 전 탐색 규약 v1

2026-09-28. 경희대 요구사항 분석과 배포·스케일링 판단의 **기록된 수요 신호**를 조사한다. 이 실험의 정답은 상대시간 `h`에 제출된 요청의 `Response tokens` 합계다. 이는 토큰 처리 시각, GPU 사용량, 필요한 GPU/VM 수, 사용자 SLO 위반, 스케일 조치의 효과가 아니다. 요청별 출력 토큰 연구에서 같은 원본의 일별·집단별 출력 분포와 day 315–334 시험 결과를 이미 열람했다. 따라서 이번 실험은 **후향적 탐색**이며 새 독립 검증 또는 완전히 미개봉 시험으로 주장하지 않는다. 다만 이 과제의 시간별 합계 예측 점수를 보기 전에 아래 규약과 코드를 고정한다.

## 원본·모집단·관측 경계

- [BurstGPT v2.0 원본](../data/external/burstgpt_v2/SOURCE.md) `BurstGPT_3.csv`의 SHA256은 `2299986a07388aa303ec2c41d1131e756db650a39ed6ef9dfe7cc3d7f9a43b8f`, 크기는 231,682,327 B다. 시간은 추적 시작 뒤 상대 초다. 상대일은 `floor(Timestamp/86400)`, 시간칸은 `floor(Timestamp/3600)`이다. 절대 날짜·요일은 알려져 있지 않다.
- `Model=ChatGPT`와 `Model=GPT-4`의 `Log Type=Conversation log`를 **서로 다른 두 집단**으로 유지한다. `Request tokens`와 `Response tokens`가 0인 행도 사후 선별 없이 포함한다. 기록된 요청이 없는 시간칸의 합계 0은 로그에서 관측한 0일 뿐, 실제 서비스가 유휴였다는 증거가 아니다. 원본에는 로그 heartbeat와 성공 상태가 없다.
- 학습 상대일 **225–264**, 검증 **265–284**, 잠금 시험 **285–334**. 모든 정시 시간칸을 열거한다. 이번 코드는 첫 `day≥285` 행의 문자열에서 **시각만 파싱**해 중단하고 출력 토큰 필드를 해석하지 않는다. 별도 시험 채점 모드는 만들지 않는다. 기존 [요청별 출력 토큰 실험](burstgpt_output_tokens_findings.md)은 `day 315–334`를 이미 채점했고, [입력 합계 실험](burstgpt_input_demand_validation_no_go.md)은 이와 다른 시간별 입력 합계를 평가했다.

## 시점·라벨·특징

- 매시 `h` 시작에 `[h,h+1)`에 제출된 요청의 **기록된 출력 토큰 합계 `Y[h]`**에 대한 q90 상한을 예측한다. `Response tokens`는 결과 기록이므로 요청 접수 시에는 알 수 없다. 추적에는 출력 로그의 정확한 제공 시각이 없다. 한 시간칸이 끝나고 **추가 한 시간이 지나면** 해당 칸의 요청 결과가 모두 제공된다고 가정한다. 따라서 `h` 결정에 사용 가능한 최신 결과·입력 집계는 `h−2`다. 실제 운영 환경의 피드백 지연을 입증한 가정이 아니다.
- 학습에 쓸 정답은 검증 시작 `h=6360`에 이미 가용한 `h+2≤6360`만 허용한다. 과거 24시간 특징을 확보한 첫 학습 시각은 `h=5425`, 마지막은 `h=6358`로 **집단당 934시간**이다. 검증 시각은 `6360..6839`, 집단당 **480시간**이다. `h=6359`의 정답과 `h=6839` 이후의 정답은 학습에 사용하지 않는다.
- 학습기의 특징은 각 집단의 `h−2,h−3,h−4,h−24`의 기록된 출력 토큰 합계, 입력 토큰 합계, 요청 수; `h−25..h−2` 24시간 출력 합계 평균·상위 90분위, 입력 합계 평균, 요청이 기록된 시간 비율; 상대시간 `h mod 24`의 sin/cos다. 수량 특징에는 `log1p`를 적용한다. 정해진 상대시간 위상은 UTC 시간이나 요일이 아니다. **현재·전 시간 `h`/`h−1`의 입력/출력/요청 수, 같은 세션의 미래 요청, 사후 경과시간은 특징에서 제외한다.**

## 동결된 비교 방법

집단별로 따로 적합한다. 90분위는 `numpy.quantile(..., 0.9, method="higher")`; 모든 예측은 0 이상으로 자른다. 상수·잔차 분포는 학습 934시간의 목표만으로 만든다.

1. `train_fixed_p90`: 학습 `Y`의 고정 q90.
2. `last_available_residual_p90`: `Y[h−2] + Q₀.₉(train Y[h]−Y[h−2])`.
3. `same_hour_yesterday_residual_p90`: `Y[h−24] + Q₀.₉(train Y[h]−Y[h−24])`.
4. `trailing_24h_p90`: `Y[h−25..h−2]`의 q90.
5. `quantile_hgb`: 위 특징으로 `Y[h]`를 직접 예측하는 집단별 `HistGradientBoostingRegressor(loss="quantile", quantile=0.9, max_iter=80, max_leaf_nodes=7, learning_rate=0.05, min_samples_leaf=20, l2_regularization=1.0, early_stopping=False, random_state=42)`. 학습 시간칸에서만 적합하며 검증 중 재학습하지 않는다.

네 단순 기준선 중 검증의 **집단 동일 가중 pinball 손실**이 최소인 하나를 선택한다. 손실 차이가 `≤1e−12`면 위 번호 순서로 결정한다. 학습기와 선택 기준선은 같은 960개 검증 시간칸에서 비교한다. 기준선 탐색 자체가 검증 자료를 쓰므로 검증에서의 채택 판단은 보수적으로 읽는다.

## 학습 전 지원량·검증 채택 게이트

첫 패스에서 시각·모델·로그 유형만 해석해 집단별 요청 수와 기록된 시간 수·일수를 센다. 이 단계에서는 `Response tokens`와 `Request tokens`의 숫자값을 해석하지 않는다. 각 집단의 학습 40일 중 **30일 이상**, 검증 20일 중 **15일 이상**에 요청이 있어야 한다. 학습 960시간·검증 480시간 각각 **70% 이상**에 한 건 이상 있어야 한다. 실패하면 출력 토큰 목표를 파싱하거나 학습·검증 점수를 만들지 않는다. 지원량 통과 후 두 번째 패스에서 출력 토큰과 입력 토큰을 파싱해 출력 0건도 결과 지표에 기록한다. 이 검사는 로그 완전성을 증명하지 않는다.

지원량 통과 뒤 다음 네 조건을 **모두** 만족할 때만 후속 시험 규약을 설계할 가치가 있다고 본다.

1. 두 집단 동일 가중 검증 q90 pinball이 선택 기준선보다 **상대 5% 이상 낮음**.
2. ChatGPT와 GPT-4 **각각**에서 학습기 pinball이 선택 기준선보다 엄격히 낮음.
3. 각 집단에서 `Y[h]≤예측값`의 경험적 피복률이 **85% 이상**.
4. 두 집단을 동일 가중한 일자별 손실에서 **20일 중 12일 이상** 학습기가 선택 기준선보다 엄격히 낮음.

검증에서는 집단별·날짜별 손실과 피복률을 모두 보고한다. 성공하더라도 q90의 90% 피복을 증명한 것은 아니며, 시험 전에 별도 시험 규약·선택 아티팩트를 다시 잠가야 한다. 실패하면 학습기는 현재 KHU 요구 신호로 채택하지 않고 시험 시간별 정답을 열지 않는다. 검증 결과를 보고 특징·계수·여유값을 바꾼다면 같은 검증 재사용은 별도의 사후 탐색이라고 표시한다.

## 재현·범위

`freeze`는 원본을 해시로만 읽고 규약·스크립트·테스트·버전을 잠근다. `select`는 manifest를 검증하고, 첫 패스 지원량 통과 후 두 번째 패스에서 학습·검증 목표값을 읽는다. 두 패스 모두 시험 첫 행의 문자열에서 **시각만 파싱**해 중단하며 시험 출력 토큰은 해석하지 않는다. 결과물은 별도 `poc/optimization_research/artifacts/burstgpt_output_demand_v1`에 신규 파일로 작성하며 기존 실험을 덮어쓰지 않는다. 출력 토큰 합계 예측의 성공은 미래 **기록량** 추정에만 해당한다. 하드웨어의 실제 처리속도, 프롬프트/응답별 KV 메모리, 가격, VM 생성 지연, 사용자 지연과 조치 전후 결과가 없어 GPU 수량이나 `DEPLOY/UPDATE/SCALE_OUT/SCALE_IN` 승인을 학습한 것으로 해석하지 않는다. 이 학습기는 알려진 분위수 회귀를 새 라벨에 적용한 것이며 알고리즘의 학술적 최초성을 주장하지 않는다.
