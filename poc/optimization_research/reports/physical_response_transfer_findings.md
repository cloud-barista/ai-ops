# 자원 반응의 구조 제약과 새 입력 조건 전이

## 측정값이 허용하는 제약

주 캠페인 575개 작업의 GPU 1/2개 × CPU 2/4/8/16코어 완전한 8개 후보를 비교했다. 같은 작업·CPU에서 GPU 1→2개의 요청/초는 **2,300/2,300쌍 모두 증가**했다. 증가 중앙값은 CPU 2·4·8·16에서 각각 2.30·2.16·2.02·2.01배다. 기존 공분산+조건부 ExtraTrees 예측도 이 2,300쌍 모두에서 처리량 증가를 이미 지키므로, 이 제약을 사후 투영해도 예측이 바뀌지 않는다.

지연과 CPU에는 개선 단조성을 둘 근거가 없다. GPU 1→2개의 지연 감소는 CPU 2에서 541/575쌍이지만 CPU 16에서는 297/575쌍뿐이다. CPU 2→4에서 지연 중앙값은 GPU 1에서 1.26배, GPU 2에서 3.07배로 **오히려 증가**했다. 따라서 CPU 코어를 늘릴수록 지연이 감소한다고 강제하면 관측 자료와 충돌한다. 각 자원 쌍의 수치와 방향 건수는 [진단 산출물](../artifacts/physical_response_transfer_v1/metrics.json)에 기록했다. 이 패턴은 해당 단일 호스트·수집 방식의 경험칙이며 일반적인 VM 성능 법칙은 아니다.

## 시험한 방법과 정보 경계

기존 GPU 1개·CPU 2코어 **8개 medoid 앵커**와 다른 모델의 주 캠페인 측정만 사용했다. 9개 모델을 하나씩 제외하는 외부 분할을 지켰고, 새 입력 조건인 novel-matrix·space-filling에서는 추가 앵커를 측정하지 않았다. 기존 [`cross_model_covariance_v1`](../artifacts/cross_model_covariance_v1/metrics.json) 및 [새 조건 예측](../artifacts/cross_model_covariance_external_v1/metrics.json)의 고정 K8 예측을 읽어 같은 작업·비용에서 자원 반응 부분만 바꿨다. 두 참조 예측의 스냅샷 해시와 외부 프로브 수 0을 검사한다.

다른 encoder 모델의 `log(파라미터 바이트)`, `log(배치)`, `log(입력 길이)`, `log1p(동시성)`, 추정 앵커 지연·처리량으로 2차 다항식 기반 상대 자원 반응을 Ridge로 학습했다. GPU 수의 기본 처리량 인자 `log(GPU 수)`는 유지한다. CPU 방향에는 부호 제약을 두지 않는다. **동일한 작업 종류의 다른 모델 두 개 이상이 정확한 입력 조건을 측정했다면 기존 공분산+ExtraTrees 예측을 사용하고**, 조건이 이전 모델에 없으면 기존 지연 예측과 부드러운 지연 반응을 섞는다. 처리량 예측은 그대로 둔다. 같은 종류의 donor가 없는 Qwen은 기존 예측으로 되돌린다.

Ridge 강도 `{1, 10, 100}`과 지연 혼합비 `{0, 0.5, 1}`은 각 외부 모델 분할 안에서 **donor 입력 조건을 네 부분으로 나눠** 골랐다. 모든 9개 외부 분할에서 강도 1, 혼합비 0.5가 선택됐다. donor 내부 검증 지연 MALE의 외부 분할 평균은 기존 반응 0.2068, 50% 혼합 0.1981, 순수 다항식 0.2176이다. 이 과정은 대상 모델의 미측정 결과를 사용하지 않는다. 단, **방법 가족 자체는 기존 외부 결과를 보며 탐색한 것**이므로 이번 결과를 사전 확정된 독립 검증으로 해석할 수 없다.

## 같은 작업·예산에서의 결과

지연/요청 처리량은 비앵커 후보 7개에서 모델별 평균 절대 로그오차(MALE)를 평균한 값이다. SLO 성공/위반은 원래 수집 과정에서 생성된 목표를 바탕으로 8개 후보 중 예측 가능한 최소 GPU·CPU 순서의 후보를 고른 결과다.

| 작업 조건 | 예측 방식 | 지연 MALE ↓ | 요청/초 MALE ↓ | 성공/실제 가능 ↑ | 잘못 승인 ↓ |
| --- | --- | ---: | ---: | ---: | ---: |
| 주 캠페인 575개 | 기존 공분산+ExtraTrees | 0.2381 | 0.1268 | 338/357 | 18 |
| 주 캠페인 575개 | 새 조건 지원 게이트+부드러운 지연 | 0.2381 | 0.1268 | 338/357 | 18 |
| Novel matrix 18개 | 기존 공분산+ExtraTrees | 0.3205 | 0.3607 | 12/13 | 1 |
| Novel matrix 18개 | 새 조건 지원 게이트+부드러운 지연 | 0.3105 | 0.3607 | 12/13 | 1 |
| Space filling 44개 | 기존 공분산+ExtraTrees | 0.3459 | 0.3309 | 30/33 | 2 |
| Space filling 44개 | 새 조건 지원 게이트+부드러운 지연 | 0.3329 | 0.3309 | 30/33 | 2 |

지원 게이트는 주 캠페인에서는 0개, 새 encoder 조건에서는 novel 16개·space 40개에 적용됐다. 외부 지연 차이(새 방법−기존)의 모델 단위 재표본추출 기술적 95% 구간은 novel에서 −0.0099 `[-0.0372, +0.0180]`, space에서 −0.0130 `[-0.0201, −0.0071]`이다. 모델 수가 9개이고 새 조건은 각 모델당 2개 또는 4–5개뿐이며, 이 방법은 외부 결과를 본 뒤 설계됐다. [동일 수집기 버전의 반복 측정](repeat_variability_findings.md)에서는 다른 16개 조건의 단일 실행 배치 p95 지연 로그 표준편차 중앙값이 0.168이었다. 그 값은 이번 조건의 오차 하한으로 옮길 수 없지만, 0.01 수준의 차이가 운영상 의미가 있는지는 반복 측정이 필요하다.

같은 다항식 반응으로 지연과 처리량을 **모든 자원 후보에서 통째로 교체**하면 주 캠페인 오차가 0.2432/0.1405로 커지고 성공은 337/357로 줄었다. Space filling 성공도 29/33으로 감소했다. 따라서 전체 자원 반응 대체는 기각하고, 지원 범위 밖에서 지연만 부드럽게 보정하는 가설만 남긴다. 하지만 그 보정도 현재는 **SLO 추천 건수를 늘리지 못했다**. 새 알고리즘의 일반적인 가치나 학술적 독창성을 주장할 근거로 삼지 않는다.
