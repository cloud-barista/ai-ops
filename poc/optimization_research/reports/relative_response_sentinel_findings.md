# 기준 형상 잔차와 자원 반응 잔차의 분리: GPU 2개 sentinel 실험

## 결론

**이 구성은 현재 SQLite에서 기각한다.** 기준 형상 3–5회에 GPU 2개·CPU 2코어 측정 한 번을 더해 상대 자원 반응 잔차를 전이했지만, 강한 기준 형상 8회 방식보다 예측 오차와 형상 선택이 나빴다. 이전 모델만으로 정한 신뢰도 게이트는 모델 전체 제외 9개와 BERT 네 모델 공동 제외 4개에서 **전부 닫혔다.** 게이트를 쓰면 GPU 2개 측정 결과를 해당 후보 한 칸에만 반영하며, 새로운 전이 이득은 없다. 비용도 모델 전체 제외 9개 중 7개에서 8회 기준보다 높았다.

이는 `조건 잔차 + 자원 반응 잔차 + donor 신뢰도`의 **이번 구현**에 대한 반증이다. 모든 가능한 공동 모델이 불가능하다는 결론은 아니다. 학술적 신규성은 [가장 가까운 선행연구 검토](new_novelty_candidate_review.md)와 별개로도 입증되지 않았다.

## 정보 경계와 비교

로그 성능 `y(c,r)`에서 기준 형상 `r₀=(GPU 1, CPU 2)`의 오차 `a(c)`를 기존 교차 모델 공분산으로 추정하고, `b(c,r)=y(c,r)-y(c,r₀)-예측한 상대 자원 반응`을 따로 다뤘다. 새 모델의 한 입력 조건에서 GPU 2개를 측정하고, **같은 조건의 이미 측정한 GPU 1개 결과와의 차이**로 `b`를 관측했다. 이전 모델의 `b`는 매 donor를 제외한 내부 학습 모델에서만 구했다. 조건×자원 반응의 donor 공분산을 부드러운 커널과 50:50으로 섞고 sentinel에 조건화했다. donor 의사 대상에 대한 신뢰도 임계값도 각 의사 대상을 모든 출처 모델의 잔차 학습에서 제외하는 **완전 중첩 분할**로 정했다. 바깥 보류 모델의 미측정 성능은 학습·선택·게이트에 들어가지 않는다.

GPU 2개 실행은 한 작업을 두 GPU로 분할한 속도 향상 실험이 아니다. 수집기는 GPU마다 같은 입력 프로파일을 독립 실행 (`/path/to/aiops/khu_policy_agent/live_collector.py:1591`)하고, 처리량은 두 복제본의 합, 배치 p95 지연은 두 복제본 중 큰 값 (`/path/to/aiops/khu_policy_agent/live_collector.py:1667`)으로 저장한다. 따라서 여기서 예측하는 `요청/초 = 저장된 초당 예제 수 ÷ batch_size`는 두 복제본의 **총 처리 용량**이다. `latency_p95_ms`는 실사용 요청 p95가 아닌 배치 p95다.

비교 방법은 다음과 같다.

| 이름 | 보류 모델에서 보는 결과 | 자원 반응 반영 |
| --- | --- | --- |
| `anchor_only` | GPU 1개 기준 형상 3–5회 | 기존 조건부 자원 반응만 사용 |
| `sentinel_only` | 위 기준 형상 + GPU 2개 sentinel 1회 | 측정한 후보 한 칸만 정확히 대체 |
| `global_gpu2` | 같은 측정 | sentinel의 로그 오차를 모든 GPU 2개 후보에 가산 |
| `joint_response` | 같은 측정 | donor 상대 반응 잔차를 sentinel에 조건화하여 전파 |
| `reliability_gate` | 같은 측정 | donor 내부 중첩검증이 허용할 때만 공동 전이 |
| `anchor8` | GPU 1개 기준 형상 8회 | 기존 공분산+조건부 자원 반응 |

기준 형상은 정적 입력 좌표의 medoid로 고른다. GPU 2개 sentinel은 그중 donor 모델로 예측한 측정 비용이 가장 싼 조건이다. 기준 형상 수는 3·4·5회 중 `예측 총 GPU-wall`이 8회 기준과 가장 가까운 것으로 **보류 모델의 실행 시간 조회 전에** 정한다. 비용은 실제 `wall_seconds × 사용 GPU 수`를 나중에 합산한다. 모델 전체 제외 9개와 BERT 네 모델 공동 제외를 따로 평가했다. 새 입력 조건인 novel-matrix·space-filling에서는 보류 모델을 추가 측정하지 않고 주 캠페인 프로브만 사용했다.

## 주 캠페인 결과

지연과 처리량은 모델별 비기준 후보 7개에 대한 평균 절대 로그오차를 다시 모델 평균한 값이다. 생성 SLO의 `성공/가능`은 예측 가능하다고 판단한 최소 GPU·CPU 후보가 실제 두 제약을 만족한 횟수다. 같은 보류 모델·작업·8개 후보를 비교했다.

| 분할 | 방법 | 지연 오차 ↓ | 처리량 오차 ↓ | 성공/가능 ↑ | 잘못 승인 ↓ | 모델당 평균 GPU-wall초 ↓ |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 모델 전체 제외 9개 | `anchor8` | **0.2381** | **0.1268** | **338/357** | 18 | 6.96 |
|  | `anchor_only` | 0.2680 | 0.1646 | 329/357 | **13** | **3.44** |
|  | `sentinel_only` = `reliability_gate` | 0.2675 | 0.1644 | 329/357 | **13** | 7.82 |
|  | `global_gpu2` | 0.3172 | 0.1766 | 335/357 | 20 | 7.82 |
|  | `joint_response` | 0.2824 | 0.1750 | 333/357 | 19 | 7.82 |
| BERT 네 모델 공동 제외 | `anchor8` | **0.3386** | **0.1389** | **174/180** | 6 | 3.97 |
|  | `anchor_only` | 0.3514 | 0.1606 | 173/180 | 3 | **2.04** |
|  | `sentinel_only` = `reliability_gate` | 0.3506 | 0.1603 | 173/180 | 3 | 5.44 |
|  | `global_gpu2` | 0.4637 | 0.1836 | 172/180 | **2** | 5.44 |
|  | `joint_response` | 0.5535 | 0.1808 | 168/180 | 3 | 5.44 |

생성 SLO에서 오승인이 줄어든 방식도 일부 가능한 작업의 승인 자체를 놓칠 수 있으므로, 성공과 오승인을 함께 읽어야 한다. gate는 모델 전체 제외 9회와 BERT 공동 제외 4회, 총 13개 평가 모두에서 닫혀 `sentinel_only`와 동일했다. Qwen은 같은 작업 격자의 donor가 없어 공동 전이를 시험할 수 없고 sentinel 결과 한 칸만 쓴다.

## 실제 프로브 비용

아래는 모델 전체 제외 분할의 **모델별 실제 비용**이다. 단위는 GPU-wall초. `GPU2 측정`은 `2 × wall_seconds`를 청구한 값이다. BERT 공동 제외에서 같은 모델의 실제 측정 비용은 동일하고, 기준 형상 선택 개수가 바뀐 L2-H128만 총비용이 4.10초로 달라졌다. 전체 분할·프로브 목록 (`../artifacts/relative_response_sentinel_v1/split_manifest.csv`)

| 모델 | 기준 형상 수 | 기준 측정 | GPU2 측정 | 합계 | 기준 8회 |
| --- | ---: | ---: | ---: | ---: | ---: |
| RoBERTa-base | 4 | 6.24 | 3.94 | 10.18 | 10.50 |
| Qwen2.5-0.5B | 3 | 6.17 | 11.30 | 17.47 | 16.54 |
| ALBERT-base | 3 | 5.21 | 3.77 | 8.98 | 8.92 |
| DistilBERT-base | 3 | 2.92 | 3.39 | 6.31 | 5.11 |
| BERT-base | 3 | 5.29 | 3.90 | 9.19 | 9.30 |
| BERT-L2-H128 | 3 | 0.66 | 2.93 | 3.60 | 1.62 |
| BERT-L4-H256 | 3 | 0.84 | 3.28 | 4.12 | 2.18 |
| BERT-L4-H512 | 3 | 1.05 | 3.28 | 4.33 | 2.79 |
| ELECTRA-small | 4 | 2.55 | 3.59 | 6.14 | 5.64 |

작은 BERT 세 모델은 **GPU2 sentinel 한 번만으로도** 기준 형상 8회의 전체 GPU-wall을 초과한다. 따라서 최소 4회 측정(기준 3회+sentinel 1회)을 허용한 이번 규칙으로는 이 세 모델에서 동등한 예산 비교가 물리적으로 불가능하다. 비용이 8회 기준의 ±10% 안인 다섯 모델만 나중에 골라 집계해도, `anchor8`의 지연/처리량 오차 `0.2336/0.1359`, 성공 `157/169`에 비해 공동 전이는 `0.2867/0.2016`, `149/169`였다. 이 부분집합은 **실제 비용을 보고 나눈 사후 진단**이며 독립 검정이 아니다.

## 새 입력 조건과 가상 목표

새 조건에는 측정 0회를 추가했다. 같은 9모델 분할에서 novel-matrix의 기준 8회 지연/처리량 오차는 `0.3205/0.3607`, 공동 전이는 `0.3704/0.3834`였다. space-filling에서는 `0.3459/0.3309` 대 `0.3829/0.3739`였다. 생성 SLO 성공은 novel에서 공동 전이가 `13/13`, 기준 8회가 `12/13`이지만, 단 18개 작업 중 13개만 실제 가능하고 공동 전이의 두 예측 오차는 모두 더 크다. space에서는 공동 전이 `29/33`, 기준 8회 `30/33`이다.

donor 자료의 지연·처리량 분위수로만 만든 25개 임계값 조합에서도 모델 전체 제외의 공동 전이는 가능한 질의 `6,746`개 중 성공 `6,007`, 잘못 승인 `530`; 기준 8회는 성공 `6,143`, 잘못 승인 `574`였다. 게이트는 성공 `6,048`, 잘못 승인 `469`로 더 보수적으로 판단했지만 공동 전이가 **전혀 켜지지 않았다.** 이 질의는 575개 작업을 25번 반복한 `14,375`개의 **상관된** 가상 질문이다. 일부 후보만 가능한 질의는 `3,794`, 지연과 처리량 제약이 모두 후보 판별에 작동한 질의는 `264`뿐이다. 실제 사용자 SLO의 성능 근거로 해석하면 안 된다.
