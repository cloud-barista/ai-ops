# GenTD26 컨테이너 GPU 메모리 30분 관측 피크: 시험 전 고정 규약

고정 시각: 2026-09-28. 이 문서와 코드의 SHA-256을 선택 manifest에 남긴 뒤 시험 점수를 한 번 계산한다. 아래 대상·분할·기준선·채택 기준은 시험 점수 전에 정했다. 단, 사전 적합성 진단에서 전체 trace의 시간별 급증 빈도와 0값 분포를 살펴봤으므로 이 시험은 완전한 블라인드 검증이 아니다. 시험 결과를 본 뒤 수정하면 새 탐색 실험으로 표시한다.

## 문제와 원본 의미

[Alibaba GenTD26의 고정 commit 원본 설명](https://github.com/alibaba/clusterdata/blob/8c132fb7717fbd44cf434cf81f2cd865a80072d5/cluster-trace-v2026-GenAI/README.md)은 `pod_gpu_memory_used_bytes_anon.csv`를 컨테이너별 GPU 메모리 **사용량(bytes)** 표본, `pod_gpu_duty_cycle_anon.csv`를 GPU duty 표본으로 정의한다. 익명화에 metric scaling도 포함된다. 사용 파일은 이미 수집·검증된 [`SOURCE.md`](../data/external/gentd26/SOURCE.md)의 로컬 CSV이며 SHA-256은 메모리 `0edc1ad35284b6b7236bdd2e69795052bedc302d7b295a1a32c5bb9ff4579596`, duty `b3a91d9bd9141156e66da6b8d34520602246ee043ac60b0d2172e689a3919f99`다. 메모리 161,413행·144개 익명 컨테이너, duty 157,417행·143개 컨테이너, 익명 시각 약 22.8시간이다. 같은 `(container_ip,timestamp_anon)` 키의 중복은 각 파일에서 0이고 메모리 표본 358행은 실제 저장값 0이다. 0값의 운영 의미는 확정되지 않았으므로 그대로 보존하고 별도 층으로 보고한다.

대상은 현재 배정·서비스 상태 아래 **결정 뒤 32개, 57초 간격 표본의 GPU 메모리 사용량 최대값**이다. 32×57초=30.4분이다. 원본 표기 bytes를 2³⁰으로 나눈 공개 값 GiB 단위의 90% 조건부 분위수를 추정한다. 이는 온라인 미래 피크의 모든 순간이 아니라 관측된 57초 표본 최대값이다. GPU 장치/개수·용량, 메모리 배정량, OOM, VM 스케일 명령, 실제 사용자 SLO는 없으므로 **최소 안전 VRAM, GPU 수량, Scale-out/in 효과**로 해석하지 않는다. 같은 자료를 GPU 메모리 계측 *입력*으로 사용한 기존 대기열·업데이트 연구와, 로컬 SQLite의 정적 PyTorch 예약량 연구는 정답 및 시각축이 다르다.

## 시각·정보 경계

컨테이너마다 시각순 정렬한 메모리 표본의 매 5번째 위치에서 결정 시각 `t`를 만든다(간격 285초). 결정 시각 표본을 포함한 최근 6개 표본은 **5분 가용 지연 가정** 때문에 입력에서 숨긴다. 입력 메모리 창은 `t−69×57초`부터 `t−6×57초`까지 **64개 연속 표본**(끝 시각은 `t−342초`)이고, 정답 창은 `t+57초`부터 `t+32×57초`까지 **32개 연속 표본**이다. 64개 입력, 6개 숨김, 32개 정답 사이의 모든 간격이 정확히 57초여야 에피소드가 적격이다. 이 연속성은 공개 자료의 관측 가능성을 확인하는 오프라인 품질 조건이다. 실제 수집·전달 지연의 기록은 없으므로 342초는 검증되지 않은 보수적 가정이다. 보이지 않는 6개 표본이나 미래 표본을 특징·기준선에 넣지 않는다.

`pod_gpu_duty_cycle`은 같은 컨테이너·정확히 같은 시각으로 **입력 창에 한해서** 연결한다. duty 결측은 0으로 바꾸지 않고 유효 개수/결측률로 표시하며, 통계량은 관측치에만 계산한다. 메모리·duty의 `container_ip`는 그룹 키일 뿐 학습 특징으로 넣지 않는다. 원본 메모리 0, duty 0은 결측과 구분한다. 입력 창의 끝에서 거꾸로 **6·16·32·64개 표본**을 각각 최근 약 5·15·30·60분으로 정의한다. 메모리 특징은 마지막 값, 네 구간의 평균·최대, 16·64개 표본의 표준편차, 64개 표본의 최소·경험적 90백분위·0 비율, 마지막 값에서 16번째 이전 값의 차이다. duty 추가 특징은 네 구간의 관측 평균·최대·결측률, 64개 표본의 0 비율이다. 관측 duty가 하나도 없는 구간의 평균·최대는 NaN이다. 모든 분위수는 NumPy의 선형 보간 정의를 쓴다. 모든 통계량은 창 끝 시각 이하만 읽는다. 익명 시각의 절대값·시간대·컨테이너 ID·미래 관측 개수는 모델 특징에서 제외한다.

## 분할과 기준선

전체 메모리 최소 시각을 `t₀=1662858720`초로 둔다. 컨테이너 ID UTF-8 SHA-256의 첫 8바이트를 big-endian 정수로 읽어 `%5==0`인 ID를 **완전 보류 ID**로 정한다. 나머지는 개발 ID다. 개발 ID에서 정답 마지막 시각 `≤t₀+8h`인 결정만 학습하고, 결정 시각 `≥t₀+8h` 및 정답 마지막 시각 `≤t₀+12h`인 결정만 검증한다. `t≥t₀+12h`이며 정답 전체가 파일에 있는 결정은 시험이다. 경계를 가로지르는 정답 창은 어느 쪽에도 넣지 않는다. **주 시험**은 완전 보류 ID의 후반 시험 구간이고, 개발 ID의 후반 구간은 시간 이동을 보는 보조 시험이다. 보류 ID의 앞부분 레이블은 학습·모델 선택에 넣지 않는다. 같은 컨테이너의 시간 인접 결정이 정답 창을 공유하므로 행을 독립 표본으로 해석하지 않는다.

예측 모두 GiB 단위이고 음수는 0으로 자른다. 최근 피크 `R`은 마지막 가용 64개 메모리의 최대값이다. 비교 기준 네 가지를 미리 고정한다.

1. **최근 피크:** `R` 자체.
2. **전역 잔차 분위수:** `R + q₀.₉(y−R)`; 분위수는 개발 ID의 학습 구간에서만 계산한다.
3. **최근 피크+컨테이너 완료 이력:** 결정 시각에 이미 끝난 같은 컨테이너의 최근 4시간 내 에피소드에서 `y−R`의 경험적 q₀.₉을 구하고, 표본수 `n/(n+20)` 비중으로 전역 잔차 q₀.₉과 섞어 `R`에 더한다. `n<5`이면 전역값만 쓴다. 과거 에피소드의 **미래 끝 시각이 현재 결정 시각 이하**일 때만 그 레이블을 사용한다. 완전 보류 ID의 과거 완료 관측도 온라인에 가용한 이력으로 허용하지만 모델 적합에는 넣지 않는다.
4. **과거 4시간 원계측 피크:** 시각이 `≤t−342초`인 최근 4시간 메모리 표본의 최대값. 이력이 60개 미만이면 `R`로 대체한다.

검증 구간의 90% pinball 손실이 가장 낮은 기준선 하나를 선택한다. 동점은 위 번호가 작은 기준선으로 정한다. 학습 후보는 동일한 `HistGradientBoostingRegressor(loss='quantile', quantile=.9, max_iter=120, max_leaf_nodes=15, min_samples_leaf=80, learning_rate=.05, l2_regularization=10, random_state=42)` 두 개다. 둘 다 잔차 `y−R`을 정답으로 학습한다. 하나는 메모리 이력만, 다른 하나는 동일 에피소드에 duty 이력을 더한다. duty 모델은 검증 pinball이 메모리 전용보다 **상대 2% 이상 낮을 때만** 선택한다. 그 외에는 메모리 전용을 선택한다. 검증의 선택과 모든 모델·기준선 계수·학습 아티팩트 해시를 `selection_manifest.json`에 저장한 다음에만 시험을 연다. 시험 후 재학습·임계치 재선택은 하지 않는다.

## 시험 점수와 채택 게이트

1차 점수는 주 시험의 p90 pinball 손실(낮을수록 좋음)이다. 90% coverage, 평균 초과 예측량, 컨테이너 균등 pinball, 컨테이너별 손실, 고정 전·후반 손실/coverage를 같이 제시한다. 앞·뒤 반은 **`t₀+12h ≤ t < t₀+17h`와 `t ≥ t₀+17h`**다. 주 시험에서 마지막 가용 메모리 0, 미래 창 0 포함, duty 이력 50% 미만, 최근 피크 대비 2GiB 초과 사건을 진단용 층으로 보고한다. 파일에서 첫 관측 시각이 `t₀+8h` 이후인 컨테이너도 별도 지원 범위 층으로 제시한다. 단 2GiB는 위험 정답의 운영 임계값이 아니다. 보조 시험은 같은 계수로 개발 ID의 후반을 채점한다. 주 시험의 컨테이너를 2,000회 복원 재표집(seed 43)해 선택 학습기−선택 기준선의 평균 pinball 차 95% 백분위 구간을 낸다. 이는 같은 날짜 내 컨테이너 변동만 반영한다.

**연구용 채택 기준:** 주 시험 적격 결정 `≥2,000`, 컨테이너 `≥20`, 2GiB 새 피크 `≥50`이어야 한다. 선택 학습기의 주 시험 pinball은 선택 기준선보다 **최소 5% 낮고**, 컨테이너 균등 손실도 낮아야 한다. 두 고정 반구간 모두 기준선보다 손실이 낮아야 하며 coverage는 전체 `≥88%`, 각 반구간 `≥85%`여야 한다. 컨테이너 재표집 손실 차 구간의 상한은 0 미만이어야 한다. duty 모델을 선택했으면 메모리 전용 모델보다 주 시험 pinball도 최소 2% 낮아야 duty 신호의 추가 이득을 인정한다. 하나라도 실패하면 모델을 판단기에 채택하지 않는다. 통과하더라도 한 날짜·동일 공개 서비스에서 관측 피크를 예측한 결과일 뿐 VRAM 적합성·배포·스케일 효과의 증거가 아니다.
