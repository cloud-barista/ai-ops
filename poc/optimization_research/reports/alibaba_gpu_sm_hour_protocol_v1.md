# Alibaba GPU 다음 1시간 SM 계측 예측: 탐색 실험 v1

동결일: 2026-10-02 KST. 이 프로토콜은 모델 학습 전에 작성한다.
자료 분포와 현재값 유지 기준선 오차는 앞선 진단에서 이미 열람했다.
따라서 모든 결과를 탐색 평가로 표시하며 블라인드 독립 검증으로 부르지 않는다.

## 과제와 자료

- 원본: Alibaba Cluster Trace GPU v2026 상대 날짜 109~115일의 완전한 시간별 pod 자료.
- 온라인 추론·GenAI·GPU 요청 양수 행을 읽고, 정확히 1GPU 요청에 한정한다.
- 주 과제는 GPU SM **원시 계측값**의 다음 1시간 평균 예측이다. 다중 GPU 서버의 값도 포함하는 넓은 층과 1GPU 서버만의 엄격한 층을 별도로 학습·평가한다.
- 관측 구간 t-2,t-1,t와 정답 t+1에서 같은 pod·server이고 유효 SM이 [0,100]에 있을 때만 예제를 만든다. 엄격한 층은 네 구간 모두 서버 GPU 수가 1이어야 한다.
- 같은 pod·시각에 복수 행이 있으면 그 시각의 모든 행을 제외한다. pod의 workload ID가 선택 기간에서 결측 또는 불일치하면 제외한다.
- 미래 pod가 미관측·다른 서버·계측 불량이면 정답 0을 만들지 않는다. 결과는 다음 시간의 유효 동일 서버 관측이 존재한다는 조건부 예측이다. 제외량을 기록한다.
- 원본은 보존한다. 가공 예제·분할·예측·모델·평가·버전과 해시를 별도로 저장한다.

## 시점·분할·입력

- 시간 t의 완료 직후, t+1 시간 구간의 계측을 예측한다. 정답은 t+2 경계에서 완료된다. 실제 전송 지연은 공개 자료에 없어 0으로 가정하며 운영 실시간 성과를 주장하지 않는다.
- workload SHA256 앞 8자리 정수를 100으로 나눈 나머지를 사용한다: 학습 0~69 / 검증 70~84 / 시험 85~99. pod와 workload가 분할 간 겹치면 중단한다.
- 학습 판단은 day109~112, 마지막 t=112*24+22; 검증은 day113 hour00~22; 시험은 day114 hour00~day115 hour22. 모든 정답 구간은 해당 날짜 분할 안에 있다. 각 workload 자신의 이전 날짜 관측은 과거 입력으로 허용한다.
- 입력: GPU 공개 유형·priority, 최근 SM 3값·평균·표준편차·1/2시간 변화, 현재 관측 hour sin/cos, 서버 GPU 개수, CPU 요청 코어. 수치 결측은 HGB가 처리하며 범주형 변환은 학습에서만 적합한다.
- ID, ready_status, 준비/스케줄 지연, 다음 시간 사용량, gpu_mem_request는 입력에서 제외한다. gpu_mem_request 단위가 확인되지 않아 쓰지 않는다.

## 고정 비교와 학습

- 단순 기준선: 현재값 유지, 직전 3구간 평균, 학습 자료의 GPU 유형별 정답 중앙값(미지원 유형은 학습 전역 중앙값).
- 직접 HGB: 다음 SM을 직접 예측한다. 잔차 HGB: 다음 SM-현재 SM을 학습하고 현재 SM + alpha*예측 잔차로 복원한다.
- 두 HGB 공통 설정: absolute_error, max_iter=150, learning_rate=.05, max_leaf_nodes=15, min_samples_leaf=50, l2=1, early_stopping=False, seed42. workload별 학습 총 가중치를 동일하게 한다.
- alpha는 사전에 정한 0/.25/.5/1만 비교한다. 모든 출력은 [0,100]으로 제한한다. alpha0은 현재값 유지와 같다.
- 검증의 (행 MAE+workload 동일가중 MAE)/2가 최소인 경로를 선택한다. 동률은 현재값 유지가 우선이다. 최선 단순 기준선과 최선 학습 경로도 검증에서 고정한다. 시험을 보고 후보·특징·설정을 바꾸지 않는다.
- 표준 HGB가 새 아키텍처라는 주장은 하지 않는다. 연구 구성은 과거 신호로 변화량을 학습하고 검증에서 정한 수축 비율로 현재값에 반영하는 절차다.

## 지표와 탐색 채택 조건

- 행 MAE, workload 동일가중 MAE, p95 절대오차, 두 시험 날짜별 MAE를 보고한다. |정답-현재|>10인 변화 구간과 나머지 구간 오차를 따로 보여 준다.
- 변화 구간은 사후 진단층이며 추론 때 알 수 있는 조건이나 별도 라우팅 입력이 아니다. 작업별 변화 수·최대 집중도도 보고한다.
- 검증에서 학습 경로가 선택되고, 시험에서 검증 고정 최선 기준선보다 행·workload MAE가 모두 낮고, 변화 구간 MAE가 나빠지지 않고, 두 시험 날짜에서 행 MAE가 모두 낮고, workload 단위 2,000회 재표집의 기준선-학습 MAE 차 95% 구간 하한이 양수일 때만 탐색 개선 게이트 PASS다.
- 미충족 시 NO_GO로 기록하고 현재값 유지 등 검증 선택 기준선을 보존한다. NO_GO를 숨기거나 시험 기반으로 재튜닝하지 않는다.
- 통계 구간은 고정 모델·이 기간에 조건부이며 새로운 기간/클러스터 불확실성을 포함하지 않는다. 두 층의 개선율을 합산하지 않는다.
- PASS도 운영 채택이 아니다. 새 미사용 기간의 확인 시험, 실제 SLO·action 기록이 필요하다. GPU 부족/OOM·배포 실패·Scale-out/in 효과는 이 실험의 정답이 아니다.

## 검증

합성 예제로 날짜 경계의 시간 연결, 누락 미래의 제외, 중복의 전체 제외, 서버 이동 제외, workload 결측/변경 제외, workload/pod 분할 분리, 정답 시각 경계와 미래 입력 금지를 시험한다. 저장 모델의 재추론이 저장 예측과 일치하는지도 확인한다.
