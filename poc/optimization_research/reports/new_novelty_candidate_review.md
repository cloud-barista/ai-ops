# 조건·자원 반응 공동 전이의 신규성 점검

검토일: 2026-09-28. 범위: 기존 SQLite의 배치 p95 지연과 요청/초를 이용해, 새 AI 모델에서 4–8회 정도만 측정하고 GPU 1/2개 × CPU 2/4/8/16코어 중 형상을 고르는 방법.

## 판정

**현재 형태로는 독립적인 알고리즘 신규성과 도움을 입증하지 못했다.** 기존 모델의 잔차 구조를 옮기고, 믿기 어려운 출처를 줄이며, 지연·처리량 제약에 따라 측정·선택하는 각 원리는 이미 연구됐다. 기존 SQLite의 직접적인 변형도 전체 자원 잔차 공분산, 비슷한 donor 가중, 지원 범위 게이트, GPU 2개를 한 번 추가 측정하는 방식에서 강한 8-앵커 기준선보다 나빴다. [전체 자원 잔차](joint_resource_residual_failed_hypothesis.md), [donor 가중](donor_similarity_transfer_findings.md), [지원 게이트](support_aware_transfer_gate_findings.md), [두 자원 축 측정](dual_axis_sparse_probe_failed_hypothesis.md)

남아 있는 **탐색 가설**은 `조건별 기준 형상 오차`와 `자원 변경 시 상대 반응 오차`를 분리하고, 새 모델의 GPU 2개 측정 한 번에서 얻은 **GPU2−GPU1 로그 성능 차이**로 후자의 전이 신뢰도를 판정하는 것이다. 이는 다른 자원 형상에서 새 모델이 donor와 같은 방식으로 반응하는지 직접 시험한다. 성공해도 현재 SQLite에서의 사후 탐색이며, 새 모델·호스트·실사용 SLO의 독립 검증 전에는 논문 수준의 신규성 또는 운영 효과로 주장할 수 없다.

## 식별성과 데이터의 한계

로그 성능을 지표별로 `y_m(c,r) = f_0(m,c,r) + a_m(c) + b_m(c,r)`라 쓰고 기준 형상 `r₀=(GPU 1, CPU 2)`에서 `b_m(c,r₀)=0`으로 정한다. `a`는 작업 조건의 기준 형상 잔차, `b`는 자원 변경의 상대 반응 잔차다. **기준 형상만 관측하면 어떤 `b(c,r≠r₀)`도 동일 관측과 양립한다.** 따라서 기준 형상에서 donor와 유사하다는 신호만으로 새 모델의 자원 반응 전이가 안전하다고 판정할 수 없다. 적어도 한 작업 조건에서 두 번째 자원 형상을 관측해야 이 가설을 시험할 수 있다.

주 캠페인의 encoder 8개를 모델 하나씩 제외하면 정렬된 donor는 7개뿐이다. 64개 조건 × 8개 형상 × 2지표의 전체 잔차 벡터에 대한 경험적 중심화 공분산은 최대 rank 6이므로 강한 구조 제약과 수축이 필요하다. 현재 GPU 2개 측정 하나의 중앙 GPU-wall 비용은 약 3.82초, GPU 1개 기준 측정 하나는 약 0.60초다. 따라서 GPU 2개 한 번을 기존 8회에 **추가**하는 비교는 예산이 다르다. [비용 및 기각 결과](dual_axis_sparse_probe_failed_hypothesis.md)

수집기가 만든 SLO는 대부분 처리량만으로 후보가 갈리고 실제 사용자 목표가 아니다. `latency_p95_ms`는 온라인 요청 p95가 아니라 벤치마크의 배치 p95다. [두 제약이 작동하는 사례 수](adaptive_probe_transfer_findings.md) 실제 서비스용 배포·스케일링 효과를 주장할 수 없다.

## 한 번의 반증 가능한 SQLite 실험

사전에 구현과 판단 기준을 고정한 뒤, 모델 전체 제외와 BERT 네 모델 공동 제외를 모두 수행한다. 모든 기본 예측기·잔차 prior·게이트 계수는 각 fold의 donor만 사용하고, donor 내부에서도 모델 단위 교차검증 잔차를 쓴다. 새 모델에서 4–5개 기준 형상 조건을 측정하고 그중 하나를 GPU 2개·CPU 2코어로 한 번 더 측정한다. 해당 두 관측의 **로그 차이**를 목표 자원 반응의 유일한 증거로 쓴다. 자원 반응 잔차는 donor 모델의 기준 대비 로그 차이에 대한 강하게 수축된 저차원 모형으로 추정한다. 독립적인 조건 잔차 보정 `a`와 자원 반응 보정 `b`를 예측에서 합치되, `b`의 전이 가중치는 donor 내부에서 학습한 sentinel 예측 손실과 새 모델 sentinel의 일치 정도로 정한다.

같은 프로브 결과로 네 가지를 비교한다: (1) 기준 형상 4–5회만 사용한 기존 예측기, (2) GPU 2개 sentinel을 **관측만** 쓰고 전이하지 않는 기존 단순 보정, (3) 제안한 `a+b` 공동 전이에서 신뢰도 게이트를 제거한 버전, (4) 게이트를 적용한 완성 버전. 별도로 현재 가장 강한 **기준 형상 8회 공분산+자원 반응**과 비교하고, 실제 `GPU 개수 × wall_seconds` 비용을 모델별로 제시한다. 정확도는 모든 미측정 후보의 지연·처리량 모델별 로그오차, 판단은 donor에서만 정의한 이중 제약 SLO의 실제 가능한 형상 선택 성공·잘못 승인·최소 형상 일치로 평가한다. 신규 입력 캠페인별 결과와 Qwen의 donor 부재도 따로 보고한다.

**채택 기준:** 완성 버전이 같은 실제 GPU-wall 예산에서 가장 강한 기존 방식보다 두 지표의 오차 및 잘못 승인을 악화시키지 않으면서, 모델별·BERT 계열 제외에서 형상 선택 성공을 일관되게 높여야 한다. 게이트 없는 공동 전이보다도 개선해야 `신뢰도 판정`의 기여가 분리된다. 이 조건을 못 맞추면 방법을 기각한다. 맞추더라도 기존 SQLite의 반복 탐색이므로 독립 검증용 새 모델·호스트·실사용 SLO 데이터가 확보되기 전에는 학술적 신규성 주장을 보류한다.
