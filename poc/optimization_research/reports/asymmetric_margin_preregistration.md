# 비대칭·조건부 승인 여유값 실험 사전 규약

이 파일은 결과 실행 전에 고정한 분석 규약이다. 기존 K8 공간 선택 앵커·공분산 예측을 바꾸지 않는다. 대상 모델별 8회 측정, 후보 8개, 예측 비용은 네 정책에 공통이다.

## 방법과 분리

- 9개 모델을 하나씩 완전히 제외한다. 대상 H의 기존 K8 예측은 동결한다.
- 마진 학습용 오차는 H를 제외한 8개 donor를 모델 ID 정렬의 짝수·홀수 인덱스로 두 묶음으로 나눠 얻는다. 각 묶음의 4개 pseudo-target D는 반대쪽 4개 모델로 기본·조건부 모델과 donor OOF 공분산을 다시 학습한 뒤, D의 같은 K8 medoid 앵커 8개만 읽어 예측한다. 따라서 어느 학습에도 H 또는 해당 D가 들어가지 않는다. 이 2-fold 교차 적합은 계산량을 제한하기 위한 근사이며, 실제 H 예측의 8 donor 학습과 학습 집합 크기가 다르다.
- 오차 위험은 `실측 로그 지연 − 예측 로그 지연`, `예측 로그 요청/초 − 실측 로그 요청/초`다. 요청/초는 examples/s를 batch size로 나눈다. 마진 분위수는 donor 모델마다 따로 구한 75% 분위수의 중앙값이며 0 아래는 자른다.
- 실측으로 이미 알려진 8개 GPU1·CPU2 앵커 후보는 마진 학습에서 빼고, 선택할 때도 모든 정책의 마진을 0으로 둔다.
- 조건은 `batch_size >= 12 또는 max_length >= 512`와 GPU replica 수 1/2의 4개 조합으로 미리 고정했다. 조건별 두 위험 분위수를 전역 분위수로 수축하며 가중치는 `donor 모델 수 / (donor 모델 수 + 4)`다. 비교군은 전역 지연·처리량 비대칭 분위수, 양쪽에 공통 로그 마진 0.05, K8 0마진이다. 모든 상수는 대상 성능을 보기 전에 고정한다.

## 평가

- 원본 수집 생성 SLO와, 대상 H 이외 8개 모델의 측정 분위수로 만든 25개 지연·요청/초 목표 쌍을 별도 집계한다. 후자도 실제 사용자 목표는 아니다. 한 작업의 25개 질의는 상관되어 있다.
- 기본 운영점은 학습된 양의 마진을 그대로 적용한다. 후보는 GPU 수, CPU 코어 순서로 가장 저렴한 예측 충족 형상을 선택한다. 승인 수, 성공, 잘못 승인, 실제 가능 작업 누락을 함께 보고한다.
- 공정 비교는 H별·SLO 종류별 **조건부 비대칭 방법의 기본 운영점 승인 수 N**에 다른 세 정책의 승인 수를 정확히 맞춘다. 각 정책의 예측 여유도만으로 작업을 순위화하고 공통 절편을 이동해 상위 N건을 승인한다. H의 실측값은 순위나 절편 선택에 쓰지 않는다. 이 비교는 같은 coverage에서의 **탐색적 위험 순위 진단**이다. 절편이 음수면 예측상 SLO 미충족 후보도 승인될 수 있고, 양수면 측정된 앵커의 승인도 미뤄질 수 있으므로 배포 가능한 정책으로 해석하지 않는다.
- 성공/잘못 승인 차이는 9개 모델 단위로 따로 제시한다. 사전 탐색된 데이터라 통계적 확증이나 실운영 효과를 주장하지 않는다.
