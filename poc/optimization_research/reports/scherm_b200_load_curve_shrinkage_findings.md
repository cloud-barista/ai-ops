# B200 고부하 곡선 예측의 훈련 모델 전용 수축 선택

## 결론

**판정: `EXPLORATORY_NO_GO`.** [기본 저부하→고부하 실험](scherm_b200_load_curve_findings.md)에서 Ridge의 평균은 좋지만 모델별 TTFT·출력률 오차가 불안정했다. 이에 [사전 적은 후속 규칙](scherm_b200_load_curve_shrinkage_protocol.md)대로 바깥에서 모델 1개를 제외하고, 남은 6모델의 **안쪽 모델 전체 제외** 점수만으로 donor 중앙 비율과 Ridge의 로그 예측을 섞는 비율을 정했다. 바깥 7모델·42셀의 출력률 MALE은 donor **0.25188→0.20631**로 18.1% 줄었으나 TTFT 집계 MALE은 **0.29723→0.28940**으로 2.6%만 줄었다. 두 지표 동시 승리는 **4/7모델**, 최악의 모델별 오차비는 **1.89배**여서 사전 탐색 채택 기준 세 가지 모두 실패했다.

| 바깥 제외 모델 | 훈련 모델에서 고른 Ridge 비율 | 출력률 MALE: donor→수축 | TTFT MALE: donor→수축 |
| --- | ---: | ---: | ---: |
| Qwen2.5-14B | 1.00 | 0.196→0.187 | **0.113→0.215** |
| Qwen2.5-32B | 0.25 | 0.226→0.175 | 0.169→0.156 |
| Qwen2.5-72B | 0.50 | 0.474→0.296 | 0.250→0.236 |
| Qwen2.5-7B | 0.50 | 0.308→0.227 | 0.389→0.260 |
| Qwen2.5-Coder-14B | 0.00 | 0.040→0.040 | 0.341→0.341 |
| Qwen2.5-Coder-32B | 0.00 | 0.248→0.248 | 0.301→0.301 |
| Qwen2.5-Coder-7B | 0.00 | 0.271→0.271 | 0.517→0.517 |

안쪽의 6모델에서 정한 위험 조건은 Coder-14B의 큰 출력률 악화를 피했지만, Qwen2.5-14B에서는 Ridge 비율 1을 선택했다. 이 모델의 첫 토큰 지연이 donor 비율과 달랐다는 사실은 **모델을 제외한 훈련 자료만으로는 감지되지 않았다.** 모델별로 안전한 비율을 정하려면 더 다양한 독립 모델 또는 대상 모델의 추가 고부하 계측이 필요하다.

전체 7모델 정답을 본 **사후 고정 비율 0.25**는 세 탐색 숫자 조건을 우연히 충족했다(출력률 MALE 0.2081, TTFT 0.2805, 공동 승리 5/7, 최악 악화비 1.10). 이 비율은 이미 바깥 정답으로 골라진 것이므로 독립 시험의 결과가 아니며, 이 방법의 채택 근거로 사용하지 않는다. 안쪽 선택 시험은 이 선택 편향을 줄여 보여 주기 위한 진단이며, 시험 설계 자체도 노출된 0.25 결과의 영향을 받았다.

## 재현과 범위

[평가 코드](../scripts/evaluate_scherm_b200_load_curve_shrinkage.py)는 바깥 제외 모델의 모든 행을 안쪽 학습·비율 선택에서 제거한다. 행별 예측 (`../artifacts/scherm_b200_load_curve_shrinkage_v1/predictions.csv`)과 [바깥·안쪽 점수 및 해시](../artifacts/scherm_b200_load_curve_shrinkage_v1/summary.json)를 보존했다. [정보 경계 테스트](../tests/test_evaluate_scherm_b200_load_curve_shrinkage.py) 두 개에서 제외 모델의 고부하 정답을 변경해도 그 모델의 선택 비율과 예측이 바뀌지 않았다. 소스는 [핀 고정 Scherm CSV](../data/external/scherm_onprem_2026/SOURCE.md)다.

결과는 공개 B200 장비의 warm Qwen2.5 AWQ TP2 서빙 집계에 한정된다. 원본의 `ttft_ms_p95`는 반복 실행 평균 TTFT의 95분위이며 개별 사용자 요청 p95가 아니다. 현재 KHU의 VM 수·GPU 종류 추천 또는 `SCALE_OUT/IN` 승인에 이 학습기를 연결하지 않는다.
