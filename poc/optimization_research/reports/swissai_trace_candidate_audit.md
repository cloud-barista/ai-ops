# ETH LLM 추론 기록의 표본 품질 점검

이 문서는 전량 수집 전의 판단 근거다. 이후 16,329,237행을 모두 확인한 결과와 사전 품질 게이트 판정은 [전량 감사 보고서](swissai_trace_full_audit.md)에 있다.

[ETH EASL이 공개한 LLM Serving Trace](https://huggingface.co/datasets/eth-easl/swissai-serving-trace)는 `created_at`, `finished_at`, 요청 상태, 모델, 입력·출력 토큰 수를 담은 독립 AI 서비스 기록이다. 저자 [데이터 카드](https://huggingface.co/datasets/eth-easl/swissai-serving-trace/blob/c3dd66602b564ce189f7db81115620413e646cd5/README.md)는 `trace.jsonl`을 **16,329,237행·6.98GB**로 설명한다. 이 파일을 다운로드하거나 성능 실험에 사용하기 전에, 고정 revision `c3dd66602b564ce189f7db81115620413e646cd5`에서 HTTP Range로 2MiB씩 8개 지점을 읽어 품질을 점검했다. 시작 위치는 파일 크기 6,981,478,609 bytes에서 0%, 10%, 25%, 40%, 55%, 70%, 85%, 99% 지점으로 계산했고 각 범위의 불완전한 양끝 행은 버렸다. 이 표본은 **무작위 표본이 아니며 전체 결측률을 추정하지 않는다.**

39,230개의 완전한 JSON 행 중 39,225개는 두 시각을 해석할 수 있었다. UTC로 해석했을 때 완료시간은 전부 양수(0.003~4,238.787초)였다. 나머지 5개는 `status=DEFAULT`이지만 `finished_at='\\N'`이어서 실제 완료 라벨이 없다. 완료 시각은 15,205건에서 `Z`가 명시됐고 24,020건에서는 시간대가 없는 `YYYY-MM-DD HH:MM:SS.mmm` 형식이었다. 후자를 UTC로 해석한 결과이며 저자의 시간대 확인 전에는 가정이다.

**파일 저장 순서는 요청 시각 순서가 아니다.** 8개 2MiB 범위에서 각각 약 절반의 연속 행이 시각 역전됐다. 파일 시작 부분의 요청은 2025년 8월, 25% 위치는 2024년 12월, 끝 부분은 2025년 10월이었다. 전역 시계열 평가에는 `created_at`을 일관되게 파싱해 정렬하고 `finished_at <= 학습 컷오프`까지 만족하는 과거 라벨만 사용해야 한다. 원본 파일의 앞/뒤를 잘라 학습·시험하면 미래 자료가 섞인다. `reported_token_output`은 요청 완료 후 값이므로 입력에서 제외한다. 입력 토큰 `-1`도 별도 결측으로 처리해야 한다.

데이터 카드의 라이선스 메타데이터는 `other`이며 별도 라이선스 문서가 보이지 않았다. 원본과 파생 행 단위 자료는 로컬 연구에만 보관한다. 실제 VM 생성·스케일 사건은 없으므로 이 자료는 요청 지연 예측 절차 검증 후보이지 스케일 효과의 정답은 아니다.
