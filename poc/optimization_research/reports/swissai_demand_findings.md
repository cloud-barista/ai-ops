# SwissAI 활성 모델의 미래 10분 요청량: 완료 피드백은 예측을 개선하지 못함

2026-09-28. 이 결과는 [점수 계산 전에 고정한 규약](swissai_demand_protocol.md)에 따른 **탐색 평가**다. 2025-08-16 UTC 이후 자료는 이 실험의 특징·학습·점수 계산에 사용하지 않았다. 같은 SwissAI 추적의 요청 *종료시간*은 이미 별도로 분석했으므로 완전히 새로운 독립 자료 검증은 아니다.

## 질문과 자료 품질

경희대 Scale-out/in 판단기에 줄 수 있는 **수요 신호**로서, 5분마다 활성 모델의 다음 10분 요청 수 90분위수를 예측했다. 모델 선정에는 학습·검증 요청 수만 사용했다. 선택된 두 모델은 원문 이름 대신 SHA256 별칭 `45363f1dab`, `99668f5da8`로 표시한다. 학습은 2025-01-16~06-16, 검증은 06-16~07-16, 시험은 07-16~08-16 UTC다.

전체 원본·정렬본 SHA256, 규약 해시와 코드 해시가 일치했다. 예측 전에 만든 [dry run 감사](../artifacts/swissai_demand_v1/dry_run.json)는 규약의 **모델×분할 활성·최종 판단·양수/0 정답 건수 24개를 모두 정확히 재현**하고 품질 게이트를 통과했다. 최종 판단은 학습 12,426개, 검증 3,039개, 시험 3,428개다. 전역 최근 10분 요청이 없으면 판단을 보류하고, 이미 끝난 6시간 이상 무기록 구간 뒤 120분도 보류했다. 전역 5분 격자 중 이 조건을 통과한 비율은 학습 12,411/43,463, 검증 3,160/8,639, 시험 3,529/8,927이다. 이 제한은 활동이 많은 시각에 표본을 편중시키므로 전체 달력 시간의 성능을 뜻하지 않는다.

## 고정 시험 결과

주 지표는 **각 모델의 p90 pinball 손실을 구한 뒤 둘을 같은 비중으로 평균한 값**이다. 단위는 요청 건수다. 작은 값이 좋다. 포괄률은 `실제 10분 요청 수 ≤ 예측 p90`인 비율이며 시험 판단 행 전체를 합산했다.

| 방법 | 검증 손실 | 시험 손실 | 시험 포괄률 |
| --- | ---: | ---: | ---: |
| 도착량만 학습한 p90 HGB | 169.527 | 1,594.655 | 80.05% |
| 도착량 + 1시간 뒤 사용 가능한 완료 결과 | 171.940 | **1,614.081** | 79.73% |
| 직전 10분 요청 수 지속 | 196.665 | **779.609** | 71.50% |
| 직전 120분의 10분 창 경험적 p90 | 207.237 | **727.885** | 78.56% |
| 학습 구간 고정 모델별 p90 | 869.725 | 2,696.781 | 71.06% |

단순 기준선은 **검증에서** 직전 10분 지속이 선택됐다. 최근 창 경험적 p90이 시험에서 더 낮은 손실을 보인 사실을 이용해 기준선을 바꾸지는 않는다. 완료 피드백 추가의 주 시험 손실은 도착량 전용 모델보다 **1.22% 높고**, 검증에서 고른 지속 기준선의 약 **2.07배**다. 완전한 네 개 7일 블록에서 완료 피드백 모델의 승리는 **0/4**다. 규약의 상대 5% 개선·모델별 비악화·주별 승리·85% 모델별 포괄률 조건을 충족하지 못하므로 **탐색적 성공 판정은 실패**다.

| 모델 별칭 | 도착량 전용 손실 → 완료 피드백 손실 | 도착량 전용 포괄률 → 완료 피드백 포괄률 |
| --- | ---: | ---: |
| `45363f1dab` | 1,679.353 → **1,704.589** | 75.04% → **73.84%** |
| `99668f5da8` | 1,509.957 → **1,523.573** | 85.25% → **85.84%** |

두 학습기 모두 90% 포괄률에 못 미친다. 단순 기준선도 90%를 만족하지 않으므로 이 결과에서 운영용 p90 상한을 채택하지 않는다. 전량 점수, 검증 선택, 주별·모델별 분해, 실행 시간과 해시는 [metrics.json](../artifacts/swissai_demand_v1/metrics.json)에, 시험의 3,428개 익명화 판단·예측은 test_predictions.parquet (`../artifacts/swissai_demand_v1/test_predictions.parquet`)에 보관했다.

## 관측된 수요 변화와 해석

선택 모델 `45363f1dab`은 학습의 미래 10분 평균 요청 수가 **11.4건**이었으나 검증 **1,599.6건**, 시험 **3,641.2건**으로 달라졌다. 이 모델의 시험 판단 중 **29.48%**는 직전 10분 요청 수가 학습의 최대값 **1,296건**을 넘었다. `99668f5da8`의 미래 10분 평균도 학습 **889.2건** → 검증 **45.1건** → 시험 **2,544.2건**으로 크게 이동했다. 이러한 이동은 고정 학습 모델의 시험 악화를 설명할 **가능한 요인**이지만, 원인임을 입증하는 분석은 아니다. 시험 점수를 본 뒤 모델·특징·임계값을 재조정하지 않았다.

완료 피드백은 `finished_at + 1시간 < 판단시각`일 때만 입력했다. 실제 완료 결과 전달시각은 없고, 시간대 없는 완료시각은 UTC로 해석했다. 수집기 생존 신호가 없어서 보류 직전 첫 10분의 무기록은 실제 무부하와 자료 결손을 구분하지 못한다. 이 추적에는 VM/GPU 형상, scale 명령, 준비 시간, 사용자 지연 SLO나 전환 후 결과가 없다. **요청량 예측 실패·성공 어느 쪽도 Scale-out/in 행동의 효과를 평가하지 않는다.** 후속 운영 판단 검증에는 [명령·자원·SLO 연결 데이터 계약](scale_effect_data_contract_v1.md)이 필요하다.

## 재현

전체 계산은 `numba==0.60.0`이 설치된 이 환경의 `/usr/bin/python`에서 실행한다. `--dry-run`이 행과 품질 게이트를 먼저 고정하고, `--score`는 그 데이터·코드·규약 해시가 같을 때만 학습한다.

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 /usr/bin/python scripts/evaluate_swissai_demand.py --dry-run
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 /usr/bin/python scripts/evaluate_swissai_demand.py --score
pytest -q tests/test_swissai_demand.py
```

합성 시간 경계·공백·피드백·정확한 분위수 테스트 7개가 통과했다. 독립 코드 검토에서 시점 누출은 발견되지 않았고, 검토 중 확인한 주별 균등 평균 및 고정 건수 검사는 **점수 실행 전에** 코드에 반영했다. 규약 SHA256은 `a50ded6b5d29ec83dc84efbd7635dd63a0f05d832175e362d174ad71495fed8d`이며, 최종 코드·판단 행·시험 예측 해시는 [metrics.json](../artifacts/swissai_demand_v1/metrics.json)에 기록했다.
