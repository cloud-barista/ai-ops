# Chutes 관측 요청량 p90 v2: 점수 전 고정 규약

2026-09-29. v1 검증은 이미 노출된 개발 자료다. v1의 상대 수요 모델은 35개 중 16개 모델에서만 절대 수요 모델보다 나았고, 전체 개선의 86.5%가 한 모델에서 나왔다. v2는 이 관찰을 바탕으로 정한 **단 한 개의 후보**이며 v1 검증 예측·정답으로 보정하거나 v2 점수를 선택하지 않는다. 이 규약, 구현, 합성 테스트, 기존 원본 추출의 SHA-256은 학습 구간 내부 검증 점수 전에 `artifacts/chutes_demand_p90_v2/frozen_manifest.json`에 고정한다.

## 출처, 분할, 해석

- Harvard MadSys Chutes `chutes_metadata`, revision `85722e694bf7bb8a5a5ccdf70424fa5998372467`, `data/trace/train-00044-of-00045.parquet`, 크기 2,046,207,562 bytes, 연결 SHA-256 `ca99b91b33d04bf56f3d0b26241c4a083a7e1579f0f571887eee4ee1004c90dd`를 쓴다. 출처는 [공식 데이터 카드](https://huggingface.co/datasets/harvardMadsys/chutes_metadata)다. 기존 row group 65–73의 네 열 `invocation_id,function_name,chute_id,started_at`만 재사용한다. 기존에 봉인한 74–76은 받거나 읽지 않는다.
- 별도 시험은 **row group 77–79만** 사용한다. 원본 Parquet의 footer 메타데이터만 먼저 읽어 각 그룹이 1,001,472행이고 `started_at` 최소/최대가 각각 1970-12-28 23:37:00.080710/1970-12-29 01:59:10.560916, 01:59:10.572891/04:16:49.931794, 04:16:49.941128/06:27:59.252252임을 확인했다. 시험 결정 격자는 1970-12-29 **00:40≤t<06:20**, 5분 간격이다. 첫 판단의 과거 60분 `[23:40,00:40)`과 마지막 정답 창 `[06:15,06:20)`이 모두 77–79 안에 완전히 들어간다. 시험 요청 값은 학습 구간 내부 게이트 통과 전 열지 않는다.
- 기존 학습 격자 1970-12-27 23:15≤t<1970-12-28 10:15를 F0(23:15–04:15, 5시간 적합), C(04:15–07:15, 3시간 보정), G(07:15–10:15, 3시간 내부 검증)로 자른다. 첫 학습 판단에 완전한 60분 과거를 확보한다. 각 `y(m,t)`는 모델 `m`의 `chat_stream` 또는 `completion_stream` 중 `started_at∈[t,t+5분)`인 **기록된 시작 요청 수**다. 0도 포함한다. 모델 등록은 v1에서 학습만으로 선택된 고정 35개다. `t` 이전 30분의 해당 모델 시작이 ≥30일 때만 판단하고, 미래 정답으로 판단 행을 고르지 않는다.
- 이전 창의 정답은 창이 끝난 순간에 사용 가능하다고 가정한다. 원본은 실제 수집 지연을 기록하지 않으므로 이 연구는 오프라인 수요 예측이다. 정규화 시각의 달력 날짜·요일은 특징으로 쓰지 않는다.

## 한 가지 후보와 고정 기준선

기본 전문가 `A`는 v1 절대 수요 q0.9 HGB, `R`은 v1 상대 수요 q0.9 HGB, `H`는 직전 30분의 겹치지 않는 5분 요청 수 여섯 개 중 최대값이다. 두 HGB의 특징, 모델 균등 학습 가중치, 하이퍼파라미터는 v1 코드 그대로다. 기준선은 직전 5분 수, `H`, `A`, `R`, 그리고 아래의 고정 혼합 `S`다. 모두 같은 적격 판단 행에서 점수화한다.

1. F0로 `A`·`R`을 학습하여 C를 예측한다. C 각 행·전문가 `e∈{A,R,H}`에 대해 `d_e=ρ₀.₉(y,q_e)/max(1,m30/6)`을 계산한다. `D_global,e`는 모델별 C 평균 `d_e`를 모델 균등 평균한 값이고, 모델 `m`의 사전 손실은 `D_m,e=(n_m × mean_C(d_m,e)+12×D_global,e)/(n_m+12)`이다. C에서 적격 행이 없는 모델은 `D_global,e`를 쓴다. 이 식의 12는 작은 모델의 신뢰도를 수축시키는 고정 유사 표본 수다.
2. F0+C로 기본 전문가를 다시 학습하여 G를 예측한다. G의 각 판단 `t`에는 같은 모델의 과거 60분 안에서 이미 종료된 **적격 판단** `s+5분≤t`의 전문가 손실만 쓴다. 각 손실의 시간 가중치는 `0.9^((t-s)/5분−1)`이다. `a_m,e(t)=(6D_m,e+Σ_s weight_s d_e(s))/(6+Σ_s weight_s)`이고 `w_m,e(t)=exp(−8a_m,e)/Σ_j exp(−8a_m,j)`이다. 최종 후보 `Q=Σ_e w_m,e q_e`. G 시작에서 최근 손실 상태는 비운다. 수치 안정화를 위해 softmax에서 최솟값을 뺀다. 전문가의 G 정답은 예측을 낸 **다음** 상태 갱신에만 쓴다.
3. 비교용 고정 혼합 `S`는 `softmax(−8D_m,e)`로 계산한 가중치를 모든 판단에서 그대로 쓴다. G에서 같은 순서와 규칙으로 점수화한다. 시험을 열 자격을 얻으면 `A`·`R`만 전체 학습 11시간으로 재적합하고 C에서 구한 `D_m,e`는 바꾸지 않는다. 시험 시작에서 최근 손실 상태를 비워 같은 규칙으로 순차 점수화한다. 시험 값으로 모델·가중치·문턱을 재선택하지 않는다.

## 지원량, 손실, 사전 게이트

주 지표는 `ρ₀.₉(y,q)=0.9(y−q)₊+0.1(q−y)₊`의 **모델별 평균을 35개 모델 균등 평균**한 값이다. 모델 균등 피복률 `P(y≤q)`, 모델 균등 과소예측량, 전체 행 평균, 모델별 손실, 1시간 블록 점수도 공개한다. 1시간 블록은 ≥30개 판단·≥10개 모델에서만 세고, 연속 창을 독립 표본으로 간주한 신뢰구간은 주장하지 않는다.

- 출처 revision·원본 크기·해시, 기존 추출의 해시·row group 행 수, 각 분할 완전 이력·정답, 시간 단조성·ID 중복을 강제한다. F0/C/G 모두 고정 35개 모델의 적격 판단 ≥12개, 전체 ≥1,000개를 요구한다. 사전 지원량 점검 결과 F0는 1,821행(모델별 최소 16), C는 1,089행(최소 12), G는 1,094행(최소 17)이다. 실제 재집계가 다르면 점수를 중단한다. 각 분할에서 전체 스트리밍 시작 0건인 5분 격자가 >5%면 중단한다.
- **G 통과:** `Q`의 주 손실이 기존 네 기준선 각각보다 ≥5% 낮고 `S`보다 ≥2% 낮아야 한다. 같은 G에서 주 손실이 가장 작은 *단일* 기존 기준선보다 `Q`가 나은 모델 ≥21/35, 모델 균등 피복률 ≥85%, 모델 균등 과소예측량이 `A` 이하, 모델 하나를 어느 것을 빼더라도 네 기준선 중 가장 좋은 주 손실보다 `Q`가 ≥2% 낮아야 한다. 충분한 1시간 블록이 ≥3개이고 그중 ≥2/3에서 `Q`가 `S`보다 나아야 한다. 하나라도 실패하면 시험 그룹을 열지 않는다.
- **시험 지원량:** 77–79의 단조성·ID 유일성·완전 창, 적격 판단 ≥800행, 고정 35개 중 각 ≥12행인 모델 ≥25개, 전체 스트리밍 0건 격자 ≤5%를 요구한다. 평가 모델은 적격 판단 ≥12개인 고정 모델만 사용하며 미래 요청 수나 손실로 선정하지 않는다. 실패 시 주 시험 점수를 내지 않는다.
- **시험 채택:** `Q` 주 손실이 기존 네 기준선 각각보다 ≥10%, `S`보다 ≥5% 낮고, 가장 강한 단일 기존 기준선보다 나은 평가 모델 ≥70%, 모델 균등 피복률 ≥85%, 모델 균등 과소예측량 `A` 이하, 모델 하나를 어느 것을 빼도 네 기준선 최고보다 ≥2% 낮아야 한다. 충분한 1시간 블록 ≥4개 중 ≥70%에서 `Q`가 `S`보다 나아야 한다. 시험은 한 번만 채점한다.

v1 검증은 이 방법의 동기가 된 노출 자료이므로 v2 후보의 선택·보정·게이트에 넣지 않는다. 성공해도 새 학습 알고리즘의 최초성, 실제 수요 총량, 사용자 지연 SLO, GPU/VM 규모, `SCALE_OUT/IN`의 효과는 입증하지 않는다.
