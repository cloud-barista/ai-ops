# SwissAI 요청 출력 토큰 p90 학습: 검증 단계 미채택

2026-09-29. [점수 전 고정한 규약](swissai_output_tokens_protocol.md)으로 [SwissAI 원본](https://huggingface.co/datasets/eth-easl/swissai-serving-trace)의 요청별 기록 출력 토큰 p90을 학습했다. 학습 후보는 요청 모델·제출된 생성 설정·완료 후 1시간이 지나 **이전 UTC 날짜 시작 전에** 가용한 출력 이력을 쓰는 HGB 분위수 회귀다. 요청 입력 토큰은 접수 시점 가용성이 확인되지 않아 사용하지 않았다. [추출기](../scripts/extract_swissai_output_tokens.py)는 원본 16,329,237행을 고정 정렬본과 1:1로 결합했고, 출처·해시 기록 (`../data/external/swissai_serving_trace/output_tokens_extraction_v1.json`)을 보존했다.

## 검증 결과

학습 구간 `2025-05-16~08-15`의 기록상 `DEFAULT`·양수 완료시간·출력 관측 요청은 **6,220,129건**이며, 날짜당 최대 5,000건씩 **247,802건**을 고정 표본으로 실제 학습했다. 검증 `2025-08-16~09-15`은 **212,296건**이다. 표의 첫 지표는 완전한 7일 블록 네 개의 p90 pinball 손실을 동일 비중으로 평균한 **사전 주 지표**다. 손실 단위는 출력 토큰이다.

| 방법 | 7일 블록 동일 가중 손실 ↓ | 요청 가중 손실 ↓ | 관측 요청 피복률 |
| --- | ---: | ---: | ---: |
| 고정 전역 p90 | 448.910 | 139.746 | 90.77% |
| 고정 모델별 p90 | 447.040 | 137.405 | 91.77% |
| 최근 7일 전역 p90 | 376.581 | 153.837 | 83.89% |
| **최근 7일 모델별 p90** | **344.514** | 201.117 | 89.13% |
| 학습 HGB p90 | 383.798 | **130.476** | **92.40%** |

검증에서 선택된 강한 단순 기준선은 **최근 7일 모델별 p90**이다. HGB의 블록 동일 가중 손실은 이 기준선보다 **11.40% 높아**, 사전 요구인 5% 이상 감소에 실패했다. 전체 요청 가중 손실에서는 HGB가 더 낮지만, 규약에서 정한 주 지표를 바꾸지 않았다. 검증의 네 번째 완전 7일 블록은 1,090건으로 앞선 블록 76,762/40,152/93,852건보다 훨씬 작았고, 그 블록 HGB 손실은 1,165.801·피복률은 52.8%였다. 출력 관측이 많은 세 블록의 좋은 평균이 이 약한 구간을 가리지 않도록 블록 동일 가중치를 유지했다.

검증에서 1,000건 이상인 모델 10개 중 HGB 피복률이 **83.27%**, **84.49%**인 두 모델이 있어 사전 85% 모델별 하한도 실패했다. 전체 피복률 92.40%만으로 각 응용의 출력 길이 상한을 보장할 수 없다. [검증 지표와 익명 모델별 수치](../artifacts/swissai_output_tokens_v1/validation.json)의 SHA-256은 `3ed9a268eb473b7f44750dc415d65aa9fe9e7a6b8eeb34ff780f758de8fc0857`이다. 네 블록 평균을 저장 수치에서 다시 계산해 일치함을 확인했고, 저장 모델과 재로딩한 자료의 모델 별칭 순서도 일치했다.

사후 원인 진단에서 학습 표본에 **모델 ID가 있던 요청 비율**은 검증의 완전 7일 블록 순서대로 **98.94% → 4.54% → 5.76% → 1.83%**였다(남은 3일은 0%). 이는 새 모델의 출력 분포를 충분히 배운 상태에서 전이한 시험이 아님을 보여준다. 마지막 블록에서는 출력 관측 요청 1,090건의 대부분이 HGB에 미지 모델이었고, 요청 시 제출된 `max_tokens` 숫자도 2.0%에만 있었다. 이 진단은 이미 본 검증 구간의 입력 구성 분석이며 새 정책의 성공 근거가 아니다.

[고정 모델의 검증 보충 감사](../artifacts/swissai_output_tokens_v1/validation_slices.json)에서는 검증 212,296건 중 학습 표본에서 본 모델이 **83,197건·3종**, 보지 못한 모델이 **129,099건·79종**이었다. 미지 모델층의 요청 가중 손실은 HGB `107.682`, 최근 모델별 p90 `215.125`였으나, 같은 층의 완전 7일 블록 동일 가중 손실은 각각 `344.276`, `304.266`으로 HGB가 더 컸다. 학습 표본 모델층의 HGB 피복률도 `84.57%`였다. 층별 요청 수가 날짜마다 크게 달라 이 사후 점수로 원래 주 지표나 미채택 결정을 바꾸지 않는다. 검증 이력 창의 적격 완료 요청 **2,653,502건**에는 시간대 없는 완료시각 기록이 **0건**이었다. 따라서 명시적 UTC 완료 기록만으로 이력을 다시 만든 민감도 점수는 원래 점수와 전부 같으며, 별도 견고성 근거를 추가하지 않는다. 보충 감사는 저장된 검증 점수와 게이트를 정확히 재생했고 시험 손실·출력 분포는 계산하지 않았다.

**결정: HGB 미채택.** [검증 게이트](../artifacts/swissai_output_tokens_v1/validation.json)가 실패해 `test` 명령은 `frozen_validation_gate_failed_test_remains_closed`로 종료한다. 시험 `2025-09-16~10-23`의 출력 관측 건수 **498,008건**은 추출 품질 감사로만 확인했고, 이 실험의 시험 출력 분포·예측 손실·피복률은 계산하지 않았다. 이 결과를 본 뒤 같은 시험으로 HGB 특징이나 문턱을 조정하지 않는다.

## 적용 범위

전체 요청 중 출력 관측률은 학습 78.1%, 검증 70.7%, 시험 67.6%다. 관측된 출력은 모두 `status=DEFAULT`였고 시험 `ERROR` 238,845건의 출력은 전부 미관측이었다. `DEFAULT`가 실제 서비스 성공이라는 보장은 없으므로 점수는 **그 상태·관측 출력·양수 완료시간에 조건부**다. SwissAI의 같은 서비스·일부 기간은 앞선 다른 정답 연구에서 이미 탐색했고 이번 원본 추출도 시험 레이블 바이트를 파싱했다. 이 시험은 물리적으로 미개봉인 독립 검증이 아니며, 점수 접근만 검증 게이트로 막았다.

출력 토큰 수는 실제 GPU 메모리, VM 수, 배포·Scale-out/in 조치 후 사용자 SLO의 정답이 아니다. 최근 모델별 p90 역시 검증의 기준선이지 운영용 안전 상한으로 채택한 것은 아니다. 새 방법은 다른 서비스나 후속 기간의 미노출 자료에서 별도로 시험해야 한다.

재현: `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python3 scripts/evaluate_swissai_output_tokens.py prepare`로 [고정 모델·manifest](../artifacts/swissai_output_tokens_v1/manifest.json)를 만들고, `validate`로 [검증 점수](../artifacts/swissai_output_tokens_v1/validation.json)를 계산한다. 동일 경로 재실행은 기존 산출물을 덮어쓰지 않는다. [보충 감사 코드](../scripts/audit_swissai_output_tokens_validation_slices.py)는 고정 모델·검증 결과를 읽으며 원래 아티팩트를 바꾸지 않는다. 추출과 일별 피드백·학습·게이트·보충 감사의 합성 테스트 16개가 통과했다. 원본과 행별 추출 파일은 [출처 문서](../data/external/swissai_serving_trace/SOURCE.md)에 따라 로컬에서만 보관한다.
