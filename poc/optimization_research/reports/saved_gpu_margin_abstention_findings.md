# 저장 GPU 후보 선택의 예측 여유값 보류: 사후 전 범위 감사

## 결론

저장 모델의 정적 8후보 선택 결과에서 예측 여유가 작은 승인만 보류하면, **엄격한 처리량 목표에서 생긴 오승인 일부**는 제거된다. 그러나 느슨한 처리량 목표와 별도 입력 캠페인에서는 **예측 여유가 10% 이상인 오승인**도 남는다. `0.10`과 `0.20` 여유값 문턱 모두 정상 승인을 잃으며, 현재 자료로는 어느 문턱도 자동 배포 승인 정책으로 채택하지 않는다.

이 감사는 이전 [저장 판단 사후 감사](saved_gpu_shape_decision_audit_findings.md)의 결과와 오승인 여유값을 **이미 본 뒤** 수행했다. 아래 문턱은 탐색적 진단이며 새 독립 시험이나 안전율의 증명이 아니다.

## 방법

고정된 결정 2,660행 (`../artifacts/saved_gpu_shape_decision_audit_v1/decision_rows.csv`)의 SHA-256을 확인한 뒤, 저장 모델의 1,330개 결정만 읽었다. 한 결정에서 이미 선택한 후보의 `minimum_predicted_relative_margin`이 문턱보다 작으면 **선택을 보류**한다. 더 큰 후보로 다시 선택하거나 예측 모델을 재학습하지 않는다. 각 캠페인·목표별로 승인 성공, 오승인, 보류한 기존 성공을 같이 센다. 원래 목표의 90/10/33 작업군과 기존 저장 모델의 54/9/25 승인·전원 성공을 원본 집계와 대조했다. 아홉 민감도 목표는 각 작업군의 **같은 물리 실행을 재사용**한다.

| 캠페인·목표 | 여유 문턱 0: 성공/오승인 | 0.10: 성공/오승인 | 0.20: 성공/오승인 |
| --- | ---: | ---: | ---: |
| 주 시험, 원 생성 목표 | **54/0** | 51/0 | 48/0 |
| 주 시험, 요청/초 목표 ×0.75 | **55/1** | 51/1 | 48/0 |
| 주 시험, 요청/초 목표 ×1.25 | **46/4** | 40/0 | 38/0 |
| 새 입력 `novel-matrix`, 원 목표 | **9/0** | 9/0 | 9/0 |
| 새 입력 `space-filling`, 원 목표 | **25/0** | 21/0 | 18/0 |
| 새 입력 `space-filling`, 요청/초 ×0.75 | **26/3** | 25/3 | 24/0 |
| 새 입력 `space-filling`, 요청/초 ×1.25 | **18/2** | 18/0 | 17/0 |

표의 `요청/초 ×...` 행은 지연 목표를 원래 값으로 둔 결과다. 나머지 지연 배율 `0.75/1.25`를 포함한 **전 30개 캠페인·목표 조합**은 [결과 JSON](../artifacts/saved_gpu_margin_gate_v1/results.json)에 있다. 주 시험의 느슨한 처리량 목표 오승인 예측 여유는 **11.45%**, `space-filling`의 세 오승인은 **17.76~19.30%**여서 10% 문턱을 통과한다. `novel-matrix`의 다른 합성 목표에서는 오승인 여유가 **24.5%와 30.2%**까지 올라 20% 문턱도 통과한다. 따라서 작은 예측 여유만 오류의 원인이라는 설명은 자료와 맞지 않는다.

## 해석과 다음 단계

이 진단은 한 호스트의 배치 p95·샘플/초 예측과 수집기가 만든 목표를 사용한다. `GPU 2개`는 한 호스트의 두 복제 프로세스이며 두 VM이 아니다. 같은 작업군을 여러 목표로 재채점한 결과는 독립 서비스 요청이 아니고, 여유값을 고르는 데 이미 사용한 시험 결과를 다시 사용했다. `0.20`에서 표 일부의 오승인이 0이 되어도 운영 오승인률의 상한이나 새로운 모델·호스트의 안전성을 말할 수 없다.

현재 판단 출력에는 선택 후보의 예측 여유와 지원 범위를 **진단 신호로만** 남긴다. 후보 호환성·오승인 위험을 새로 학습하려면 사용자 SLO와 새 AI 모델·호스트에서 여러 형상을 실제로 측정한 자료가 필요하다. 특히 단순 문턱 이상의 오류가 발견됐으므로, 별도 홀드아웃을 확보하기 전에는 이 값으로 `DEPLOY`나 `SCALE_OUT/IN`을 자동 승인하지 않는다.

재현: `python poc/optimization_research/scripts/audit_saved_gpu_margin_gate.py`. [감사 코드](../scripts/audit_saved_gpu_margin_gate.py)는 입력 해시·중복 키·30개 조합의 피복·선택/성과 논리·원 목표 집계를 검사한다.
