# AI-MCMP 방법론의 현재 기여 범위: 독립 문헌 검토

## 판정

현재 가장 강하게 말할 수 있는 것은 **같은 입력 조건 격자를 공유하는 encoder 모델에서, 이전 모델의 교차검증 예측 잔차를 이용한 소수 측정 보정이 유용했다**는 탐색적 실증 결과다. 모델당 GPU 1개·CPU 2코어 측정 8회, 평균 5.76 GPU-wall초를 똑같이 사용했을 때, encoder 8모델의 지연/요청 처리량 평균 절대 로그오차는 잔차 전이 **0.235/0.119**, 부드러운 커널 **0.247/0.135**, 직접 Ridge **0.251/0.142**였다. 수집기가 생성한 SLO에서 실제 가능한 309개 조건 중 성공은 각각 **298/290/292개**였다. [실험 방법과 모델별 결과](cross_model_covariance_findings.md)

이 결과는 프로젝트에 쓸 만한 **형상 성능 예측기 후보**를 뒷받침한다. **새 알고리즘의 학술적 최초성, 새 작업·호스트로의 일반화, 실제 사용자 SLO 개선을 뒷받침하지는 않는다.** 현 SQLite만으로 독립 검증까지 가능한, 선행연구와 분명히 구별되는 새 방법론을 찾지 못했다. 알고리즘의 조합과 사용 맥락을 경희대 구현 기여로 설명할 수는 있지만, 그 조합 자체를 검증된 학술적 노벨티로 제시해서는 안 된다.

## 가까운 선행연구와 차이

| 현재 연구의 요소 | 이미 발표된 가장 가까운 원리 | 남는 차이와 판정 |
| --- | --- | --- |
| 적은 신규 모델 측정으로 자원 성능을 전이하고 형상을 고르기 | [Paragon, ASPLOS 2013](https://people.csail.mit.edu/delimitrou/papers/2013.asplos.paragon.pdf)은 이전 응용 정보와 신규 응용의 짧은 프로파일을 결합한다. [Quasar, ASPLOS 2014](https://www.csl.cornell.edu/~delimitrou/papers/2014.asplos.quasar.pdf)는 QoS 제약에 맞는 자원 크기와 배치를 판단한다. | 여기서는 단일 VM의 AI 추론에서 요청 조건별 GPU 복제·CPU 한도의 성능을 다룬다. 적용 범위의 차이이며 소수 프로파일 후 추천이라는 원리의 신규성은 아니다. |
| 과거 모델의 잔차 표면에서 공분산을 만들고 새 모델의 8개 관측에 조건화하기 | [Schwaighofer 등, NeurIPS 2004](https://papers.nips.cc/paper_files/paper/2004/hash/453fadbd8a1a3af50a9df4df899537b5-Abstract.html)은 여러 자료의 고정 입력점에서 비모수 공분산을 학습한다. [구조적 잔차 다중작업 GP, NeurIPS 2013](https://papers.nips.cc/paper_files/paper/2013/hash/59c33016884a62116be975a9bb8257e3-Abstract.html)는 작업 간 잔차 상관을 명시한다. [Empirical Gaussian Processes, 2026](https://arxiv.org/html/2602.12082)는 과거 궤적의 경험적 평균·공분산으로 새 궤적의 일부 관측을 조건화하고 불규칙한 입력 위치까지 다룬다. | 여기서는 **기본 성능 예측기의 내부 모델 제외 잔차**를 prior로 만들고, 예측한 기준 형상을 별도 자원 반응 모델로 전파한다. 도메인에 맞춘 2단 구성은 구체적이나, 경험적 공분산 조건화 자체를 새 원리로 주장할 수 없다. 특히 2026 논문은 격자 밖에서 기본 커널로 돌아가는 불확실성 처리도 다룬다. |
| 어떤 조건을 먼저 측정할지 순차적으로 고르기 | [CherryPick, NSDI 2017](https://www.usenix.org/conference/nsdi17/technical-sessions/presentation/alipourfard)은 적은 실행으로 클라우드 설정을 고르는 Bayesian optimization이다. [L2S, ESEC/FSE 2018](https://www.cs.cmu.edu/~mvelezce/publications/JVKS-FSE18.pdf)는 원천 환경 정보를 이용해 대상 환경의 측정 위치를 고른다. [FleetSieve, 2026](https://arxiv.org/html/2608.19659)는 지연·용량의 SLO 판단에 중요한 프로파일을 고른다. | 현재의 관측 잔차 기반 순차 규칙은 같은 초기 4개를 쓰는 관측 없는 정적 대조군보다 예측 오차와 합성 SLO 성공이 조금 나빴다. [실험](adaptive_probe_transfer_findings.md)상 방법 기여 후보가 아니다. |
| 예측값으로 두 제약을 만족하는 최소 자원 형상 고르기 | [Feasibility-Aware Decision-Focused Learning, NeurIPS 2025](https://papers.nips.cc/paper_files/paper/2025/hash/ef158a0d4f5364741a571b8d1d44fb1b-Abstract-Conference.html)은 예측된 제약값의 가능성과 선택 품질을 함께 최적화한다. FleetSieve도 SLO 판단 중심 측정과 보수·낙관 결정을 다룬다. | 현재의 SLO는 수집기 또는 훈련 자료 분위수로 만든 목표다. 실제 가격과 사용자 SLO가 없어서 결정 손실이나 안전성을 새 방법으로 입증할 수 없다. |

이 표는 *관련 원리가 먼저 발표되었다*는 판단이다. 해당 선행연구가 현재의 코드와 완전히 같은 구현이라는 뜻은 아니다. 이 구현의 구체적인 조합이 발표 가능한 기여인지 판단하려면 강한 재구현 기준선과 독립 실험이 더 필요하다.

## 내부 실험이 더해 준 증거와 반증

- 원래 구현의 행렬은 중심화 공분산이 아니라 잔차의 **비중심 2차 모멘트**다. 별도 실험에서 중심화하고 평균을 0으로 둬도 공유 격자 오차가 **0.236/0.118**로 유지됐다. 조건별 donor 평균만 부드러운 커널에 더한 방식은 **0.246/0.136**이었다. 따라서 이득을 단순 평균 편향 전이로만 설명하기 어렵다. [분해 결과](covariance_bias_ablation_findings.md)
- donor마다 지연·처리량 잔차 쌍을 64가지 시드로 입력 조건 사이에 섞자, 원래 정렬의 **0.2351/0.1192와 생성 SLO 성공 298개**가 순열 대조군 평균 **0.2559/0.1529와 291.3개**보다 좋았다. 그러나 순열은 조건별 평균과 공분산 구조를 함께 무너뜨리므로 **공분산만의 인과 효과**를 분리한 실험은 아니다. 방법을 동일 자료에서 탐색한 뒤 계산한 `1/65` 순위도 확증적 p값이 아니다. [순열 대조](covariance_permutation_control_findings.md)
- 공유 격자 개선의 약 절반이 BERT L4-H256 한 모델에서 나온다. 같은 모델의 새 입력 조건에서 처리량 전이는 역효과가 났다. 새 조건의 encoder 전체 처리량 MALE은 공분산 보간이 novel-matrix **0.379**, space-filling **0.352**로 커널 **0.361/0.324**, Ridge **0.348/0.314**보다 나빴다. 새 조건 지연만 부드러운 자원 반응으로 조금 개선한 후속 방식도 생성 SLO 선택 성공은 늘리지 못했다. [격자 밖 결과](cross_model_covariance_findings.md), [자원 반응 실험](physical_response_transfer_findings.md)
- 등록 BERT 네 모델을 함께 학습에서 빼면 공분산의 지연 오차 이점은 커널 대비 **0.0006**에 그쳤다. DistilBERT까지 함께 빼면 대상 다섯 모델의 지연 오차는 공분산 **0.3868**, 커널 **0.3695**로 역전됐다. 처리량 이점은 남았지만 생성 SLO 성공은 양쪽 모두 **209/217**이었다. [계열 공동 제외](family_holdout_transfer_findings.md)
- donor 잔차의 평균을 제거한 공분산도 같은 계열 공동 제외에서 다시 시험했다. 다섯 모델의 지연은 **0.3853 대 커널 0.3695**, 처리량은 **0.1243 대 0.1472**, 생성 SLO 성공은 **208 대 209**였다. 원래 행렬의 비중심 평균 성분을 제거해도 지연·처리량 상충은 해결되지 않는다. [중심화 검증](family_holdout_centered_findings.md)
- 같은 수집기 버전의 반복 실행에서 얻은 새 입력 조건 10개·16 GPU 셀을 평가하면 공분산/커널 지연 오차 **0.2275/0.2292**, 처리량 오차 **0.2683/0.2681**이었다. 생성 SLO에서 비교 가능한 GPU 선택 여섯 건은 두 방법이 같았다. [반복 측정 검증](live_repeat_transfer_findings.md)
- 실행 중 GPU 1개의 계측을 더하면 GPU 2개 처리량 예측은 주 캠페인 **0.112→0.098**, 새 space 조건 **0.171→0.123**으로 나아졌다. 그러나 지연은 일관되지 않았고 가상 Scale-out 승인에서는 성공·잘못된 승인의 상충이 남았다. 모니터링을 쓴 복제 후 성능 예측은 [MLscale](https://research.ibm.com/publications/using-machine-learning-for-black-box-autoscaling) 등 선행연구가 있다. [계측 조건부 실험](telemetry_conditioned_scaling_findings.md)
- 등록 BERT 네 모델을 함께 뺀 모니터링 예측에서는 주 캠페인의 처리량 개선이 **0.0952→0.0947**로 작고 novel 조건에서는 **0.0878→0.0986**으로 악화됐다. Space 조건의 개선은 BERT-base 한 모델에 집중됐으며, 가상 판단에서 성공·오승인이 함께 늘었다. [계측 방식의 계열 검증](telemetry_family_holdout_findings.md)
- 모니터링 값 네 개를 대상 작업 사이에 함께 섞으면 GPU 2개 처리량 오차는 **0.0961→0.1167**, 같은 배치 크기 안에서 섞어도 **0.1094**로 늘었다. 조건에 맞춘 계측값이 예측 정보를 준다는 내부 근거이지만, 실제 Scale-out action이나 다른 계열의 성공을 보장하지 않는다. [계측 순열 대조](telemetry_permutation_control_findings.md)
- 새 입력 조건에 어떤 잔차 보정기를 적용할지 훈련 donor의 모델×조건 중첩 검증으로 골랐지만, 아홉 분할 모두 공분산을 선택했다. 외부 조건의 처리량 역효과와 SLO 성과는 그대로였다. 이 자료의 donor 내부검증으로는 조건 분포가 달라질 때 필요한 선택을 식별하지 못했다. [방식 선택 실패 실험](support_hybrid_transfer_findings.md)
- 훈련 자료로 만든 25개 SLO쌍에서는 총 14,375개 질의 중 **73.6%가 형상 전부 가능하거나 전부 불가능**했다. 일부만 가능한 질의에서는 공분산이 커널보다 성공 56건 많고 잘못 승인 22건 적었지만, Ridge보다 성공 64건 많은 대신 잘못 승인 35건 많았다. 한 workload의 목표를 25번 바꿔 얻은 질의를 독립 표본처럼 세면 안 된다. [난도 감사](slo_case_mix_findings.md)

## SQLite만 있을 때의 다음 질문

**검증할 좁은 가설:** “입력 조건이 과거 모델과 정확히 정렬되는 경우의 잔차 전이는 모델군 전체에서 커널보다 낫고, 정렬되지 않는 경우에는 다른 모델의 자료만 보고 전이를 줄여 커널보다 해롭지 않게 할 수 있는가?” 이는 **새로운 원리라는 주장**이 아니라 현재의 가장 큰 실패 지점인 격자 밖 역전이를 겨냥한 검증 질문이다. 측정한 대상 모델의 미측정 형상 값이나 외부 캠페인 결과로 게이트를 조정해서는 안 된다. 기존의 정확한 donor 개수 게이트와 앵커 내부검증 게이트는 처리량·지연을 동시에 개선하지 못했다. [게이트 실험](support_aware_transfer_gate_findings.md)

기존 SQLite로는 새 규칙을 훈련 donor의 모델 단위·입력 조건 블록 단위 분할에서 설계하고, 모델별 오차·잘못 승인·정확한 최소 형상·GPU-wall을 함께 점검할 수 있다. 특히 BERT L4-H256 제외, 모델 계열 제외, 새 입력 캠페인별 성능을 반드시 나눠야 한다. 하지만 기존 외부 캠페인 결과를 이미 여러 방법 설계에 참고했으므로 **재사용된 SQLite에서 얻는 모든 새 개선은 탐색 결과**다. 새 규칙이 좋아지더라도 학술적 최초성이나 독립 검증의 빈자리는 채워지지 않는다. 선행 [Empirical GP](https://arxiv.org/html/2602.12082)의 격자 밖 기본 prior 복귀와 [설정 성능 전이 연구](https://arxiv.org/abs/1709.02280)의 환경 변화별 전이 한계와 직접 비교해야 한다.

현재 학습·평가 자료에는 자연어 사용자 요청과 정답 요구 형상, 시간 순서의 scale action·사후 결과, VM 가격, 실사용자 요청 지연 SLO가 없다. 원격 RTX 5070 Ti의 새 causal LM 두 개는 모델·호스트·작업 종류가 동시에 달라져 공분산 효과의 독립 분리가 불가능하다. 단일 실행의 배치 p95와 실제 요청 p95도 구분해야 한다. [데이터 범위](novelty_gap_and_next_experiment.md), [반복 측정 변동](repeat_variability_findings.md)

**권고:** 공유 조건 encoder의 잔차 전이는 연구용 예측기 후보로 유지한다. 요구사항 분석과 Scale-out/in 학습의 성과, 운영용 배포 안전성, 새로운 알고리즘의 노벨티는 지금 주장하지 않는다. 원자료만 쓸 수 있는 동안에는 이 실패 범위와 재현 가능한 평가를 명확히 남기는 것이 다음 독립 실험의 출발점이다.
