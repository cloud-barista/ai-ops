# GenTD26 요청시간 예측의 커버리지 제약 실험

## 결론

검증 구간에서 커버리지를 **92%**로 맞춘 보정은 5개 비중복 시험 구간 13,415건을 합쳤을 때 기존 모델 ID 보정의 커버리지를 **88.9% → 92.2%**로 높였다. `IMG_2_IMG`는 **85.2% → 90.8%**, `M0003`은 **85.6% → 90.1%**였다. 평균 p90 pinball 손실은 **2.637 → 2.693초**로 늘었지만 전역 rolling 기준선 **2.775초**보다 낮았다.

이 합산 결과는 **요청마다 90% 상한을 보장하지 않는다.** 12월 1일 시작 시험 구간의 전체 커버리지는 **86.5%**였고, `IMG_2_IMG`는 **80.0%**, `M0003`은 **86.6%**였다. 따라서 배포·스케일링 판단에 적용할 정책으로 채택하지 않는다. 검증 라벨이 부족한 집단과 분포 변화에 대한 안전장치가 추가로 필요하다.

## 데이터와 평가 방법

- 자료는 Alibaba [GenTD26 요청 추적 자료](https://github.com/alibaba/clusterdata/tree/8c132fb7717fbd44cf434cf81f2cd865a80072d5/cluster-trace-v2026-GenAI)의 `lora_request_trace.csv`다. 성공 요청의 기록된 `exec_time_seconds`를 예측했다. 이 자료는 실제 완료 시각을 제공하지 않아 레이블 가용 시각을 **요청 생성 시각 + 실행시간 + 추가 1시간**으로 가정했다.
- [기존 5개 시점 평가](gentd26_walkforward_findings.md)의 학습·잔차 초기화·정책 선택·시험 구간을 유지했다. 기본 p90 모델은 각 시점에서 다시 학습했고, 정책 선택은 해당 시험 시작 전까지 가용하다고 가정한 레이블만 사용했다. 시험 구간 5개는 서로 겹치지 않는다.
- 기준선은 검증에서 선택한 **전역 rolling 잔차 보정**과 **기존 모델 ID·요청 종류 보정**이다. 새 보정은 이 두 예측을 0%, 25%, 50%, 75%, 100% 비율로 혼합한다. 각 혼합에 대해 검증 레이블로만 비음수 여유 시간을 정한다. 먼저 전체 요청, 이어 검증 표본 100건 이상인 요청 종류, 마지막으로 100건 이상인 모델 ID에 목표 커버리지를 충족하는 최소 여유 시간을 더한다. 같은 검증 구간에서 pinball 손실이 가장 작은 혼합을 선택한다.
- 목표 커버리지 **90%와 92%** 두 설정을 별도 비교했다. 92% 목표와 100건 지원 문턱은 기존 시험 진단에서 커버리지 미달을 확인한 뒤 구성한 **후향적 가설**이다. 92%는 시간 변화에 대한 단순한 여유치이며, 신뢰수준이나 미래 커버리지의 통계적 보증은 아니다. 검증 구간의 같은 레이블로 여유 시간과 혼합비를 모두 골랐으므로 검증 점수는 낙관적일 수 있다.
- 두 설정의 모든 시점에서 검증 전체 커버리지와 지원되는 요청 종류·모델 ID 각각의 검증 커버리지는 설정 목표 이상이었다. 시험 결과로 여유 시간, 최소 표본 수, 혼합비를 다시 선택하지 않았다.

## 해석과 사용 범위

검증 커버리지를 명시적으로 제한하면 그룹 보정의 손실 이점 일부를 유지하면서 합산 커버리지를 높일 수 있다. 그러나 다섯 구간 중 한 구간은 두 설정 모두 90% 아래였고, 92% 설정은 평균 예측시간을 기존 그룹 보정보다 **3.4초** 높였다. 앞으로는 지원되지 않는 집단에서 결정을 보류하는 방식과 분포 변화 감지를 검토할 수 있다. 이 자료만으로 어느 방식의 운영상 효과를 확인할 수는 없다.

이 평가는 **같은 공개 추적 자료 안의 후향적 방법 개발**이다. 기존 그룹 보정과 이번 커버리지 제약 모두 일부 시험 기간의 진단을 본 뒤 개발되었으므로 독립 재현으로 해석하지 않는다. 새 기간과 실제 레이블 도착 시각으로 재검증하기 전에는 **운영 상한 정책으로 채택하지 않는다**. 실제 응용 지연 SLO, 정확한 결과 도착 시각, VM 증감 행동과 그 반사실적 결과가 없다. 따라서 이 결과는 **요청 실행시간 상한 보정**에만 해당하며 배포·스케일링 행동의 효용이나 안전성을 입증하지 않는다.

재현:

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 python scripts/evaluate_gentd26_coverage_guard.py
python -m unittest discover -s tests -p 'test_gentd26_coverage_guard.py' -v
```

실행 코드: [`evaluate_gentd26_coverage_guard.py`](../scripts/evaluate_gentd26_coverage_guard.py). 각 시점의 선택 정책, 커버리지, 원본·스크립트 SHA256: [`metrics.json`](../artifacts/gentd26_coverage_guard_v1/metrics.json). 요청별 예측: `test_predictions.parquet` (`../artifacts/gentd26_coverage_guard_v1/test_predictions.parquet`). 전역·기존 그룹 예측은 이전 5개 시점 산출물과 같은 13,415건에서 **최대 절대 오차 0초**로 일치했다. 작은 계약 테스트 3개를 통과했다.
