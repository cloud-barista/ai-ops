# 두 자원 축 희소 측정 가설: 현재 자료에서는 채택하지 않음

## 질문과 설계

새 AI 모델의 여러 요청 조건에서 GPU 1개·CPU 2코어를 여섯 번 측정한 뒤, 같은 요청 조건 하나를 GPU 2개·CPU 2코어로 한 번 더 측정하면 자원 변경에 따른 성능 오차를 효율적으로 보정할 수 있는가?

- 주 평가: 모델 9개에 대해 하나씩 모델 전체를 제외하고 학습했다. 기존 [교차 모델 공분산 방식](../scripts/cross_model_covariance.py)으로 측정하지 않은 요청 조건의 기준 성능을 추정했다. 학습 모델과 테스트 모델의 성능 결과는 분리했다.
- 공통 측정 위치: 요청 조건을 고르게 덮는 medoid 방식으로 GPU 1개·CPU 2코어의 요청 조건 6개를 골랐다. 추가 GPU 2개 측정은 그 6개 중 전체 입력 조건의 중심과 가장 가까운 곳(`dual_center`) 또는 다른 모델만으로 학습한 측정 시간 모델이 가장 저렴하다고 예측한 곳(`dual_cheapest`)에 배치했다.
- 보정: 추가 측정의 실제 로그 지연시간과 로그 처리량에서 여섯 기준 측정으로 예측한 값을 뺀 뒤, 그 차이를 모든 GPU 2개 후보에 적용했다. 이 단순한 보정은 새로운 학습 모델의 효과와 측정 축의 효과를 구분하기 위한 탐색 가설이다.
- 기준선: 같은 공분산 모델에서 GPU 1개 기준 측정만 6·8·16·32번 수행했다. 각 방법의 예측 오차는 **모든** 테스트 요청 조건의 기준 이외 자원 7개에서, 배포 판단은 같은 8개 후보에서 평가했다. GPU-wall 비용은 `wall_seconds × GPU 개수`의 합이다.

## 결과

| 방법 | 모델당 평균 GPU-wall초 | 지연시간 로그 절대오차 | 처리량 로그 절대오차 | 성공한 선택 / 가능한 요청 357개 | SLO 위반 선택 |
|---|---:|---:|---:|---:|---:|
| 기준 6회 | 4.75 | 0.248 | 0.136 | 333 | 14 |
| 기준 8회 | 6.96 | 0.238 | 0.127 | 338 | 18 |
| 기준 16회 | 14.86 | 0.231 | 0.106 | 341 | 17 |
| 6회 + GPU 2개 1회, 중앙 조건 | 9.33 | 0.253 | 0.153 | 331 | 14 |
| 6회 + GPU 2개 1회, 예상 최저 비용 조건 | 9.10 | 0.307 | 0.149 | 336 | 19 |

`dual_center`는 기준 8회보다 모델당 평균 2.37 GPU-wall초를 더 쓰면서 지연시간과 처리량 오차가 각각 0.015와 0.026 높았다. 모델 9개를 단위로 한 paired bootstrap의 95% 구간은 처리량 오차 차이에 대해 **[+0.003, +0.057]**, 비용 차이에 대해 **[+1.47, +3.50]**이었다. 성공한 배포 선택도 7건 적었다. `dual_cheapest`는 기준 8회보다 평균 2.15 GPU-wall초를 더 쓰고 지연시간 오차가 0.069 높았다. 이 차이의 모델 단위 95% 구간은 **[+0.015, +0.127]**이다. 중앙 조건 방식은 9개 모델 모두에서 기준 8회보다 비쌌고, 예상 최저 비용 방식도 8개 모델에서 비쌌다.

GPU 2개 측정 한 번의 비용 중앙값은 약 3.82 GPU-wall초로, GPU 1개 기준 측정 한 번의 0.60초보다 컸다. 추가 측정으로 직접 관측한 GPU 2개 후보 하나는 정확해졌지만, 그 오차를 모든 요청 조건의 GPU 2개 후보에 동일하게 옮기면 대체로 오차가 커졌다. Qwen 같은 일부 모델의 지연시간 오차는 개선됐지만 전체 모델과 비용을 함께 보면 이 정책을 채택할 근거가 없다.

## 결론과 검증 범위

**이 가설은 현재 자료에서 실패했다.** 추가 GPU 2개 측정을 위한 외부 조건 평가나 더 복잡한 보정 모형으로 확장하지 않는다. 새 방법의 이점을 주장할 수 있는 결과가 아니다.

측정하지 않은 테스트 성능값을 100배 바꿔도 이 방법의 예측이 변하지 않는 테스트를 포함해 [전체 테스트 47개](../tests/test_dual_axis_sparse_probe.py)가 통과했다. 주 실험의 입력 스냅샷·스크립트·의존 파일 해시, 모델별 값, 측정 위치, 예측값과 bootstrap 비교는 [재현 아티팩트](../artifacts/dual_axis_sparse_probe_v1/metrics.json)에 기록했다. 이 실험은 단일 호스트의 9개 모델과 수집 스크립트가 생성한 SLO에 한정된다.
