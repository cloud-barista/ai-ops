# SwissAI 상대 수요 p90 후속 실험: 보류 기간의 표본 게이트 실패

2026-09-28. [첫 요청량 실험의 실패](swissai_demand_findings.md)를 보고 고정한 [후속 규약](swissai_scale_adaptive_protocol.md)에 따라, **모델 학습·예측 점수 계산 전에** 2025-08-16~10-16 UTC의 판단 행을 감사했다. 새 기간은 두 모델을 그대로 시험하도록 예약했지만, 두 번째 모델의 활동 표본이 사전 기준에 못 미쳤다. 따라서 상대 수요 학습기와 절대 건수 학습기를 **적합하지 않았고, 보류 기간 점수도 계산하지 않았다.** 이 결과는 방법의 성능 실패가 아니라 **자료 적격성 실패**다.

## 고정 자료와 품질 검사

원본·축약 SwissAI 해시와 앞 실험 개발 판단 행의 SHA256 `d8443b67a500ca443e8d556152e5da299d63ebb1f81f05f4e5661c17af418c89`가 일치했다. 후속 규약 SHA256은 `ee2064ed62a86a9eae0ff03c57ffb92fdea0fbf70d840a364db0a6a4e6aa3c59`다. 앞 실험의 학습·검증·첫 시험 판단 **18,893개 전부**를 예정 개발 행으로 읽었으며, 새 기간의 모델 선택에는 사용하지 않았다. 기존 두 모델 별칭 `45363f1dab`, `99668f5da8`을 유지했다.

전역 5분 격자 판단 시각은 17,567개다. 직전 10분의 전역 요청 부재 또는 이미 관측한 6시간 이상 공백 뒤 120분 보류를 적용하면 **4,715개(26.84%)**가 남아 전역 ≥20% 기준은 통과한다. 모델별 결과는 다음과 같다. 양수/0은 *미래 10분 요청 수*가 각각 양수/0인 판단 행 수다. 이 값은 예측 점수가 아니다.

| 모델 별칭 | 새 기간 원시 요청 | 활성 판단 | 적격 판단 | 양수 / 0 정답 | 판정 |
| --- | ---: | ---: | ---: | ---: | --- |
| `45363f1dab` | 155,686 | 1,727 | 932 | 528 / 404 | 표본 기준 통과 |
| `99668f5da8` | **396** | 252 | **134** | **18 / 116** | 적격 판단 ≥500, 양수 ≥100 기준 실패 |

두 모델의 활성 판단 보존율은 각각 53.97%, 53.17%로 ≥50% 기준을 넘는다. 시험 전체의 원시 요청 수는 **514,569건**이지만, 그 대부분은 이 고정 두 모델 외의 요청이다. 후속 규약은 *두 모델 모두* 시험할 수 있어야 점수를 내도록 했으므로 한 모델만 남기거나 다른 모델로 대체하지 않는다. 시험 종료일을 옮기거나 임계값을 낮추는 것도 이 평가에는 적용하지 않는다.

감사에서 각 모델의 마지막 적격 판단 시각은 `45363f1dab`이 **2025-09-06 22:15 UTC**, `99668f5da8`이 **2025-08-30 22:00 UTC**였다. 이후 해당 모델의 적격 판단이 없는 까닭이 실제 사용 중단인지 기록 누락인지는 이 자료만으로 구분하지 못한다.

## 재현과 남은 범위

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 /usr/bin/python scripts/evaluate_swissai_scale_adaptive.py --dry-run
pytest -q tests/test_swissai_scale_adaptive.py
```

[dry_run.json](../artifacts/swissai_scale_adaptive_v1/dry_run.json)에 출처·코드·규약·개발 행 해시, 전역·모델별 건수와 실패 이유가 있다. holdout_rows.parquet (`../artifacts/swissai_scale_adaptive_v1/holdout_rows.parquet`)에는 품질 감사용 익명화 판단 행 **1,066개**가 저장돼 있다. 이 파일에는 학습 모델의 예측값이 없으며 `metrics.json`이나 학습 모델 파일도 만들지 않았다. 2025-10-16 이후 생성 요청은 이 실험의 특징·판단·점수에 사용하지 않았다. 파일 배치 경계가 종료일을 가로지를 수 있어 Parquet 읽기 단위가 그 이후의 바이트를 물리적으로 포함할 수는 있지만, 해당 행은 처리하지 않았다.

특징 정규화·역변환·시간 경계·중복 행 검사 등의 합성 테스트 7개는 통과했다. 품질 게이트 실패 때문에 실제 자료에 대한 학습·점수 코드 경로는 실행하지 않았으며, 모델 성능에 관한 결론을 내리지 않는다.

이 실패는 공개 서비스의 모델 교체·활동 변화가 **고정 모델 집합의 후행 평가 가능성 자체를 약화**시킬 수 있음을 보여 준다. 원인을 특정하거나 상대 수요 방법의 우열을 판단할 근거는 없다. 실제 VM/GPU 수, 사용자 SLO, 스케일 명령과 전환 결과도 이 자료에는 없어 운영 scale 효과를 평가할 수 없다.
