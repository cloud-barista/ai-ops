# Alibaba MaaS 상태별·결측 인식 GPU 위험: 같은 주 후속 탐색

2026-09-28. 이 평가는 [기존 MaaS GPU 위험 실험](maas_instance_risk_findings.md)의 실패 결과를 확인한 뒤 작성한 [후속 가설](maas_risk_prior_art_and_next_hypothesis.md)을 시험한다. 점수 계산 전 [구현 선택](maas_state_followup_implementation_note.md)과 [코호트 감사](../artifacts/maas_state_followup_v1/dry_run.json)를 고정했다. **같은 공개 추적 자료의 같은 주 시험일을 재사용한 탐색 결과**이며 독립 검증이 아니다.

## 결론

완전 창·현재 정상 상태 53,513건에서 새 상태별 로지스틱의 Brier는 **0.019403**으로, 기존 검증 선택 기준선 **0.020702**보다 상대 **6.28%** 낮았다. 기존 저장 단일 로지스틱의 0.138259보다도 낮았다. 두 시험일의 Brier, 전체 AP, 일자별 상위 5% 경보 재현율도 두 기존 비교군보다 좋아 [사전에 정한 성공 기준](maas_state_followup_implementation_note.md)을 충족했다. 기존 기준선과 모델의 **저장된 예측**을 같은 217,672개 완전 창 시험 행에 일대일 연결했고, 정답·현재 상태가 모두 일치했다. 다만 **시험 점수를 본 뒤** 추가한 현재 정상 전용 단순 Beta 기준선의 Brier는 **0.020339**였다. 이 기준선 대비 새 상태별 모델의 상대 이득은 **4.60%**로 사전 5% 문턱보다 작다. 이 사후 비교는 원래 판정을 변경하지 않지만 성과의 크기를 판단할 때 함께 봐야 한다.

그러나 확대 학습 집단의 **새 단일 로지스틱**은 이 층에서 Brier **0.019285**로 상태별 모델보다 조금 좋았다. 따라서 성과를 상태별 분리만의 효과나 새로운 스케일링 알고리즘의 검증으로 해석할 수 없다. 부분결측·현재 정상 상태에서도 새 단일 모델 0.128041, 상태별 모델 0.128556이었다. 계측 유효성 마스크를 뺀 상태별 절제 모델은 각각 0.021016, 0.234164로 악화했지만, 이 비교 역시 같은 주 사후 탐색이다.

## 시각, 집단, 점수 전 게이트

원자료는 감사된 Alibaba MaaS 주간 1% 인스턴스 ID 표본의 5분 평균 창이다. 판단 `d=t+600초`에서 `t−600,t−300,t`의 관측 창만 입력한다. 정답은 `t+600`부터 `t+2100`까지 여섯 창 중 SM ≥80% 또는 GPU 메모리 ≥90%인 창이 있는지다. 마지막 정답이 전달된다고 가정한 `d+2100초`가 분할 끝 안에 들어야 한다. 실제 전달 시각이 기록된 것은 아니다. 미래 창의 누락은 **정답 미관측**으로 처리한다. 미래 클러스터·GPU 수 변경은 진단에만 사용하고 입력에 넣지 않았다.

| 집단·층 | 학습 적격/양성 | 검증 적격/양성 | 시험 적격/양성 |
| --- | ---: | ---: | ---: |
| 완전 창 전체 | 385,242 / 287,256 | 99,713 / 80,856 | 217,672 / 165,835 |
| 완전 창 현재 정상 | 102,357 / 5,281 | 20,168 / 1,432 | 53,513 / 1,899 |
| 과거 부분결측 전체 | 31,107 / 24,121 | 7,594 / 6,277 | 14,318 / 11,697 |
| 과거 부분결측 현재 정상 | 11,866 / 4,942 | 2,562 / 1,249 | 4,727 / 2,119 |

네 집단·층은 모두 각 분할의 적격 ≥2,000, 양성·음성 각각 ≥100, 양성 인스턴스 ≥30 게이트를 통과했다. 두 시험일의 현재 정상층 양성도 완전 창 **1,174/725**, 부분결측 **1,112/1,007**로 각각 100건 이상이다. 현재 창은 있으나 무효·중복인 시험 판단 키 **109,697개**는 `INSUFFICIENT_EVIDENCE`로 세어 예측하지 않았다. 현재 행 자체가 없는 달력 시각은 후보를 열거할 수 없다.

상태별 로지스틱 적합을 위한 양쪽 클래스 게이트도 [점수 전 감사](../artifacts/maas_state_followup_v1/dry_run.json)에 기록했다. 확대 학습 집단의 현재 정상은 학습 양성/음성 **10,223/104,000**, 검증 **2,681/20,049**이며, 현재 초과는 학습 **301,154/972**, 검증 **84,452/125**였다. 네 상태·분할 모두 두 클래스가 있었다.

과거 부분결측은 현재 창이 유효하고 오래된 두 창 중 하나 이상이 없거나 중복·무효인 경우다. 후보 집단을 **현재·과거만으로 먼저** 정하고, 그 뒤 미래 여섯 창을 통한 정답 관측률을 감사했다. 시험 후보 전체의 정답 관측률은 완전 창 **217,672/271,023(80.3%)**, 부분결측 **14,318/23,072(62.1%)**다. 주 평가층인 현재 정상 후보에서는 각각 **53,513/65,191(82.1%)**, **4,727/9,571(49.4%)**다. 시험 부분결측 후보의 과거 사유는 최초 창 없음 9,661, 중간 창 없음 2,823, 최초 창 중복 8,252, 중간 창 중복 8,970, 최초 창 무효 300, 중간 창 무효 338건이다. 사유는 서로 겹친다. 정답을 관측한 행에서는 미래 클러스터·GPU 수 변경이 양쪽 집단 모두 0건이었다.

## 방법과 같은 행 비교

새 단일 모델과 정상/초과 상태별 두 모델, 마스크 제거 절제 모델은 모두 **완전 창 ∪ 과거 부분결측**의 학습 행을 사용했다. 상태별 적합은 이 합집합을 현재 정상/초과로 나눴다. 오래된 두 창의 SM·메모리·`samples` 결측값은 이 확대 **학습 집합의 열별 중앙값**으로 채우고 원래 16개 수치 특징을 다시 계산했다. 모든 새 로지스틱에는 현재 초과 여부와 유효한 최근 세 창 중 초과 여부를 넣었다. 주 모델에는 오래된 두 창의 유효 마스크와 과거 유효 창 나이 **300/600/900초**를 더했다. 마스크 절제에서는 세 입력을 함께 제거했다. `StandardScaler`도 학습 행에서만 적합했고, `C={0.1,1,10}`은 검증 Brier로 골랐다. 모델 ID와 미래 값은 입력이 아니다.

아래 상위 5% 경보는 **각 시험일·각 집단별** 확률 상위 `ceil(0.05×n)`개다. 동률은 원래 해시 키로 정했다. 전체 재현율은 두 날의 경보를 합쳐 계산했다.

| 완전 창·현재 정상, 동일 53,513건 | Brier ↓ | AP ↑ | 상위 5% 재현율 ↑ |
| --- | ---: | ---: | ---: |
| 새 상태별 + 유효 마스크 | 0.019403 | **0.570364** | **0.633491** |
| 새 단일 + 유효 마스크 | **0.019285** | 0.551782 | 0.620326 |
| 새 상태별, 마스크 제거 | 0.021016 | 0.528970 | 0.632438 |
| 기존 선택 `any_recent_threshold` | 0.020702 | 0.449504 | 0.533965 |
| 기존 단일 로지스틱 | 0.138259 | 0.169505 | 0.330700 |

별도 사후 단순 기준선은 **완전 창·현재 정상 학습 행만**에서 `any_recent_high` 0/1별 Beta(1,1)률 **0.033061/0.721537**을 계산했다. 시험 Brier는 **0.020339**다. 시험 점수를 본 뒤 제안했으므로 위의 사전 선택·성공 판정 표에는 넣지 않았다.

완전 창 전체 217,672건에서도 새 상태별 모델 Brier **0.005773**, 선택 기준선 **0.006128**, 기존 로지스틱 **0.059147**이다. 현재 정상층의 일자별 핵심 비교는 다음과 같다.

| 시험일 | 새 상태별 Brier / 상위 5% 재현율 | 기존 선택 기준선 | 기존 로지스틱 |
| --- | ---: | ---: | ---: |
| 145일 | 0.025397 / 0.614991 | 0.027338 / 0.517888 | 0.154210 / 0.338160 |
| 146일 | 0.013927 / 0.663448 | 0.014641 / 0.560000 | 0.123689 / 0.318621 |

| 과거 부분결측·현재 정상, 동일 4,727건 | Brier ↓ | AP ↑ | 상위 5% 재현율 ↑ |
| --- | ---: | ---: | ---: |
| 새 상태별 + 유효 마스크 | 0.128556 | 0.809296 | 0.095800 |
| 새 단일 + 유효 마스크 | **0.128041** | **0.812868** | 0.095328 |
| 새 상태별, 마스크 제거 | 0.234164 | 0.688184 | 0.091553 |
| 부분결측 학습의 현재 상태별 Beta 평활률 | 0.248334 | 0.448276 | 0.044832 |
| **사후** 현재 상태×과거 유효 창 나이 Beta 평활률 | 0.167457 | 0.704813 | 0.078339 |

부분결측 전체 14,318건의 Brier는 상태별 **0.043347**, 새 단일 **0.043180**, 마스크 제거 **0.078215**, 상태별 평활률 **0.082895**다. 마지막 상태×나이 평활률은 **dry-run의 나이별 정답 건수를 본 뒤** 추가한 진단용 비교다. 부분결측 **학습 행만** 사용해 평활했고 사전 성공 판정에는 넣지 않았다. 부분결측 현재 정상층의 시험일 145/146 Brier는 새 상태별 **0.139669/0.116660**, 사전 단순 상태별 평활률 **0.249456/0.247134**다.

## 선택과 일반화 한계

시험 현재 정상층의 관측된 미래 초과율은 완전 창 **1,899/53,513(3.55%)**, 부분결측 **2,119/4,727(44.83%)**로 크게 다르다. 부분결측에서 과거 유효 창 나이 300/600/900초별로는 각각 **482/1,753(27.50%)**, **37/870(4.25%)**, **1,600/2,104(76.05%)**다. 이는 관측 품질 신호가 위험 예측에 유용할 수 있음을 보이지만, 결측 자체가 초과를 일으킨다는 뜻은 아니다.

**사후 집단구성 진단:** 시험 현재 정상층에서 완전 집단 ID는 786개, 부분결측 ID는 2,258개이며 738개가 겹친다. 겹친 ID의 완전 행은 **1,766/53,053(3.33%)**, 부분결측 행은 **315/2,851(11.05%)**가 양성이다. 부분결측에만 있는 1,520개 ID의 1,876행은 **1,804건(96.16%)** 양성이다. 이 1,520개 ID는 이 평가의 학습·검증 **라벨 관측 행**에서도 보이지 않는다. 따라서 전체 집단 간 위험률 차이의 큰 부분은 ID 구성 및 관측 선택과 연결될 수 있다. ID는 모델 특징에 넣지 않았다. 시험 현재 정상층의 ID별 행 수 중앙값도 완전 **15**, 부분결측 **1**이다.

**사후 미관측 정답 민감도:** 현재 정상 시험 후보의 미관측 미래를 전부 음성/양성으로 두면 전체 후보 위험률은 완전 창 **2.91~20.83%**, 부분결측 **22.14~72.75%**다. 구간이 근소하게 분리되더라도 미관측 이유, 새 ID 구성, 미래 창의 선택은 남는다. **성능 점수는 미래 여섯 창의 정답을 모두 관측한 부분집합에서만** 계산했다.

별도 [사후 강건성 감사](../artifacts/maas_state_followup_v1/posthoc_robustness.json)는 저장된 점수·예측을 확인하고 인스턴스 ID를 단위로 2,000회 짝지어 재표집했다. 완전 창·현재 정상에서 새 상태별−기존 선택 기준선의 Brier 차는 **−0.001299**, 95% 백분위 구간 **[−0.002172,−0.000393]**이다. 시험일 145의 구간은 **[−0.003309,−0.000580]**, 146의 구간은 **[−0.001597,+0.000196]**으로 후자는 0을 포함한다. 사전 기준의 두 날 **점 추정치** 우세는 충족했지만, 일자별 이득이 인스턴스 재표집에서도 확실하다고 표현하지 않는다. 이 재표집은 클러스터·일자 공통 충격이나 같은 주 재사용을 해결하지 못하며 사전 성공 판정에는 포함되지 않았다.

같은 사후 감사에서 새 상태별−현재 정상 전용 Beta 기준선의 Brier 차는 **−0.000936**, ID 재표집 95% 구간은 **[−0.001466,−0.000434]**였다. 이 더 강한 단순 기준선은 시험 결과를 본 뒤 정의했으므로 독립적인 사전 비교가 아니다.

`gpu_mem_util>100`의 공개 스키마상 의미는 확인되지 않아 기존 규약처럼 제외했다. 이 값의 의미에 따라 적격성·정답이 바뀔 수 있다. 표본은 한 공개 서비스·한 주·1% ID이고 시간상 독립된 새 시험 자료가 아니다. 실제 `SCALE_OUT/IN` 명령, 실행 완료, 사용자 지연·처리량 반사실 결과가 없으므로 이 확률은 **관측된 GPU 초과 위험**에만 대응한다. 서비스에서 VM 증감 판단이나 배포 효과가 좋아진다는 결론은 낼 수 없다. 다음 검증은 별도 기간/ID 표본과 실제 명령·응용 SLO 연계를 확보해야 한다.
