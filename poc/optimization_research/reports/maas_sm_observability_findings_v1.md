# Alibaba MaaS SM 관측 상태 예측: 개발 검증 결과 v1

## 판정

**사전 규약의 개발 게이트는 실패했다. 따라서 bucket 1의 새 ID 시험은 진행하지 않는다.** `bucket 0`의 140–142일로 모델을 학습하고 143일로 방법별 온도 하나를 보정한 뒤, 144일 119,703개 결정 후보를 한 번 평가했다. 사전 지원량 19개 조건은 모두 통과했다. 2단계 HGB는 세 단순 기준선보다 좋았으나, 같은 입력을 쓰는 직접 3분류 HGB보다 3클래스 Brier가 높았다. 6시간 네 블록 모두에서도 직접 HGB보다 높아 3/4 블록 승리 조건을 충족하지 못했다.

이 평가는 [사전 규약](maas_sm_observability_protocol_v1.md)과 [지원량 감사](../artifacts/maas_sm_observability_v1/feasibility.json)에 따라 진행했다. 목표는 **같은 관측 할당에서 향후 30분의 GPU SM 5분 평균이 80% 이상으로 관측되는 상태(H), 여섯 창 모두 정상으로 관측되는 상태(N), 정답을 확정할 수 없는 상태(U)**의 확률이다. 사용자 지연 SLO, GPU 메모리 부족, VM 증감 조치의 효과는 측정하지 않는다.

|---|---:|---:|---:|
| 2단계 HGB | 0.327200 | 0.525344 | 0.536362 |
| 전체 빈도 | 0.453009 | 0.963198 | 0.796058 |
| 조건부 빈도 | 0.397319 | 0.798267 | 0.671848 |
| 다항 로지스틱 | 0.354416 | 0.587757 | 0.604627 |
| 직접 3분류 HGB | **0.326560** | **0.516804** | **0.535059** |

2단계 HGB의 ID 동등가중 Brier는 직접 HGB보다 **0.000640 높다**. 규약상 직접 HGB보다 최소 5% 낮아야 하는 조건과 행 동등가중 Brier를 최소 2% 낮춰야 하는 조건이 모두 실패했다. H·U one-vs-rest Brier의 2% 비열화 조건, 최선 기준선 대비 로그손실 1% 조건, H ECE≤0.03 및 U ECE≤0.05는 통과했다. 2단계 모델의 H ECE는 0.0181, U ECE는 0.0209다. 이 보정 결과만으로 채택 게이트의 예측력 조건을 대신할 수 없다.

지원량은 학습 H/N/U 7,199/266,203/91,837, 보정 2,848/81,818/28,966, 검증 4,186/87,379/28,138이다. 검증 H는 972개 ID, U는 4,976개 ID에서 관측됐다. ID 동등가중치는 각 단계에서 ID별 총가중치가 같도록 계산했고, 두 번째 분류기는 H 제외 집합에서 다시 계산했다. 학습 후 튜닝이나 재학습은 하지 않았다.

## 미해결 정답과 해석 범위

U 28,138건을 형식적으로 0 또는 1로 채울 때, 검증 집합의 이진 사건 비율은 산술적으로 **3.50–27.00%** 범위다. 이는 물리적인 반사실 위험이나 신뢰구간이 아니다. 모든 U 행의 같은 미지 정답을 두 예측기 사이에서 함께 보충한 이진 Brier 차이 민감도 구간은 2단계 모델과 직접 HGB 비교 시 **−0.004245~+0.004372**로 0을 포함한다. 다른 세 기준선과의 구간도 모두 0을 포함한다. 따라서 미해결 정답을 보충한 전체 이진 위험 예측의 우열은 판정하지 않는다. 3클래스 관측 상태 결과도 같은 주·같은 bucket의 하루 개발 검증이며 새 ID·새 시기 일반화 증거가 아니다.
