# SwissAI 유휴 모델의 10분 내 요청 재도착 위험: 탐색 시험 결과

## 결론

5분간 요청이 없던 AI 모델에 향후 10분 안에 요청이 다시 올 확률을 학습했다. 고정된 2025-07-16~08-16 시험 845건에서 선택 로지스틱의 Brier는 **0.214223**, 검증으로 선택한 모델별 과거 재도착률 기준선은 **0.222405**였다. 상대 개선은 **3.68%**로 [사전 채택 기준 5%](swissai_idle_return_protocol.md)에 못 미친다. 네 완전 시험 주 중 세 주에서 이겼지만, 두 조건을 모두 만족해야 하므로 **학습기는 채택하지 않고 경험적 기준선을 유지한다**. 이 과제의 정답은 요청 재도착이지 실제 `SCALE_IN` 명령의 이득이 아니다.

## 자료·모델 선택

- 출처는 [ETH EASL SwissAI Serving Trace](https://huggingface.co/datasets/eth-easl/swissai-serving-trace)의 고정 revision이며 원본·정렬 자료의 SHA256과 분할은 [평가 규약](swissai_idle_return_protocol.md)에 기록돼 있다. 같은 서비스·기간을 앞선 연구에서 이미 탐색했고, 유휴 5분 조건도 라벨 지지 수를 보고 정했다. 따라서 이 결과는 **후향적 탐색**이다.
- 모델별 서로 다른 요청 발생시각에서 5분 유휴가 된 시점에 판단을 한 번 만들고, 다음 10분의 첫 요청 여부를 정답으로 썼다. 정확한 µs 경계, 분할 끝 검열, 이미 알려진 6시간 전역 공백 뒤 120분 보류를 적용했다. 학습은 2,237건/양성 846, 검증은 780/335, 시험은 **845/276**, 시험 대상은 41개 모델이다. [점수 전 적격성 감사](../artifacts/swissai_idle_return_v1/dry_run.json)가 모든 고정 지지 기준을 통과했다.
- 학습·검증 뒤 시험 점수 전에 [선택 동결 기록](swissai_idle_return_selection_frozen.md)을 작성했다. 검증 Brier가 낮은 **로지스틱**을 부스팅 대신 선택했고, 경험적 기준선의 수축 강도 `κ=100`, Poisson 기준선의 과거 창 120분을 고정했다. 시험을 보고 계수·기준선을 다시 고르지 않았다.
- 경험적 기준선은 학습 전역 확률을 고정하고, 검증·시험 중 해당 판단 시각보다 **10분 정답 창이 이미 끝난** 같은 모델의 유휴 에피소드만 온라인으로 추가했다. 미래 시험 정답을 앞선 판단에 사용하지 않았다.

## 같은 시험행의 비교

| 방법 | 시험 Brier ↓ | 시험 log loss ↓ | 평균 예측 확률 |
| --- | ---: | ---: | ---: |
| 선택 로지스틱 | **0.214223** | **0.618123** | 0.392246 |
| 모델별 과거 재도착률 + 학습 전역 확률 수축 | 0.222405 | 0.636765 | 0.395482 |
| 최근 120분 요청률 Poisson | 0.451005 | 3.951768 | 0.746485 |

실제 양성률은 **0.326627**다. 로지스틱도 평균 확률을 높게 예측해 보정이 완전하지 않다. Poisson은 이 자료에서 과거 도착률의 정상·독립 가정이 맞지 않는 약한 기준선이었다. 의사결정상 중요한 비교는 검증에서 강했던 **모델별 과거 재도착률**과의 차이다.

| 고정 시험 블록 | 건수 / 양성 | 로지스틱 Brier | 경험적 기준선 Brier | 비교 |
| --- | ---: | ---: | ---: | --- |
| 7/16–7/22 | 123 / 32 | 0.198794 | 0.210086 | 개선 |
| 7/23–7/29 | 239 / 84 | 0.223526 | 0.225170 | 개선 |
| 7/30–8/5 | 217 / 60 | 0.198769 | 0.216126 | 개선 |
| 8/6–8/12 | 157 / 42 | 0.209703 | 0.209352 | 악화 |
| 8/13–8/15, 보조 | 109 / 58 | 0.248510 | 0.261545 | 개선 |

시험 모델 41개 중 `≥10건`과 양·음성 모두 있는 **5개 모델**만 동일 모델 가중 평균에 적격하다. 이 5개의 평균 Brier는 **로지스틱 0.222411, 경험적 기준선 0.217927**로 방향이 뒤집힌다. 학습 종료 전 원시 요청이 전혀 없던 모델의 시험 303건/양성 77건은 로지스틱 0.192975, 기준선 0.198995였지만, 해당 모델에서 학습 적격 에피소드가 0건인 집단은 307건으로 별도로 보고한다. 일부 모델·주에 집중된 행 가중 개선을 전체 신규 모델 일반화로 해석하지 않는다.

시험 845건 중 **322건은 정답 창에 서비스 전체 요청도 0건**이다. 수집기 heartbeat가 없어 참된 무요청과 기록 누락을 구분할 수 없다. 미래 전역 요청이 있는 523건에는 양성 276건이 **전부 포함**되어 사건률이 바뀌므로, 이 집단의 점수를 주 결과나 누락 음성 보정치로 쓰지 않는다. 같은 집단 안에서만 비교하면 로지스틱 Brier 0.252314, 경험적 기준선 0.263338이다. 판단 당시 이미 다른 모델의 요청이 직전 10분에 있었던 온라인 보조 층 496건/양성 138건에서도 로지스틱 0.206953, 기준선 0.213418이다. 어느 층도 수집기 정상 동작을 보증하지 않는다.

## 판정과 산출물

학습기의 전체 이득 **3.68% < 사전 5%**다. 네 완전 주 중 세 주 승리 조건은 충족했지만, 모델별 균등 평균이 더 나쁘고 기록 공백 여부도 확인할 수 없다. 경희대의 현재 판단 메커니즘에는 학습 모델을 추가하지 않으며, 실험용으로는 **검증 선택 경험적 재도착률 기준선**을 남긴다. 실제 축소 정책을 평가하려면 VM/replica 수, 축소·복구 시각, 재요청의 지연·실패 및 사용자 SLO가 연결된 자료가 필요하다.
