# 설치 및 활용 가이드

## 요구사항

- Go 1.25 이상
- PowerShell 5.1 이상 for the local demo
- Linux/macOS에서는 `curl`과 `bash`를 사용할 수 있다.

## 서버 실행

```powershell
cd AppDeploy
$env:RESOURCE_PROVIDER = "local"
$env:PLACEMENT_PROVIDER = "local"
go run ./cmd/server
```

기본 주소는 `http://localhost:8080`이다.

- OpenAPI: `http://localhost:8080/openapi.yaml`
- API viewer: `http://localhost:8080/swagger`
- Health: `http://localhost:8080/api/v1/healthz`

이 프로젝트는 headless API 서버다. 별도의 embedded web console은 제공하지
않는다.

## 로컬 E2E 데모

```powershell
cd AppDeploy
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\local-demo.ps1
```

데모는 Application 등록, Local VM 등록, 결정론적 placement, 실제 로컬
프로세스 실행, 로그 조회, 중지, 자원 예약 반환까지 검증한다.

## Provider 설정

```text
RESOURCE_PROVIDER=local
PLACEMENT_PROVIDER=local
AIAPP_LOCAL_RUNTIME_WORK_DIR=tmp/local-runtime
```

ETRI 모드는 실제 API 계약 없이 stub으로만 제공된다.

```text
RESOURCE_PROVIDER=etri
PLACEMENT_PROVIDER=etri
ETRI_RESOURCE_ENDPOINT=<provided-by-etri>
ETRI_PLACEMENT_ENDPOINT=<provided-by-etri>
ETRI_CREDENTIAL_REF=cred://etri/resource-provider
ETRI_TIMEOUT=30s
```

endpoint가 없으면 서버는 시작되지 않는다. 실제 ETRI DTO, 인증, endpoint
경로는 계약 확정 후 Adapter에 추가한다.

## 검증

```powershell
$env:GOCACHE = ".\\.gocache"
go test ./...
go vet ./...
```

OpenAPI 변경 시 `contracts/openapi/openapi.yaml`을 기준으로 확인한다.
`docs/api/openapi.html`은 API viewer이며 별도 애플리케이션 UI가 아니다.
