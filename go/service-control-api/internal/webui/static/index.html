CORE WORKFLOW

자동 분석 및 판단

요청을 한 번 입력하면 요구사항 분석, 인프라 추천, Agent 배포 판단과 Adapter 전달을 순서대로 실행합니다.

AppDeploy 없이 실행 가능
실험 진행 방법처음 실행한다면 순서와 확인 항목을 펼쳐보세요.
  1. 1
    입력 방식 선택

    자연어 요청 또는 구조화 App Spec을 선택하고 배포 요구사항을 입력합니다.

  2. 2
    자동 분석 및 판단 실행

    자동 분석 및 판단을 눌러 네 단계를 한 번에 실행합니다.

  3. 3
    판단 결과 확인

    DEPLOY·REJECT·RETRY, Registry 권한, Go Guard, DesiredDeploymentSpec과 Adapter 상태를 확인합니다.

  4. 4
    선택 실험

    실험 결과에서 추론 비교 또는 Feedback·스케일링 판단을 추가로 검증합니다.

핵심 완료 기준: DEPLOY 판단과 Guard 승인 후 DesiredDeploymentSpec과 Adapter 증거가 생성되면 실험이 완료된 것입니다. SIMULATED는 실제 VM 배포가 아닙니다.

외부 시스템 연동: Common JSON v1.0 application.analysis.request는 /api/v1/agent-control/application-analysis-requests로 전송합니다. 같은 message_id를 다시 보내면 기존 실행 결과를 반환하여 중복 배포 요청 생성을 방지합니다.

  1. 1요구사항 분석ApplicationProfile 생성
  2. 2인프라 추천Mock 자원 후보 비교
  3. 3Agent 배포 판단Registry · Guard · Desired Spec
  4. 4Adapter 전달Mock simulation · External handoff ready
